AP Precalculus Logarithms: Rules, Equations, and Worked Examples

Read a logarithm as an exponent, check its domain, and connect the algebra to growth and decay.

School of Math · Updated October 6, 2026 · 4 min read

A logarithm answers an exponent question: logb(x) = y means by = x. In real-number work, the base must be positive and not equal to 1, and the argument must be positive. Start with that meaning before memorizing log rules.

Worked multiple-choice example

What is log2(8) + log9(1/3)?

  1. −5/3
  2. 10/3
  3. 5/2
  4. 7/2
Answer

Since 2³ = 8, log₂(8) = 3. To solve 9y = 1/3, write 32y = 3−1, so y = −1/2. The sum is 3 − 1/2 = 5/2, choice C.

Rules with their conditions

RuleFor positive u and v, valid base b
Productlogb(uv) = logb(u) + logb(v)
Quotientlogb(u/v) = logb(u) − logb(v)
Powerlogb(ur) = r logb(u)
Change of baselogb(u) = ln(u)/ln(b)

There is no corresponding rule splitting log(u + v) into log(u) + log(v). For example, log₂(2 + 2) = 2, while log₂(2) + log₂(2) = 2 happens to match by accident; using 2 and 6 instead gives log₂(8) = 3 but log₂(2) + log₂(6) = log₂(12), not 3. One coincidental example does not establish an identity.

Solve an equation and check the original domain

Solve log₂(x − 1) + log₂(x − 3) = 3.

Answer

The original arguments require x > 3. Combine the logs: log₂((x − 1)(x − 3)) = 3. Therefore (x − 1)(x − 3) = 8, so x² − 4x − 5 = 0. Factoring gives (x − 5)(x + 1) = 0. The candidates are 5 and −1, but only 5 satisfies x > 3. The solution is x = 5.

The rejected value is not “almost correct.” It makes the original real logarithms undefined. Review domain restrictions whenever solving produces more than one candidate.

Interpret a growth model

A population model is P(t) = 600(1.04)t, with t in years. When does the model first reach 900?

Answer

Set 900 = 600(1.04)t. Then 1.5 = 1.04t, so t = ln(1.5)/ln(1.04) ≈ 10.34 years. If the question only records whole-year observations, the first observed year at or above 900 is year 11. State which interpretation the context requires.

Three independent practice questions

1. Evaluate log4(1/8).

Answer

4y = 1/8 becomes 22y = 2−3, so y = −3/2.

2. Solve ln(x + 2) = ln(3x − 4).

Answer

The domain requires x > 4/3. Equal logarithms with the same valid base have equal arguments: x + 2 = 3x − 4, giving x = 3, which is valid.

3. A quantity is multiplied by 0.8 each hour. How long until it is half its initial value?

Answer

Solve 0.8t = 0.5 to get t = ln(0.5)/ln(0.8) ≈ 3.11 hours. The initial amount cancels because the question asks about a proportion of that amount.

Questions and answers

What does a logarithm mean?

It gives the exponent needed to produce its argument from its base.

Can the argument be negative in real-number work?

No. A real logarithm requires a positive argument.

Can I split the logarithm of a sum?

No. The product rule does not apply to addition inside the logarithm.

Why check solutions after using log rules?

Algebra can produce candidates outside the original logarithms’ domains.

When should I round a time answer up?

Only when the context calls for whole observation periods or another discrete unit.
