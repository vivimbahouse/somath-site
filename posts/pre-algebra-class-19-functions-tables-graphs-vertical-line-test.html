What is a function?

A function is a rule that assigns exactly one output to each input. In the poster the inputs 1, 2 and 3 each have one arrow, to 4, 5 and 6, so the mapping is a function. The second diagram sends the single input 2 to two different outputs, 5 and 7, so it is not a function: the input 2 cannot have two answers.

The rule is about inputs, not outputs. Different inputs are allowed to share an output, which is why (1, 4), (2, 4), (3, 4) is a function: every input still has one and only one partner. To decide, look at each input and ask “does this input ever get two different outputs?” If the answer is never, the relation is a function.

Ordered pairs are written (input, output). The “your turn” set {(1, 3), (2, 5), (1, 7)} is not a function because the input 1 appears with 3 and again with 7.

Practice: try these five questions

Q1

Is the set of ordered pairs {(2, 9), (4, 11), (6, 13)} a function? Explain.

Answer

Yes, it is a function

  1. List the inputs (first numbers): 2, 4, 6. No input is repeated.

  2. Each input has exactly one output: 2 → 9, 4 → 11, 6 → 13.

  3. No input receives two different outputs, so the relation is a function.

Q2

A mapping diagram sends 5 → 1, 6 → 2 and 5 → 8. Is it a function? Why or why not?

Answer

No, it is not a function

  1. The input 5 has two arrows: one to 1 and one to 8.

  2. A function may give each input only one output, so 5 cannot go to both 1 and 8.

  3. Because one input has two different outputs, the diagram does not represent a function.

Q3

Is {(0, 7), (3, 7), (8, 7), (10, 7)} a function? Explain what is repeated and whether it matters.

Answer

Yes, it is a function

  1. The inputs are 0, 3, 8, 10; none is repeated.

  2. The output 7 is repeated, but repeated outputs are allowed. The rule only says each input gets one output.

  3. Every input has exactly one output, so this is a function (a constant function: every input gives 7).

Q4

Fill in the blank so the relation is not a function, then explain: {(3, 2), (7, 5), (__, 9)}.

Answer

Use 3 or 7 as the missing input, for example (3, 9)

  1. To break the function rule, one input must have two different outputs.

  2. Writing 3 in the blank gives (3, 2) and (3, 9): input 3 has outputs 2 and 9, so it is not a function. Writing 7 works the same way: (7, 5) and (7, 9).

  3. Any other input, such as 4, would keep the relation a function because every input would still have one output.

Q5

A snack machine gives one snack for each button. Button A gives chips, Button B gives pretzels, Button C gives chips. Is “button → snack” a function? Would “snack → button” be a function?

Answer

Button → snack is a function; snack → button is not

  1. Button → snack: inputs A, B, C each produce exactly one snack (A → chips, B → pretzels, C → chips). Two buttons sharing chips is fine. This is a function.

  2. Snack → button: the input “chips” leads to two different buttons, A and C.

  3. One input with two outputs breaks the rule, so snack → button is not a function.

Inputs, outputs and function rules

The input is the value you start with, usually written \(x\), and the output is the value the rule produces, usually written \(y\). A rule such as “multiply by 3, then add 2” is written as the equation \(y = 3x + 2\). Putting in the input 4 gives \(y = 3(4) + 2 = 14\).

The same rule is applied to every input. The poster table uses \(y = 3x + 2\) for \(x = -1, 0, 2, 4\) and produces \(-1, 2, 8, 14\). Replace \(x\) with the input, follow the order of operations, and record the output.

To find a rule from inputs and outputs, ask what happens to each input. Inputs 1, 2, 3 becoming 5, 6, 7 means each input went up by 4, so the rule is \(y = x + 4\). Always test the rule on every pair before you trust it.

Q6

For the rule \(y = 4x - 1\), find the outputs when \(x = 0, 2,\) and \(5\).

Answer

\(y = -1, 7, 19\)

  1. Replace \(x\) with 0: \(y = 4(0) - 1 = 0 - 1 = -1\).

  2. Replace \(x\) with 2: \(y = 4(2) - 1 = 8 - 1 = 7\).

  3. Replace \(x\) with 5: \(y = 4(5) - 1 = 20 - 1 = 19\).

Q7

Write the rule “divide by 2, then add 5” as an equation. Then find the output when the input is 12.

Answer

\(y = \dfrac{x}{2} + 5\); output 11

  1. “Divide by 2” gives \(\dfrac{x}{2}\); “then add 5” gives \(y = \dfrac{x}{2} + 5\).

  2. Substitute \(x = 12\): \(y = \dfrac{12}{2} + 5 = 6 + 5 = 11\).

  3. Check the order: divide first, then add. Adding first would give \((12 + 5) \div 2 = 8.5\), which is a different rule.

Q8

Inputs 2, 3, 4 produce outputs 10, 15, 20. Find the rule and write it as an equation.

Answer

\(y = 5x\)

  1. Compare each pair: 2 → 10, 3 → 15, 4 → 20. Each output is 5 times its input.

  2. Write the rule: \(y = 5x\).

  3. Test every pair: \(5(2) = 10\), \(5(3) = 15\), \(5(4) = 20\). The rule works for all three.

Q9

Inputs 0, 1, 2, 3 produce outputs 6, 5, 4, 3. Find the rule.

Answer

\(y = 6 - x\)

  1. The outputs go down by 1 each time the input goes up by 1, so the rule subtracts \(x\).

  2. When \(x = 0\) the output is 6, so start from 6: \(y = 6 - x\).

  3. Check: \(6 - 1 = 5\), \(6 - 2 = 4\), \(6 - 3 = 3\). All four pairs fit.

Q10

For \(y = 2x + 7\), which input gives the output 25?

Answer

\(x = 9\)

  1. Set the output equal to 25: \(25 = 2x + 7\).

  2. Subtract 7 from both sides: \(18 = 2x\).

  3. Divide both sides by 2: \(x = 9\). Check: \(2(9) + 7 = 18 + 7 = 25\).

Completing function tables

A function table lists inputs and the outputs the rule produces. To fill a missing output, substitute the input and follow the operations in order. With \(y = 2x + 3\) and \(x = -2\): multiply, \(2(-2) = -4\); then add 3, \(-4 + 3 = -1\).

A missing input is found by working backward, which is solving an equation. If \(y = 11\), write \(11 = 2x + 3\), subtract 3 to get \(8 = 2x\), and divide by 2 to get \(x = 4\). Always check by substituting: \(2(4) + 3 = 11\).

Be careful with negative inputs. Multiply the sign too: \(3(-1) - 2 = -3 - 2 = -5\). Writing each step on its own line keeps the sign errors out.

Q15

Answer

Not correct; the output for \(x = 3\) should be 13

  1. Substitute \(x = 3\): \(6(3) - 5 = 18 - 5 = 13\).

  2. The table shows 12, so the row is wrong. The correct pair is (3, 13).

  3. Every row of a function table must follow the same rule, so recompute any row that looks off.

Identifying functions from tables

To decide whether a table is a function, check the inputs. Look for any input that appears more than once, then compare the outputs in those rows. Different outputs for the same input means the table is not a function.

Repeated outputs do not break the rule. The table 1 → 4, 2 → 4, 3 → 6 is a function even though 4 appears twice. The table 1 → 4, 2 → 5, 1 → 7 is not a function because the input 1 has two different outputs, 4 and 7.

An identical repeated pair, such as (2, 5) listed twice, does not break the rule either, because the input 2 still has only one output, 5.

From tables to graphs

Each row of a function table is an ordered pair \((x, y)\). For \(y = x + 1\) the rows become (−2, −1), (−1, 0), (0, 1), (1, 2), (2, 3). To plot a pair, read \(x\) first and move horizontally, then move vertically to \(y\) and mark the point.

The first number always tells you how far left or right to go; the second tells you how far down or up. The pair \((-2, -1)\) is 2 units left and 1 unit down, which is not the same point as \((-1, -2)\).

Plot only the points the table lists unless the problem asks for more. A table with five rows produces five dots; connecting them is a separate decision that depends on whether in-between inputs make sense.

Reading function graphs

A graph in context works like a table: the input is on the horizontal axis and the output is on the vertical axis. To read an output, find the input on the \(x\)-axis, move up to the plotted point, then read across to the \(y\)-axis. In the poster, 3 notebooks at $2 each gives the point (3, 6).

To go the other way, start on the \(y\)-axis, move across to the point, then read down to the input. Every point is an ordered pair that gives both pieces of information at once, so (2, 4) means “2 notebooks cost $4.”

Always read the axis labels and the scale. Grid lines may count by 2, 3 or 5, not just by 1. The questions below use a raffle-ticket graph and a plant-growth graph.

The vertical-line test

A graph shows \(y\) as a function of \(x\) when every vertical line meets the graph at most once. A vertical line stands over a single input; if it hits the graph twice, that input has two outputs, which a function does not allow.

The parabola \(y = x^2\) passes: slide a vertical line anywhere and it meets the curve once. A circle fails: the vertical line \(x = 1\) meets it at two points with different \(y\)-values. A slanted line passes; a vertical line such as \(x = 2\) fails because that one input has infinitely many outputs.

Vertical lines test inputs. Horizontal lines say nothing about whether \(y\) is a function of \(x\); a horizontal line crossing a graph many times only shows a repeated output, which is allowed.

Answer

Passes: the graph is a function

Fails: not a function

Passes: the graph is a function

  3. The graph passes the test; it is the constant function \(y = -3\).

Pass or fail? Explain using vertical lines.

Pass or fail? Explain using vertical lines. Then explain why a horizontal line crossing it several times does not matter.

Answer

Passes: the graph is a function

  1. Slide a vertical line across the zigzag. The graph goes up and down, but it never doubles back over the same \(x\)-value, so each vertical line meets it once.

  2. The horizontal line \(y = 0\) crosses the zigzag several times. That only shows the output 0 is produced by several inputs.

  3. Repeated outputs are allowed; only repeated inputs with different outputs break the function rule. The graph passes.

Mixed practice: function or not?

Functions can be shown as mapping diagrams, ordered pairs, tables, equations or graphs. The test is always the same question: does any input have two different outputs? For tables and ordered pairs, scan the inputs for repeats. For graphs, use vertical lines.

Repeated outputs never break the rule. A table where every output is 5 is a function, and so is the horizontal line \(y = 2\). A circle fails because a vertical line meets it twice, and (1, 2), (3, 4), (1, 6) fails because the input 1 appears with two outputs.

When a relation is not a function, one change can fix it: give the repeated input the same output in both places, or change one of the repeated inputs to a new value.

Homework word problems

Twelve problems that move from writing a rule to deciding which direction of a real relationship is a function. Define the input and output before you start, and check every answer in the original rule or graph.

W1

A taxi charges a $3 pickup fee plus $2 per mile. Write a rule for the total cost \(y\) of a ride of \(x\) miles, then find the cost of a 6-mile ride.

Answer

\(y = 2x + 3\); $15

  1. Each mile adds $2, so the mileage cost is \(2x\). The $3 fee is added once: \(y = 2x + 3\).

  2. Substitute \(x = 6\): \(y = 2(6) + 3 = 12 + 3 = 15\).

  3. A 6-mile ride costs $15. Check with a table row: 1 mile costs $5, 2 miles cost $7, and so on, up by $2 each mile.

Answer

\(y = 12x\)

  1. Earnings are 12 times the hours: \(y = 12x\).

  2. \(12(3) = 36\), \(12(5) = 60\), \(12(8) = 96\).

  3. Each hour is one input with exactly one amount earned, so earnings are a function of hours.

Maya is 3 years older than her brother. Let \(x\) be the brother's age and \(y\) Maya's age. Write the rule, complete the table for brother ages 5, 8 and 12, and find the brother's age when Maya is 20.

W4

A gym charges a $20 joining fee plus $15 per month. Write the rule for the total cost \(y\) after \(x\) months. Find the cost of 6 months, and find how many months cost $125 in total.

Answer

\(y = 15x + 20\); $110 for 6 months; 7 months cost $125

  1. Monthly cost \(15x\) plus the one-time fee: \(y = 15x + 20\).

  2. Six months: \(15(6) + 20 = 90 + 20 = 110\).

  3. Missing input: \(125 = 15x + 20\) → \(105 = 15x\) → \(x = 7\). Check: \(15(7) + 20 = 125\).

W5

In a school, each student is assigned exactly one homeroom teacher, and each teacher has about 25 students. Is “student → homeroom teacher” a function? Is “homeroom teacher → student” a function? Explain.

Answer

Student → teacher is a function; teacher → student is not

  1. Student → teacher: each student (input) has exactly one teacher (output). Many students sharing a teacher only repeats an output. Function.

  2. Teacher → student: one teacher (input) is matched with about 25 different students (outputs).

  3. One input with many outputs is not a function.

W6

A florist's price list shows the cost of a bouquet by the number of roses: 6 roses cost $18, 12 roses cost $36, and 6 roses cost $21 on holidays. Is “number of roses → price” a function? Explain, and tell what extra information would make it one.

Answer

Not a function as listed; adding the date (holiday or not) to the input would make it a function

  1. The input 6 roses appears twice with different outputs, $18 and $21.

  2. One input with two different outputs is not a function.

  3. If the input were “number of roses and whether it is a holiday,” then (6, regular) → 18 and (6, holiday) → 21 are different inputs, and each would have one price.

A class survey records height and the number of students with that height: 60 in → 3 students, 62 in → 5 students, 64 in → 3 students. Is “height → number of students” a function? Is “number of students → height” a function? Explain in context.

Answer

Height → number of students is a function; number of students → height is not

  1. Height → students: each height (60, 62, 64) has exactly one count. Two heights sharing the count 3 only repeats an output. Function.

  2. Students → height: the input 3 leads to two different heights, 60 in and 64 in.

  3. Knowing “3 students” does not tell you which height, so that direction is not a function.

Challenge. A drone's altitude is recorded every two seconds and graphed. Is altitude a function of time? Is time a function of altitude? Explain both answers using the graph.

Answer

Altitude is a function of time; time is not a function of altitude

  1. Altitude as a function of time: each time has exactly one altitude, and every vertical line meets the graph once. The drone cannot be at two heights at the same moment. Function.

  2. Time as a function of altitude: the altitude 30 m occurs at 2 s and at 4 s, and the altitude 0 m occurs at 0 s and 8 s. The input 30 m would have two outputs.

  3. So time is not a function of altitude. Any graph of a quantity measured against time passes the vertical-line test, but reversing the roles can fail.

Quick questions and answers

What is a function in pre-algebra?

A function is a rule that assigns exactly one output to each input. Inputs are usually written x and outputs y, and each pair can be written (x, y).

Can two inputs have the same output in a function?

Yes. Repeated outputs are allowed. The rule only forbids one input having two different outputs, so (1, 4), (2, 4), (3, 4) is a function.

How do I tell whether a table is a function?

Scan the input column for repeated values. If a repeated input has different outputs, the table is not a function. If every input appears once, or repeated inputs have identical outputs, it is a function.

How do I find a missing input in a function table?

Set the rule equal to the known output and solve backward with inverse operations. For y = 2x + 3 and y = 11, write 11 = 2x + 3, subtract 3, then divide by 2 to get x = 4.

How do I plot a table on a graph?

Each row is an ordered pair (x, y). Read x first and move horizontally, then move vertically to y and mark the point. Plot only the listed points unless the problem asks for more.

What is the vertical-line test?

A graph shows y as a function of x if every vertical line meets the graph at most once. Two intersections on one vertical line mean one input has two outputs, so the graph fails. Horizontal lines do not test this.
