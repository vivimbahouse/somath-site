Recognizing exponential functions

An exponential function has the variable in the exponent: \(f(x)=ab^x\), with \(b>0\), \(b\ne1\), and \(a\ne0\). Equal input increments give equal multiplicative ratios. A variable in the base, as in \(x^3\), is not exponential.

For the positive growth and decay models in this lesson, assume \(a>0\). A reflected graph with \(a<0\) still has an exponential form, but the increasing/decreasing direction reverses. Always read parentheses and negative exponents carefully.

Practice: try these five questions

Q1

Which functions are exponential? Explain each choice.

\[f(x)=7\cdot4^x,\quad g(x)=4x^3\]
Answer

Only \(f(x)=7\cdot4^x\) is exponential.

  1. In f, the base 4 is fixed and the input x is in the exponent. It has the form abˣ with a = 7 and b = 4.

  2. In g, x is the base and 3 is the fixed exponent, so g is a polynomial power function, not an exponential.

Check and interpret

For f, increasing x by 1 multiplies the output by 4. For g, consecutive output ratios are not constant.

Q2

Outputs at inputs 0, 1, 2, 3 are 6, 18, 54, 162. Show that an exponential model fits and write it.

Answer

\(f(x)=6\cdot3^x\)

  1. The output at x = 0 gives the initial value a = 6.

  2. Divide consecutive outputs to test for a common ratio.

    \[18/6=54/18=162/54=3\]

  3. Use the common ratio as the base.

    \[f(x)=6\cdot3^x\]

Check and interpret

At x = 3, \(6\cdot3^3=6\cdot27=162\), matching the last entry.

Q3

Outputs at inputs 0, 1, 2, 3 are 8, 13, 18, 23. Are these values linear or exponential? Justify.

Answer

Linear, not exponential.

  1. Compare consecutive differences.

    \[13-8=18-13=23-18=5\]

  2. Compare ratios: they are not equal.

    \[\frac{13}{8}\ne\frac{18}{13}\]

  3. A constant difference gives the linear model.

    \[f(x)=8+5x\]

Check and interpret

The model yields 8 at x = 0 and 23 at x = 3. Equal differences, not equal ratios, identify this pattern.

Q4

Evaluate f(-1) exactly. Show the power before multiplying.

\[f(x)=4\cdot \left(3\right)^{x}\]
Answer

\(f(-1)=\frac{4}{3}\)

  1. Substitute the requested input for x.

    \[f(-1)=4\cdot\left(3\right)^{-1}\]

  2. Evaluate the power. For a negative exponent, take the reciprocal of the corresponding positive power.

    \[\left(3\right)^{-1}=\frac{1}{3}\]

  3. Multiply by the coefficient.

    \[4\cdot\frac{1}{3}=\frac{4}{3}\]

Check and interpret

Exponentiation happens before multiplication. The output one step later would be \(4\), which is \(3\) times this answer.

Q5

Explain why base 1 is excluded from a nonconstant exponential model.

\[f(x)=12\cdot1^x\]
Answer

\(f(x)=12\) for every real x.

  1. Any real power of the positive number 1 equals 1.

    \[1^x=1\]

  2. Multiply by the initial coefficient.

    \[12\cdot1=12\]

  3. The output never changes, so this is constant rather than exponential growth or decay.

Check and interpret

The outputs at x = −2, 0, and 5 are all 12.

Initial value and repeated multiplier

For \(f(x)=ab^x\), \(f(0)=a\), because \(b^0=1\). The base is also the ratio \(f(x+1)/f(x)=b\), provided the coefficient is nonzero.

If a vertical shift is present, \(a\) is not automatically the y-intercept. Substitute \(x=0\) in the whole function. The five questions here use the unshifted form so you can interpret \(a\) and \(b\) directly.

Q6

Identify the initial value and multiplier. State growth or decay and the percentage change per one-unit increase in x.

\[f(x)=7\cdot \left(2\right)^{x}\]
Answer

Initial value \(7\); factor \(2\); growth of \(100\)% per step.

  1. Set x equal to zero; every positive base to the zero power equals 1.

    \[f(0)=7\cdot1=7\]

  2. The base is the repeated multiplier, not the percentage rate.

    \[b=2\]

  3. Subtract 1 from the base for growth; subtract the base from 1 for decay.

    \[r=b-1=1\]

Check and interpret

The next output is \(f(1)=14\). Dividing by the initial output gives \(2\), the stated multiplier.

Q9

An exponential model has f(0) = 14 and f(1) = 35. Find the base and write the model.

Answer

\(f(x)=14(2.5)^x\)

  1. Use the value at zero as the initial coefficient.

    \[a=14\]

  2. Divide the next output by the first.

    \[b=\frac{35}{14}=\frac52=2.5\]

  3. Substitute a and b in the exponential form.

    \[f(x)=14(2.5)^x\]

Check and interpret

At x = 1, \(14(2.5)=35\). The factor 2.5 means 150% growth, not 250% growth.

Q10

A positive-base exponential function passes through (1, 12) and (3, 108). Find a and b.

Answer

\(f(x)=4\cdot3^x\)

  1. Use the two given points.

    \[ab=12,\quad ab^3=108\]

  2. Divide equations; the input gap is 2, so the ratio is b squared.

    \[b^2=\frac{108}{12}=9\]

  3. The base must be positive, so b = 3. Recover a from the first equation.

    \[a=\frac{12}{3}=4\]

Check and interpret

Both points work: \(4\cdot3=12\) and \(4\cdot27=108\).

Exponential growth

When \(a>0\) and \(b>1\), \(ab^x\) increases as \(x\) increases. Growth adds the same percentage to the current amount each period, not the same number of units.

For a growth rate \(r\) written as a decimal, use \(b=1+r\). Doubling is a factor of 2 and a 100% increase; tripling is a factor of 3 and a 200% increase.

Q13

A model starts at 200 units and grows by 10% per year. Write an exponential model and find the amount after 3 years.

Answer

\(A(t)=200\cdot \left(\frac{11}{10}\right)^{t}\); after 3 years: 266.2 units (model prediction).

  1. Define t as the number of years since the starting measurement. The initial amount is 200 units.

  2. Convert the rate to a decimal and form the repeated multiplier.

    \[r=\frac{1}{10},\quad b=1+\frac{1}{10}=\frac{11}{10}\]

  3. Use the starting amount times the multiplier raised to the number of periods. The model uses t ≥ 0.

    \[A(t)=200\cdot \left(\frac{11}{10}\right)^{t}\]

  4. Substitute the requested time. Keep full precision until the final answer.

    \[A(3)=200\left(\frac{11}{10}\right)^{3}=\frac{1331}{5}\]

Check and interpret

The model gives \(A(0)=200\). Each new period multiplies the previous amount by \(\frac{11}{10}\), rather than adding or subtracting the same fixed amount.

Q14

Compare the outputs after 3 periods. Which is larger, and by how much?

\[A(t)=30\cdot2^t,\quad B(t)=50(1.5)^t\]
Answer

A is larger by 71.25 units.

  1. Evaluate the first model.

    \[A(3)=30\cdot8=240\]

  2. Evaluate the second model.

    \[B(3)=50(3.375)=168.75\]

  3. Subtract the smaller output from the larger.

    \[240-168.75=71.25\]

Check and interpret

A starts smaller but has the larger multiplier. Initial size alone does not determine the larger future output.

Q15

A student models 20% growth from 80 units as 80(0.20)^t. Explain the error and give the correct amount after 2 periods.

Answer

\(A(t)=80(1.20)^t\); after 2 periods: 115.2 units.

  1. A 20% increase keeps the original 100% and adds another 20%.

    \[b=1+0.20=1.20\]

  2. Write the corrected model.

    \[A(t)=80(1.20)^t\]

  3. Evaluate after two periods.

    \[A(2)=80(1.44)=115.2\]

Check and interpret

A factor of 0.20 would keep only 20% each period, causing 80% decay. The correct outputs increase from 80 to 96 to 115.2.

Q19

A quantity halves every 3 hours, starting at 96 units. Write a model in hours and find the amount after 9 hours.

Answer

\(A(t)=96(1/2)^{t/3}\); after 9 hours: 12 units.

  1. One factor of one-half is applied for each 3-hour interval. The number of intervals is t/3.

  2. Write the model.

    \[A(t)=96\left(\frac12\right)^{t/3}\]

  3. Nine hours contains three half-life intervals.

    \[A(9)=96\left(\frac12\right)^3=12\]

Check and interpret

The sequence at 0, 3, 6, 9 hours is 96, 48, 24, 12. Using t instead of t/3 would halve the quantity too frequently.

Q20

Will this model ever equal zero at a finite real input? Explain using the factors.

\[f(x)=45(0.6)^x\]
Answer

No. The output is positive for every finite real x.

  1. The base is positive, so every finite real power of it is positive.

    \[(0.6)^x>0\]

  2. Multiplying by the positive coefficient keeps the result positive.

    \[45(0.6)^x>0\]

  3. Because the base is less than 1, the output approaches 0 as x increases without bound.

Check and interpret

The line y = 0 is a horizontal asymptote, not a finite x-intercept.

Converting rates and factors

Convert a percentage to a decimal by dividing by 100. Growth uses \(b=1+r\); decay uses \(b=1-r\). Reverse the process with \(r=b-1\) for growth or \(r=1-b\) for decay.

The rate is tied to one unit of the exponent. If two models use different time units, convert the periods before comparing their factors. A 10% increase followed by a 10% decrease does not return to the starting amount.

Tables of values and negative inputs

Evaluate exponents before multiplying. For a positive base, \(b^0=1\) and \(b^{-n}=1/b^n\). A negative exponent means a reciprocal, not a negative output.

For equally spaced inputs with step 1, unshifted exponential outputs have constant ratio \(b\). If the inputs are two units apart, the ratio is \(b^2\); unequal input steps cannot be compared with a single-step ratio.

Q26

Make a table for x = −2, −1, 0, 1, 2. Explain the pattern between consecutive outputs.

\[f(x)=2\cdot \left(3\right)^{x}\]
Answer

\((-2,\frac{2}{9})\), \((-1,\frac{2}{3})\), \((0,2)\), \((1,6)\), \((2,18)\)

  1. Substitute x = -2. Evaluate the exponent, then multiply and apply any vertical shift.

    \[f(-2)=2\cdot \left(3\right)^{(-2)}=\frac{2}{9}\]

  2. Substitute x = -1. Evaluate the exponent, then multiply and apply any vertical shift.

    \[f(-1)=2\cdot \left(3\right)^{(-1)}=\frac{2}{3}\]

  3. Substitute x = 0. Evaluate the exponent, then multiply and apply any vertical shift.

    \[f(0)=2\cdot \left(3\right)^{(0)}=2\]

  4. Substitute x = 1. Evaluate the exponent, then multiply and apply any vertical shift.

    \[f(1)=2\cdot \left(3\right)^{(1)}=6\]

  5. Substitute x = 2. Evaluate the exponent, then multiply and apply any vertical shift.

    \[f(2)=2\cdot \left(3\right)^{(2)}=18\]

Graphing from exact points

Build a table that includes zero, positive inputs, and negative inputs. Label a consistent scale on both axes, plot the points, and draw a smooth curve that approaches the horizontal asymptote.

For a positive unshifted exponential, the y-intercept is \((0,a)\), the range is positive, and the graph has no x-intercept. The plotted window is only part of an infinite curve; it does not restrict the function’s mathematical domain.

Choose units first: if \(t\) counts years, the base must represent one year. Repeated percent change follows \(A(t)=a(1\pm r)^t\), with \(r\) a decimal. Interpret both the starting amount and the time period in the story.

Quick questions and answers

What makes a function exponential?

The variable is in the exponent of a fixed positive base other than 1. In an unshifted exponential, equal input steps produce a constant output ratio, not a constant difference.

How can I tell growth from decay?

For a positive initial value in abˣ, a base greater than 1 produces growth, while a base between 0 and 1 produces decay. A negative coefficient reflects the graph and reverses its increasing/decreasing direction.

Is the multiplier the percentage rate?

No. For growth, subtract 1 from the multiplier; for decay, subtract the multiplier from 1. Multiply the resulting decimal by 100 to express it as a percentage.

What does a negative exponent mean?

A negative exponent gives the reciprocal of the corresponding positive power. It does not make a positive-base exponential output negative.

How do shifts affect the asymptote and range?

For ab^(x−h)+k, the horizontal asymptote is y=k. The range lies above k when a is positive and below k when a is negative. Substitute zero into the entire formula for the y-intercept.

How does compounding more than once a year work?

Divide the nominal annual decimal rate by the number of compounding periods per year, then multiply the number of years by that same number for the exponent. Keep full precision until the final rounding.
