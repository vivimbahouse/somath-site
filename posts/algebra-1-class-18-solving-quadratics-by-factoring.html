Quadratic equations and standard form

A quadratic equation is an equation whose highest power of the variable is 2. Its standard form is \(ax^2 + bx + c = 0\) with \(a \neq 0\): \(a\) is the coefficient of \(x^2\), \(b\) is the coefficient of \(x\), and \(c\) is the constant term. Signs belong to the coefficients, so in \(3x^2 - 8x + 5 = 0\) the value of \(b\) is \(-8\).

If an equation is not equal to zero, move every term to one side by adding or subtracting the same quantity on both sides. Factoring methods only tell us something useful when the product equals zero, so always set the equation equal to zero before factoring.

Q5

Decide whether each equation is quadratic: \(4x - 7 = 0\) and \((x + 1)(x - 2) = 0\). Explain.

Answer

\(4x - 7 = 0\) is linear, not quadratic; \((x + 1)(x - 2) = 0\) is quadratic.

  1. In \(4x - 7 = 0\) the highest power of \(x\) is 1, so \(a = 0\). It is a linear equation.

  2. Multiply out \((x + 1)(x - 2)\): \(x^2 - 2x + x - 2 = x^2 - x - 2\). The highest power is 2, so the equation is quadratic with \(a = 1\), \(b = -1\), \(c = -2\).

    \[x^2 - x - 2 = 0\]

  3. Because the second equation is already a product equal to zero, it is ready for the zero-product property without any further rearranging.

The zero-product property

If two factors multiply to zero, at least one of them must be zero: \(AB = 0\) means \(A = 0\) or \(B = 0\). This is the key that turns a factored quadratic into two simple linear equations. For \((x - 6)(x + 4) = 0\), set \(x - 6 = 0\) and \(x + 4 = 0\) to get \(x = 6\) or \(x = -4\).

The property works only when the product equals zero. If \((x - 2)(x + 5) = 8\), you cannot set each factor equal to 8; first expand, subtract 8, and factor again. Always substitute each solution back into the original equation to check.

Q10

A student writes \(x - 2 = 8\) or \(x + 5 = 8\) for this equation. Explain the error, then solve correctly.

\[(x - 2)(x + 5) = 8\]
Answer

\(x = -6\) or \(x = 3\)

  1. The zero-product property applies only when the product is 0. The product here is 8, so the factors cannot be set equal to 8. Expand the left side: \((x - 2)(x + 5) = x^2 + 3x - 10\), so the equation is \(x^2 + 3x - 10 = 8\).

  2. Subtract \(8\) on both sides so the equation equals zero (standard form).

    \[x^2 + 3x - 18 = 0\]

  3. Find two numbers that multiply to \(-18\) and add to \(3\): \(6\) and \(-3\), because \((6)(-3) = -18\) and \(6 + (-3) = 3\).

    \[(x + 6)(x - 3) = 0\]

  4. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[x + 6 = 0 \Rightarrow x = -6 \quad\text{or}\quad x - 3 = 0 \Rightarrow x = 3\]

  5. Check \(x = -6\) in the original equation: left side \((-6)^2 + 3(-6) - 10 = 36 - 18 - 10 = 8\); right side \(8\). Both sides equal \(8\), so it checks.

  6. Check \(x = 3\) in the original equation: left side \(3^2 + 3(3) - 10 = 9 + 9 - 10 = 8\); right side \(8\). Both sides equal \(8\), so it checks.

Factoring out the greatest common factor

When every term shares a factor, pull it out first. For \(ax + bx = x(a + b)\), the shared factor is \(x\). In \(x^2 - 7x = 0\) both terms contain \(x\), giving \(x(x - 7) = 0\) and the solutions \(x = 0\) or \(x = 7\). In \(4x^2 + 20x = 0\) the GCF is \(4x\), giving \(4x(x + 5) = 0\).

Never divide both sides by \(x\) to simplify: that step throws away the solution \(x = 0\). Factor instead, and then the zero-product property finds every solution.

Factoring trinomials with leading coefficient 1

For \(x^2 + bx + c = 0\), find two numbers \(m\) and \(n\) that multiply to \(c\) and add to \(b\). Then \(x^2 + bx + c = (x + m)(x + n)\). A positive \(c\) means both numbers have the same sign (the sign of \(b\)); a negative \(c\) means one is positive and one is negative.

After factoring, set each factor equal to zero. For \(x^2 + 9x + 20 = 0\) the pair is 4 and 5, so \((x + 4)(x + 5) = 0\) and \(x = -4\) or \(x = -5\). Multiply the factors back out to be sure they match the original trinomial.

Factoring trinomials with the ac method

When the leading coefficient is not 1, multiply \(a\) and \(c\) and find two numbers with product \(ac\) and sum \(b\). Split the middle term using those numbers, group the four terms in pairs, factor each pair, and factor out the common binomial. For \(2x^2 + 9x + 4 = 0\): \(ac = 8\), the pair is 8 and 1, so \(2x^2 + 8x + x + 4 = 2x(x + 4) + 1(x + 4) = (2x + 1)(x + 4)\).

Multiply, split, group, solve. Always check for a greatest common factor first, and expect fraction solutions such as \(x = -\frac{1}{2}\) when a factor like \(2x + 1\) appears.

Solve using the ac method.

\[2x^2 + 9x + 4 = 0\]
Answer

\(x = -\frac{1}{2}\) or \(x = -4\)

Special factoring patterns

Two patterns save time. A difference of squares \(a^2 - b^2 = (a - b)(a + b)\) has no middle term: \(x^2 - 49 = 0\) becomes \((x - 7)(x + 7) = 0\), so \(x = 7\) or \(x = -7\). It also works with coefficients that are squares, such as \(4x^2 - 9 = (2x - 3)(2x + 3)\).

A perfect-square trinomial \(a^2 \pm 2ab + b^2 = (a \pm b)^2\) has a repeated factor, so the equation has one distinct solution, called a double root. For \(x^2 + 10x + 25 = 0\), \((x + 5)^2 = 0\) gives \(x = -5\). Recognize the pattern, factor, and set the factor equal to zero.

Rearranging and checking solutions

Many equations arrive with terms on both sides or as a product that does not equal zero. Rearrange first: add or subtract to bring everything to one side, combine like terms, and then factor. For \(x^2 - 4x = 21\), subtract 21 to get \(x^2 - 4x - 21 = 0 = (x - 7)(x + 3)\), so \(x = 7\) or \(x = -3\).

Check in the original equation, not in a rearranged version. Substituting \(x = -3\) gives \((-3)^2 - 4(-3) = 9 + 12 = 21\), which matches the right side. Rearrange, factor, solve, check.

    \[n^2 = 4n + 5\]

  3. Expand and write it in standard form.

    \[n^2 - 4n - 5 = 0\]

  4. Find two numbers that multiply to \(-5\) and add to \(-4\): \(-5\) and \(1\), because \((-5)(1) = -5\) and \(-5 + (1) = -4\).

    \[(n - 5)(n + 1) = 0\]

  5. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[n - 5 = 0 \Rightarrow n = 5 \quad\text{or}\quad n + 1 = 0 \Rightarrow n = -1\]

  6. Both solutions are allowed because nothing in the problem rules out negative numbers. Check \(n = -1\): \((-1)^2 = 1\) and \(4(-1) + 5 = 1\).

  7. Interpretation: The number is 5 or −1; both values work.

W4

A ball is thrown upward from the ground. Its height in feet after \(t\) seconds is \(h = -16t^2 + 64t\). When does the ball land?

Answer

The ball lands after 4 seconds.

  1. Let \(t\) = the time in seconds; the ball lands when \(h = 0\).

  2. Model the situation with an equation.

    \[-16t^2 + 64t = 0\]

  3. Expand and write it in standard form.

    \[-16t^2 + 64t = 0\]

  4. Both terms contain \(16t\), so the greatest common factor is \(16t\). Factor out \(-16t\) so the binomial inside has a positive leading term. Do not divide both sides by \(t\), or the solution \(t = 0\) is lost.

    \[-16t(t - 4) = 0\]

  5. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[t = 0 \quad\text{or}\quad t - 4 = 0 \Rightarrow t = 4\]

  6. The solution \(t = 0\) is the launch, so the landing time is \(t = 4\).

  7. Check: \(-16(4)^2 + 64(4) = -256 + 256 = 0\).

  8. Interpretation: The ball lands after 4 seconds.

W5

A model rocket's height in meters after \(t\) seconds is \(h = -5t^2 + 30t\). At what times is the rocket 40 m high?

Answer

The rocket is 40 m high at 2 seconds (on the way up) and at 4 seconds (on the way down).

  1. Let \(t\) = the time in seconds; set \(h = 40\).

  2. Model the situation with an equation.

    \[-5t^2 + 30t = 40\]

  3. Expand and write it in standard form.

    \[-5t^2 + 30t - 40 = 0\]

  4. Every term is divisible by \(-5\). Factor out the GCF first. Factoring out the negative makes the leading coefficient inside positive.

    \[-5(t^2 - 6t + 8) = 0\]

  5. Find two numbers that multiply to \(8\) and add to \(-6\): \(-4\) and \(-2\), because \((-4)(-2) = 8\) and \(-4 + (-2) = -6\).

    \[-5(t - 4)(t - 2) = 0\]

  6. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[t - 4 = 0 \Rightarrow t = 4 \quad\text{or}\quad t - 2 = 0 \Rightarrow t = 2\]

  7. Both times are positive and make sense: the rocket passes 40 m twice. Check \(t = 2\): \(-5(4) + 60 = 40\); check \(t = 4\): \(-5(16) + 120 = 40\).

  8. Interpretation: The rocket is 40 m high at 2 seconds (on the way up) and at 4 seconds (on the way down).

W6

An 8-inch by 10-inch photo is surrounded by a frame of uniform width. The total area of the photo and frame is 143 square inches. How wide is the frame?

Answer

The frame is 1.5 inches wide.

  1. Let \(x\) = the width of the frame in inches, so the outer dimensions are \(8 + 2x\) and \(10 + 2x\).

  2. Model the situation with an equation.

    \[(8 + 2x)(10 + 2x) = 143\]

  3. Expand: \((8 + 2x)(10 + 2x) = 80 + 16x + 20x + 4x^2 = 4x^2 + 36x + 80\).

  4. Expand and write it in standard form.

    \[4x^2 + 36x - 63 = 0\]

  5. The leading coefficient is \(4\), so use the ac method. Multiply \(a \cdot c = (4)(-63) = -252\). Find two numbers with product \(-252\) and sum \(36\): \(42\) and \(-6\).

  6. Split the middle term using those two numbers.

    \[4x^2 + 42x - 6x - 63 = 0\]

  7. Group in pairs and factor each pair; the same binomial appears in both groups.

    \[2x(2x + 21) - 3(2x + 21) = 0\]

  8. Factor out the common binomial.

    \[(2x - 3)(2x + 21) = 0\]

  9. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[2x - 3 = 0 \Rightarrow x = \frac{3}{2} \quad\text{or}\quad 2x + 21 = 0 \Rightarrow x = -\frac{21}{2}\]

  10. Reject \(x = -\frac{21}{2}\): a width cannot be negative. So \(x = \frac{3}{2} = 1.5\).

  11. Check: the outer dimensions are \(8 + 3 = 11\) and \(10 + 3 = 13\), and \(11 \times 13 = 143\).

  12. Interpretation: The frame is 1.5 inches wide.

W7

A triangle has an area of 36 cm². Its base is 6 cm more than its height. Find the base and the height.

Answer

The height is 6 cm and the base is 12 cm.

  1. Let \(h\) = the height in centimeters, so the base is \(h + 6\).

  2. Model the situation with an equation.

    \[\tfrac{1}{2}\,h(h + 6) = 36\]

  3. Multiply both sides by 2: \(h(h + 6) = 72\).

  4. Expand and write it in standard form.

    \[h^2 + 6h - 72 = 0\]

  5. Find two numbers that multiply to \(-72\) and add to \(6\): \(12\) and \(-6\), because \((12)(-6) = -72\) and \(12 + (-6) = 6\).

    \[(h + 12)(h - 6) = 0\]

  6. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[h + 12 = 0 \Rightarrow h = -12 \quad\text{or}\quad h - 6 = 0 \Rightarrow h = 6\]

  7. Reject \(h = -12\): a length cannot be negative. So \(h = 6\) and the base is \(6 + 6 = 12\).

  8. Check: \(\tfrac{1}{2}(12)(6) = 36\) cm².

  9. Interpretation: The height is 6 cm and the base is 12 cm.

W10

A club sells T-shirts. If the price is \(p\) dollars, it sells \(40 - p\) shirts, so the revenue is \(p(40 - p)\) dollars. What prices give a revenue of exactly $300?

Answer

A price of $10 or $30 gives revenue of $300.

  1. Let \(p\) = the price in dollars.

  2. Model the situation with an equation.

    \[p(40 - p) = 300\]

  3. Expand and write it in standard form.

    \[-p^2 + 40p - 300 = 0\]

  4. Factor out \(-1\) so the leading coefficient inside is positive.

    \[-(p^2 - 40p + 300) = 0\]

  5. Find two numbers that multiply to \(300\) and add to \(-40\): \(-30\) and \(-10\), because \((-30)(-10) = 300\) and \(-30 + (-10) = -40\).

  6. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[p - 30 = 0 \Rightarrow p = 30 \quad\text{or}\quad p - 10 = 0 \Rightarrow p = 10\]

  7. Both prices are positive and sensible. Check: \(10(30) = 300\) and \(30(10) = 300\).

  8. Interpretation: A price of $10 or $30 gives revenue of $300.

W12

The legs of a right triangle differ by 7 cm, and the hypotenuse is 13 cm. Find the lengths of the legs.

Answer

The legs are 5 cm and 12 cm.

  1. Let \(x\) = the shorter leg in centimeters, so the longer leg is \(x + 7\).

  2. Model the situation with an equation.

    \[x^2 + (x + 7)^2 = 13^2\]

  3. Use the Pythagorean theorem. Expand: \(x^2 + x^2 + 14x + 49 = 169\), so \(2x^2 + 14x + 49 = 169\).

  4. Expand and write it in standard form.

    \[2x^2 + 14x - 120 = 0\]

  5. Every term is divisible by \(2\). Factor out the GCF first.

    \[2(x^2 + 7x - 60) = 0\]

  6. Find two numbers that multiply to \(-60\) and add to \(7\): \(12\) and \(-5\), because \((12)(-5) = -60\) and \(12 + (-5) = 7\).

    \[2(x + 12)(x - 5) = 0\]

  7. By the zero-product property, at least one factor must be zero. Set each factor equal to zero and solve.

    \[x + 12 = 0 \Rightarrow x = -12 \quad\text{or}\quad x - 5 = 0 \Rightarrow x = 5\]

  8. Reject \(x = -12\): a length cannot be negative. So \(x = 5\) and the longer leg is 12.

  9. Check: \(5^2 + 12^2 = 25 + 144 = 169 = 13^2\).

  10. Interpretation: The legs are 5 cm and 12 cm.

Quick questions and answers

Why must the equation equal zero before factoring?

The zero-product property says a product is zero only when a factor is zero. If the product equals any other number, such as 8, knowing the factors tells you nothing about their individual values. Move every term to one side first.

What is the zero-product property?

If \(AB = 0\), then \(A = 0\) or \(B = 0\). After factoring a quadratic into two linear factors, set each factor equal to zero and solve the two small equations.

Why can't I divide both sides by \(x\) in \(x^2 - 7x = 0\)?

Dividing by \(x\) assumes \(x \neq 0\), so the solution \(x = 0\) disappears. Factor instead: \(x(x - 7) = 0\) gives both \(x = 0\) and \(x = 7\).

How do I factor when the leading coefficient is not 1?

Use the ac method: multiply \(a\) and \(c\), find two numbers with that product and sum \(b\), split the middle term, group in pairs, and factor out the common binomial. Check for a GCF first.

What does a double root mean?

A perfect-square trinomial such as \(x^2 - 14x + 49 = (x - 7)^2\) has a repeated factor, so the equation has only one distinct solution, \(x = 7\). Graphically, the parabola touches the x-axis once.

How do I check a solution?

Substitute it into the original equation, not a rearranged one, and compute both sides. If they are equal, the solution is correct. In word problems also confirm the value makes sense; reject negative lengths or times.

What if a quadratic doesn't factor over the integers?

Then this class's method does not apply directly. Later classes solve such equations by completing the square and with the quadratic formula; factoring is the fastest route whenever an integer pair exists.
