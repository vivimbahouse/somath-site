Why the denominator stays the same

The denominator tells you the size of each piece; the numerator tells you how many pieces you have. In \(\frac{2}{7} + \frac{3}{7}\), both fractions count sevenths, so two sevenths plus three sevenths is five sevenths: \(\frac{5}{7}\). The size of the pieces never changes, so the denominator stays 7. Adding the denominators to get \(\frac{5}{14}\) would claim the pieces suddenly became half as big, which is why that is always wrong.

Rational expressions follow the same rule. \(\frac{2}{x}\) is two copies of \(\frac{1}{x}\) and \(\frac{3}{x}\) is three copies, so \(\frac{2}{x} + \frac{3}{x} = \frac{2+3}{x} = \frac{5}{x}\). In general, \(\frac{a}{d} + \frac{b}{d} = \frac{a+b}{d}\) and \(\frac{a}{d} - \frac{b}{d} = \frac{a-b}{d}\). Because the denominator is a variable expression, note the restriction: here \(x \neq 0\). Then simplify the result if the numerator and denominator share a factor.

Practice: try these five questions

Q1

Add and simplify.

\[\frac{3}{11} + \frac{5}{11}\]
Answer

\(\dfrac{8}{11}\)

  1. The denominators match, so add the numerators and keep the denominator.

    \[\frac{3}{11} + \frac{5}{11} = \frac{3+5}{11} = \frac{8}{11}\]

  2. Three elevenths plus five elevenths is eight elevenths. The fraction is already in lowest terms.

Q2

Add and state the restriction.

\[\frac{4}{x} + \frac{9}{x}\]
Answer

\(\dfrac{13}{x}, \; x \neq 0\)

  1. Keep the common denominator \(x\) and add the numerators.

    \[\frac{4}{x} + \frac{9}{x} = \frac{4+9}{x} = \frac{13}{x}\]

  2. The denominator is zero when \(x = 0\), so \(x \neq 0\).

Q3

Add, simplify, and state the restriction.

\[\frac{7}{2y} + \frac{5}{2y}\]
Answer

\(\dfrac{6}{y}, \; y \neq 0\)

  1. Add the numerators over the common denominator.

    \[\frac{7+5}{2y} = \frac{12}{2y}\]

  2. Divide the numerator and denominator by their common factor, 2.

    \[\frac{12}{2y} = \frac{6}{y}\]

  3. The original denominator \(2y\) is zero when \(y = 0\).

Q4

Subtract and state the restriction.

\[\frac{5}{a} - \frac{8}{a}\]
Answer

\(-\dfrac{3}{a}, \; a \neq 0\)

  1. Subtract the numerators and keep the denominator.

    \[\frac{5}{a} - \frac{8}{a} = \frac{5-8}{a} = \frac{-3}{a} = -\frac{3}{a}\]

  2. The denominator is zero when \(a = 0\).

Q5

A student writes the work below. Explain the mistake, then give the correct sum.

\[\frac{3}{x} + \frac{4}{x} = \frac{7}{2x}\]
Answer

\(\dfrac{7}{x}, \; x \neq 0\)

  1. The student added the denominators. Both terms count copies of \(\dfrac{1}{x}\), so the denominator stays \(x\).

    \[\frac{3}{x} + \frac{4}{x} = \frac{3+4}{x} = \frac{7}{x}\]

  2. Check with \(x = 1\): the left side is \(3 + 4 = 7\). The correct answer gives \(\dfrac{7}{1} = 7\); the student's answer gives \(\dfrac{7}{2} = 3.5\).

Which value is excluded?

Before you add, look at the shared denominator and ask which value makes it zero. In \(\frac{x}{x-4} + \frac{1}{x-4}\), both denominators are \(x - 4\), which equals zero at \(x = 4\). Since division by zero is undefined, neither original fraction exists at \(x = 4\), so that value is excluded from the start.

Set the denominator equal to zero and solve to find the excluded value. Linear denominators such as \(2x + 5\) can give fractional values like \(x = -\frac{5}{2}\). Quadratic denominators can give two values: factor and use the zero product property. A value that makes only the numerator zero is allowed. Write the restriction next to the answer: \(\frac{x+1}{x-4}, \; x \neq 4\).

Q6

Find the excluded value, then add.

\[\frac{x}{x+6} + \frac{5}{x+6}\]
Answer

\(\dfrac{x+5}{x+6}, \; x \neq -6\)

  1. Set the common denominator equal to zero.

    \[x + 6 = 0 \;\Rightarrow\; x = -6\]

  2. Add the numerators over the common denominator.

    \[\frac{x+5}{x+6}, \quad x \neq -6\]

Q7

Find the excluded value, add, and simplify.

\[\frac{2}{3x-12} + \frac{7}{3x-12}\]
Answer

\(\dfrac{3}{x-4}, \; x \neq 4\)

  1. Set the denominator equal to zero.

    \[3x - 12 = 0 \;\Rightarrow\; 3x = 12 \;\Rightarrow\; x = 4\]

  2. Add the numerators.

    \[\frac{2+7}{3x-12} = \frac{9}{3x-12}\]

  3. Factor 3 out of the denominator and cancel it with the 9.

    \[\frac{9}{3(x-4)} = \frac{3}{x-4}, \quad x \neq 4\]

Q8

Find both excluded values, then add.

\[\frac{x+1}{x^2-16} + \frac{2}{x^2-16}\]
Answer

\(\dfrac{x+3}{x^2-16}, \; x \neq 4 \text{ and } x \neq -4\)

  1. Factor the denominator as a difference of squares.

    \[x^2 - 16 = (x-4)(x+4)\]

  2. Each factor gives an excluded value.

    \[x = 4 \quad \text{or} \quad x = -4\]

  3. Add the numerators. The numerator \(x + 3\) shares no factor with the denominator, so the answer is simplified.

    \[\frac{x+3}{x^2-16}, \quad x \neq \pm 4\]

Q9

Find the excluded value, then subtract.

\[\frac{4x}{2x+5} - \frac{1}{2x+5}\]
Answer

\(\dfrac{4x-1}{2x+5}, \; x \neq -\tfrac{5}{2}\)

  1. Set the denominator equal to zero.

    \[2x + 5 = 0 \;\Rightarrow\; 2x = -5 \;\Rightarrow\; x = -\tfrac{5}{2}\]

  2. Subtract the numerators over the common denominator.

    \[\frac{4x-1}{2x+5}, \quad x \neq -\tfrac{5}{2}\]

Q10

Is \(x = 0\) excluded from the expression below? Add, then evaluate the sum at \(x = 0\).

\[\frac{x}{x-1} + \frac{3}{x-1}\]
Answer

\(\dfrac{x+3}{x-1}, \; x \neq 1; \text{ at } x = 0 \text{ the value is } -3\)

  1. Only the denominator decides what is excluded. \(x - 1 = 0\) gives \(x = 1\), so \(x = 0\) is allowed.

    \[x - 1 = 0 \;\Rightarrow\; x = 1\]

  2. Add the numerators.

    \[\frac{x+3}{x-1}, \quad x \neq 1\]

  3. Evaluate at \(x = 0\).

    \[\frac{0+3}{0-1} = \frac{3}{-1} = -3\]

Add polynomial numerators

When the numerators are polynomials, put each one in parentheses over the common denominator, then combine like terms. For \(\frac{2x+3}{x+5} + \frac{x+4}{x+5}\), write \(\frac{(2x+3)+(x+4)}{x+5}\). The \(x\)-terms combine to \(3x\) and the constants to \(7\), giving \(\frac{3x+7}{x+5}\).

The parentheses matter little for addition, but they build the habit you need for subtraction. Combine only like terms: \(x^2\) with \(x^2\), \(x\) with \(x\), constants with constants. After combining, try to factor the numerator; if it shares a factor with the denominator, cancel it. If not, the answer is complete. A denominator such as \(x^2 + 1\) is never zero for real \(x\), so it has no excluded value.

Q11

Add and state the restriction.

\[\frac{3x+1}{x+2} + \frac{x+6}{x+2}\]
Answer

\(\dfrac{4x+7}{x+2}, \; x \neq -2\)

  1. Group the numerators over the common denominator.

    \[\frac{(3x+1)+(x+6)}{x+2}\]

  2. Combine like terms: \(3x + x = 4x\) and \(1 + 6 = 7\).

    \[\frac{4x+7}{x+2}, \quad x \neq -2\]

Q12

Add and state the restriction.

\[\frac{x^2+2x}{x-5} + \frac{3x-1}{x-5}\]
Answer

\(\dfrac{x^2+5x-1}{x-5}, \; x \neq 5\)

  1. Group the numerators.

    \[\frac{(x^2+2x)+(3x-1)}{x-5}\]

  2. Combine like terms: the \(x^2\) term stays, \(2x + 3x = 5x\), and the constant is \(-1\).

    \[\frac{x^2+5x-1}{x-5}\]

  3. \(x^2 + 5x - 1\) does not factor over the integers, so nothing cancels. The restriction is \(x \neq 5\).

Q13

Add and state the restriction.

\[\frac{5x-2}{2x+1} + \frac{x+9}{2x+1}\]
Answer

\(\dfrac{6x+7}{2x+1}, \; x \neq -\tfrac{1}{2}\)

  1. Group and combine the numerators: \(5x + x = 6x\), \(-2 + 9 = 7\).

    \[\frac{(5x-2)+(x+9)}{2x+1} = \frac{6x+7}{2x+1}\]

  2. The denominator is zero when \(2x + 1 = 0\), so \(x = -\tfrac{1}{2}\) is excluded.

Q14

Add. Does this expression have an excluded value?

\[\frac{x^2-3}{x^2+1} + \frac{2x^2+x}{x^2+1}\]
Answer

\(\dfrac{3x^2+x-3}{x^2+1}; \text{ no excluded value}\)

  1. Combine like terms: \(x^2 + 2x^2 = 3x^2\), the \(x\)-term is \(x\), the constant is \(-3\).

    \[\frac{(x^2-3)+(2x^2+x)}{x^2+1} = \frac{3x^2+x-3}{x^2+1}\]

  2. \(x^2\) is never negative, so \(x^2 + 1 \ge 1\). The denominator is never zero, and every real number is allowed.

Q15

Add and state the restriction.

\[\frac{4a+5b}{a-b} + \frac{2a-3b}{a-b}\]
Answer

\(\dfrac{6a+2b}{a-b}, \; a \neq b\)

  1. Combine the \(a\)-terms and the \(b\)-terms separately: \(4a + 2a = 6a\), \(5b - 3b = 2b\).

    \[\frac{(4a+5b)+(2a-3b)}{a-b} = \frac{6a+2b}{a-b}\]

  2. The numerator factors as \(2(3a + b)\), which shares no factor with \(a - b\). The denominator is zero when \(a = b\).

Subtract the entire numerator

The minus sign in front of a fraction applies to its whole numerator, not just the first term. Put the second numerator in parentheses: \(\frac{5x+4}{x-2} - \frac{2x-3}{x-2} = \frac{(5x+4)-(2x-3)}{x-2}\). Then distribute the minus sign to every term inside: \(-(2x - 3) = -2x + 3\).

Now combine like terms: \(5x + 4 - 2x + 3 = 3x + 7\), so the answer is \(\frac{3x+7}{x-2}, \; x \neq 2\). The most common error is writing \(5x + 4 - 2x - 3\), which changes only the first sign. A good habit is to rewrite subtraction as adding the opposite: subtracting \(2x - 3\) is the same as adding \(-2x + 3\). After combining, factor the numerator and cancel if possible.

Q16

Subtract, simplify, and state the restriction.

\[\frac{7x+2}{x-3} - \frac{4x+5}{x-3}\]
Answer

\(\dfrac{3(x-1)}{x-3}, \; x \neq 3\)

  1. Group the second numerator and distribute the minus sign.

    \[\frac{(7x+2)-(4x+5)}{x-3} = \frac{7x+2-4x-5}{x-3}\]

  2. Combine like terms.

    \[\frac{3x-3}{x-3}\]

  3. Factor the numerator. \(3(x - 1)\) shares no factor with \(x - 3\), so nothing cancels.

    \[\frac{3(x-1)}{x-3}, \quad x \neq 3\]

Q17

Subtract and state the restriction.

\[\frac{6x-1}{x+4} - \frac{2x-9}{x+4}\]
Answer

\(\dfrac{4(x+2)}{x+4}, \; x \neq -4\)

  1. Distribute the minus sign: \(-(2x - 9) = -2x + 9\).

    \[\frac{6x-1-2x+9}{x+4} = \frac{4x+8}{x+4}\]

  2. Factor the numerator: \(4x + 8 = 4(x + 2)\). It shares no factor with \(x + 4\).

    \[\frac{4(x+2)}{x+4}, \quad x \neq -4\]

Q18

Subtract and state the restriction.

\[\frac{x^2+3x}{x+7} - \frac{x^2-2x+4}{x+7}\]
Answer

\(\dfrac{5x-4}{x+7}, \; x \neq -7\)

  1. Distribute the minus sign to all three terms of the second numerator.

    \[\frac{x^2+3x-x^2+2x-4}{x+7}\]

  2. The \(x^2\) terms cancel; \(3x + 2x = 5x\).

    \[\frac{5x-4}{x+7}, \quad x \neq -7\]

Q19

Subtract and state the restriction.

\[\frac{3x-8}{2x+3} - \frac{-x-5}{2x+3}\]
Answer

\(\dfrac{4x-3}{2x+3}, \; x \neq -\tfrac{3}{2}\)

  1. Subtracting \(-x - 5\) means adding \(x + 5\).

    \[\frac{3x-8-(-x-5)}{2x+3} = \frac{3x-8+x+5}{2x+3}\]

  2. Combine like terms.

    \[\frac{4x-3}{2x+3}, \quad x \neq -\tfrac{3}{2}\]

Q20

Subtract and write the numerator in factored form.

\[\frac{5-x}{x-6} - \frac{2x-7}{x-6}\]
Answer

\(\dfrac{-3(x-4)}{x-6}, \; x \neq 6\)

  1. Distribute the minus sign: \(-(2x - 7) = -2x + 7\).

    \[\frac{5-x-2x+7}{x-6} = \frac{12-3x}{x-6}\]

  2. Factor out \(-3\) so the variable term is positive inside the parentheses.

    \[\frac{-3(x-4)}{x-6}, \quad x \neq 6\]

  3. Check at \(x = 0\): original \(\dfrac{5}{-6} - \dfrac{-7}{-6} = \dfrac{-5-7}{6} = -2\); answer \(\dfrac{-3(-4)}{-6} = -2\).

Factor after subtracting

After you combine numerators, always check whether the new numerator factors. In \(\frac{x^2}{x-3} - \frac{9}{x-3}\), the combined numerator is \(x^2 - 9\), a difference of squares: \((x-3)(x+3)\). The factor \(x - 3\) matches the denominator, so it cancels and the result is \(x + 3\).

The restriction does not disappear when the factor cancels. At \(x = 3\) the original denominator is zero, so the answer is \(x + 3, \; x \neq 3\). Look for a GCF first, then a difference of squares or a trinomial. Sometimes the whole expression simplifies to a constant, such as \(\frac{4x-12}{2x-6} = 2\); the restriction still applies.

Q21

Subtract, simplify, and state the restriction.

\[\frac{x^2}{x+5} - \frac{25}{x+5}\]
Answer

\(x - 5, \; x \neq -5\)

  1. Subtract the numerators.

    \[\frac{x^2-25}{x+5}\]

  2. Factor the difference of squares and cancel \(x + 5\).

    \[\frac{(x-5)(x+5)}{x+5} = x - 5\]

  3. The original denominator is zero at \(x = -5\), so \(x \neq -5\).

Q22

Subtract, simplify, and state the restriction.

\[\frac{x^2+4x}{x-2} - \frac{x+10}{x-2}\]
Answer

\(x + 5, \; x \neq 2\)

  1. Distribute the minus sign and combine.

    \[\frac{x^2+4x-x-10}{x-2} = \frac{x^2+3x-10}{x-2}\]

  2. Factor the trinomial: 5 and \(-2\) multiply to \(-10\) and add to 3.

    \[\frac{(x+5)(x-2)}{x-2}\]

  3. Cancel \(x - 2\).

    \[x + 5, \quad x \neq 2\]

Q23

Add, simplify, and state the restriction.

\[\frac{x^2+2x}{x+4} + \frac{6x+16}{x+4}\]
Answer

\(x + 4, \; x \neq -4\)

  1. Add the numerators.

    \[\frac{x^2+8x+16}{x+4}\]

  2. The numerator is a perfect-square trinomial.

    \[\frac{(x+4)^2}{x+4} = x + 4\]

  3. The original denominator is zero at \(x = -4\).

    \[x + 4, \quad x \neq -4\]

Q24

Subtract, simplify, and state both restrictions.

\[\frac{3x+5}{x^2-1} - \frac{2x+6}{x^2-1}\]
Answer

\(\dfrac{1}{x+1}, \; x \neq 1 \text{ and } x \neq -1\)

  1. Distribute the minus sign and combine.

    \[\frac{3x+5-2x-6}{x^2-1} = \frac{x-1}{x^2-1}\]

  2. Factor the denominator and cancel \(x - 1\).

    \[\frac{x-1}{(x-1)(x+1)} = \frac{1}{x+1}\]

  3. Both factors of the original denominator give restrictions: \(x \neq 1\) and \(x \neq -1\).

Q25

Subtract, simplify, and state the restriction.

\[\frac{4x}{2x-6} - \frac{12}{2x-6}\]
Answer

\(2, \; x \neq 3\)

  1. Subtract the numerators.

    \[\frac{4x-12}{2x-6}\]

  2. Factor the GCF from each part.

    \[\frac{4(x-3)}{2(x-3)}\]

  3. Cancel \(x - 3\) and reduce \(\dfrac{4}{2}\). The expression equals 2 for every allowed \(x\).

    \[2, \quad x \neq 3\]

Combine three rational expressions

Three or more fractions with the same denominator combine into one fraction. Put every numerator in parentheses, keeping the sign in front of each: \(\frac{(3x+2)-(x-4)+(2x+1)}{x+1}\). Each minus sign applies only to the numerator immediately after it.

Distribute each sign, then combine like terms in two groups. The \(x\)-terms give \(3x - x + 2x = 4x\) and the constants give \(2 + 4 + 1 = 7\), so the answer is \(\frac{4x+7}{x+1}, \; x \neq -1\). Work left to right and underline the terms whose signs changed. As always, factor the final numerator to see whether anything cancels with the denominator.

Q26

Combine and state the restriction.

\[\frac{2x+5}{x+3} + \frac{x-1}{x+3} - \frac{x+2}{x+3}\]
Answer

\(\dfrac{2(x+1)}{x+3}, \; x \neq -3\)

  1. Group the numerators, keeping each sign.

    \[\frac{(2x+5)+(x-1)-(x+2)}{x+3}\]

  2. Distribute the minus sign: \(-(x + 2) = -x - 2\).

    \[\frac{2x+5+x-1-x-2}{x+3}\]

  3. Combine: \(2x + x - x = 2x\) and \(5 - 1 - 2 = 2\). Factor the numerator.

    \[\frac{2x+2}{x+3} = \frac{2(x+1)}{x+3}, \quad x \neq -3\]

Q27

Combine and state the restriction.

\[\frac{5x}{x-4} - \frac{2x+3}{x-4} - \frac{x-7}{x-4}\]
Answer

\(\dfrac{2(x+2)}{x-4}, \; x \neq 4\)

  1. Distribute both minus signs.

    \[\frac{5x-2x-3-x+7}{x-4}\]

  2. Combine: \(5x - 2x - x = 2x\) and \(-3 + 7 = 4\).

    \[\frac{2x+4}{x-4} = \frac{2(x+2)}{x-4}, \quad x \neq 4\]

Q28

Combine and state the restriction.

\[\frac{x^2+1}{x+2} - \frac{3x-5}{x+2} + \frac{4x-2}{x+2}\]
Answer

\(\dfrac{x^2+x+4}{x+2}, \; x \neq -2\)

  1. Distribute the minus sign: \(-(3x - 5) = -3x + 5\).

    \[\frac{x^2+1-3x+5+4x-2}{x+2}\]

  2. Combine: \(-3x + 4x = x\) and \(1 + 5 - 2 = 4\).

    \[\frac{x^2+x+4}{x+2}\]

  3. \(x^2 + x + 4\) does not factor, and at \(x = -2\) it equals 6, not 0, so \(x + 2\) is not a factor. The answer is complete.

Q29

Combine and state the restriction.

\[\frac{4x+1}{x-1} - \frac{x+5}{x-1} - \frac{2x-5}{x-1}\]
Answer

\(\dfrac{x+1}{x-1}, \; x \neq 1\)

  1. Distribute both minus signs.

    \[\frac{4x+1-x-5-2x+5}{x-1}\]

  2. Combine: \(4x - x - 2x = x\) and \(1 - 5 + 5 = 1\).

    \[\frac{x+1}{x-1}, \quad x \neq 1\]

Q30

Combine, simplify, and state the restriction.

\[\frac{x^2+4}{x+1} + \frac{5x-1}{x+1} - \frac{2x+1}{x+1}\]
Answer

\(x + 2, \; x \neq -1\)

  1. Distribute the minus sign and combine.

    \[\frac{x^2+4+5x-1-2x-1}{x+1} = \frac{x^2+3x+2}{x+1}\]

  2. Factor: 1 and 2 multiply to 2 and add to 3.

    \[\frac{(x+1)(x+2)}{x+1}\]

  3. Cancel \(x + 1\); the restriction stays.

    \[x + 2, \quad x \neq -1\]

Spot the subtraction mistake

In \(\frac{4x+1}{x+3} - \frac{x-5}{x+3}\), the student subtracted \(x\) but also subtracted 5, writing \(4x + 1 - x - 5 = 3x - 4\). Subtracting \(x - 5\) removes the \(x\) and gives back the 5: \(-(x - 5) = -x + 5\). The correct numerator is \(4x + 1 - x + 5 = 3x + 6\), so the answer is \(\frac{3x+6}{x+3}, \; x \neq -3\).

To check any answer, substitute an allowed number. At \(x = 0\), the original is \(\frac{1}{3} - \frac{-5}{3} = \frac{6}{3} = 2\). The correct answer gives \(\frac{6}{3} = 2\), but the student’s gives \(\frac{-4}{3}\). Other common errors: subtracting the denominators, distributing the sign to only one numerator in a three-term problem, and forgetting the restriction after canceling.

Q31

Find and fix the mistake.

\[\frac{6x+5}{x+2} - \frac{2x+3}{x+2} = \frac{4x+8}{x+2}\]
Answer

\(\dfrac{4x+2}{x+2}, \; x \neq -2\)

  1. The student added the 3 instead of subtracting it. Distribute the minus sign: \(-(2x + 3) = -2x - 3\).

    \[6x + 5 - 2x - 3 = 4x + 2\]

  2. The correct answer:

    \[\frac{4x+2}{x+2} = \frac{2(2x+1)}{x+2}, \quad x \neq -2\]

  3. Check at \(x = 0\): \(\dfrac{5}{2} - \dfrac{3}{2} = 1\), and \(\dfrac{2}{2} = 1\). The student's answer gives 4.

Q32

Find and fix the mistake.

\[\frac{3x-1}{x-4} - \frac{x-6}{x-4} = \frac{2x-7}{x-4}\]
Answer

\(\dfrac{2x+5}{x-4}, \; x \neq 4\)

  1. The student subtracted the 6 again. Subtracting \(-6\) adds 6: \(-(x - 6) = -x + 6\).

    \[3x - 1 - x + 6 = 2x + 5\]

  2. The correct answer:

Q33

A student wrote the work below. Find the error and give the correct answer.

\[\frac{x^2+2x}{x+5} - \frac{x^2-3x}{x+5} = \frac{-x}{x+5}\]
Answer

\(\dfrac{5x}{x+5}, \; x \neq -5\)

  1. The student wrote \(2x - 3x = -x\), changing only the \(x^2\) sign. Distribute the minus sign to both terms: \(-(x^2 - 3x) = -x^2 + 3x\).

    \[x^2 + 2x - x^2 + 3x = 5x\]

  2. The correct answer:

    \[\frac{5x}{x+5}, \quad x \neq -5\]

Q34

A student says the expression below equals 1 for every value of \(x\). What is missing?

\[\frac{x+4}{x-1} - \frac{5}{x-1} = \frac{x-1}{x-1} = 1\]
Answer

\(1, \; x \neq 1\)

  1. The arithmetic is correct: \(x + 4 - 5 = x - 1\), and \(\dfrac{x-1}{x-1} = 1\).

  2. The restriction is missing. At \(x = 1\), the original denominators are zero, so the expression is undefined there, not equal to 1.

    \[1, \quad x \neq 1\]

Q35

Find and fix the mistake.

\[\frac{5x+2}{x+6} - \frac{3x-4}{x+6} + \frac{x+1}{x+6} = \frac{3x-1}{x+6}\]
Answer

\(\dfrac{3x+7}{x+6}, \; x \neq -6\)

  1. The student wrote \(-4\) instead of \(+4\). Distribute the minus sign: \(-(3x - 4) = -3x + 4\).

    \[5x + 2 - 3x + 4 + x + 1 = 3x + 7\]

  2. The correct answer:

    \[\frac{3x+7}{x+6}, \quad x \neq -6\]

  3. Check at \(x = 0\): \(\dfrac{2}{6} + \dfrac{4}{6} + \dfrac{1}{6} = \dfrac{7}{6}\), which matches \(\dfrac{7}{6}\).

Split the math club bill

When a total is shared equally by \(n\) people, each person’s share is the total divided by \(n\). If supplies cost \(3n + 12\) dollars and a coupon saves \(n + 2\) dollars, each student pays their share of the cost minus their share of the savings: \(\frac{3n+12}{n} - \frac{n+2}{n} = \frac{2n+10}{n}\).

Splitting the fraction term by term can make the answer easier to read: \(\frac{2n+10}{n} = \frac{2n}{n} + \frac{10}{n} = 2 + \frac{10}{n}\). Each student pays 2 dollars plus a share of a 10-dollar fixed cost. With 10 students, that is \(2 + 1 = 3\) dollars. In context, \(n\) counts people, so it is a positive whole number and \(n \neq 0\) is automatic. Always finish by substituting the given value and including units.

Practice: try these five questions

Q36

A class party costs \(5n + 40\) dollars. A PTA grant covers \(n + 8\) dollars. The \(n\) students split the rest equally. Write each student's cost in simplest form, then find it for 8 students.

Answer

\(4 + \dfrac{32}{n} \text{ dollars}; \; \$8 \text{ for 8 students}\)

  1. Subtract the shares over the common denominator \(n\).

    \[\frac{5n+40}{n} - \frac{n+8}{n} = \frac{5n+40-n-8}{n} = \frac{4n+32}{n}\]

  2. Split the fraction term by term.

    \[\frac{4n}{n} + \frac{32}{n} = 4 + \frac{32}{n}\]

  3. Substitute \(n = 8\).

    \[4 + \frac{32}{8} = 4 + 4 = 8 \text{ dollars}\]

Q37

Over \(d\) days, Class A collects \(5d + 12\) cans and Class B collects \(2d + 3\) cans. How many more cans per day does Class A average? Find the value for \(d = 3\).

Answer

\(\dfrac{3(d+3)}{d} \text{ cans per day}; \; 6 \text{ when } d = 3\)

  1. Each class's daily average is its total divided by \(d\). Subtract.

    \[\frac{5d+12}{d} - \frac{2d+3}{d} = \frac{5d+12-2d-3}{d} = \frac{3d+9}{d}\]

  2. Factor: \(\dfrac{3(d+3)}{d}\). Substitute \(d = 3\).

    \[\frac{3(3+3)}{3} = \frac{18}{3} = 6 \text{ cans per day}\]

Q38

A rectangle has length \(\dfrac{2x+1}{x+3}\) meters and width \(\dfrac{x+5}{x+3}\) meters, with \(x > 0\). Write the perimeter in simplest form.

Answer

\(\dfrac{6(x+2)}{x+3} \text{ meters}\)

  1. Perimeter is twice the sum of length and width. Add first.

    \[\frac{2x+1}{x+3} + \frac{x+5}{x+3} = \frac{3x+6}{x+3}\]

  2. Double it and factor.

    \[2 \cdot \frac{3x+6}{x+3} = \frac{6x+12}{x+3} = \frac{6(x+2)}{x+3}\]

  3. Check at \(x = 1\): length \(\dfrac{3}{4}\), width \(\dfrac{6}{4}\), perimeter \(2 \cdot \dfrac{9}{4} = 4.5\); formula \(\dfrac{18}{4} = 4.5\).

Q39

A tank holds \(\dfrac{8x+20}{x+2}\) liters. Then \(\dfrac{3x+10}{x+2}\) liters drain out, with \(x > 0\). How much water is left?

Answer

\(5 \text{ liters}\)

  1. Subtract the amounts.

    \[\frac{8x+20}{x+2} - \frac{3x+10}{x+2} = \frac{8x+20-3x-10}{x+2} = \frac{5x+10}{x+2}\]

  2. Factor and cancel.

    \[\frac{5(x+2)}{x+2} = 5\]

  3. Exactly 5 liters remain, whatever the value of \(x\).

Q40

Pipe A fills \(\dfrac{3}{t}\) of a pool per hour and Pipe B fills \(\dfrac{5}{t}\) of the pool per hour. What fraction do they fill together in one hour? If \(t = 16\), how long do they take to fill the pool?

Answer

\(\dfrac{8}{t} \text{ per hour}; \; 2 \text{ hours when } t = 16\)

  1. Add the rates.

    \[\frac{3}{t} + \frac{5}{t} = \frac{8}{t}\]

  2. With \(t = 16\), they fill \(\dfrac{8}{16} = \dfrac{1}{2}\) of the pool per hour.

    \[\frac{8}{16} = \frac{1}{2}\]

  3. Half a pool each hour fills the whole pool in 2 hours.

Homework review

One review question for each topic, in image order. Keep the common denominator, distribute every minus sign, factor the result, and state the restriction from the original expression.

R1

Add, simplify, and state the restriction.

\[\frac{5}{3x} + \frac{7}{3x}\]
Answer

\(\dfrac{4}{x}, \; x \neq 0\)

  1. Add the numerators over \(3x\).

    \[\frac{5+7}{3x} = \frac{12}{3x}\]

  2. Cancel the common factor 3.

    \[\frac{4}{x}, \quad x \neq 0\]

R2

Find the excluded value, then subtract.

\[\frac{2x}{x+9} - \frac{3}{x+9}\]
Answer

\(\dfrac{2x-3}{x+9}, \; x \neq -9\)

  1. The denominator is zero at \(x = -9\).

    \[x + 9 = 0 \;\Rightarrow\; x = -9\]

  2. Subtract the numerators. The value \(x = \tfrac{3}{2}\) makes the numerator zero but is allowed.

    \[\frac{2x-3}{x+9}, \quad x \neq -9\]

R3

Add and state the restriction.

\[\frac{x^2-4x}{x+1} + \frac{2x+7}{x+1}\]
Answer

\(\dfrac{x^2-2x+7}{x+1}, \; x \neq -1\)

  1. Combine like terms: \(-4x + 2x = -2x\).

    \[\frac{x^2-2x+7}{x+1}\]

  2. At \(x = -1\) the numerator is \(1 + 2 + 7 = 10\), so \(x + 1\) is not a factor. The restriction is \(x \neq -1\).

R4

Subtract and state the restriction.

\[\frac{9x-2}{3x-1} - \frac{6x-3}{3x-1}\]
Answer

\(\dfrac{3x+1}{3x-1}, \; x \neq \tfrac{1}{3}\)

  1. Distribute the minus sign: \(-(6x - 3) = -6x + 3\).

    \[\frac{9x-2-6x+3}{3x-1} = \frac{3x+1}{3x-1}\]

  2. The denominator is zero at \(x = \tfrac{1}{3}\).

R5

Subtract, simplify, and state the restriction.

\[\frac{x^2+6x}{x-1} - \frac{7}{x-1}\]
Answer

\(x + 7, \; x \neq 1\)

  1. Subtract the numerators.

    \[\frac{x^2+6x-7}{x-1}\]

  2. Factor: 7 and \(-1\) multiply to \(-7\) and add to 6. Cancel \(x - 1\).

    \[\frac{(x+7)(x-1)}{x-1} = x + 7, \quad x \neq 1\]

R6

Combine, simplify, and state the restriction.

\[\frac{3x+4}{x-5} - \frac{x-2}{x-5} + \frac{x-21}{x-5}\]
Answer

\(3, \; x \neq 5\)

  1. Distribute the minus sign and combine.

    \[\frac{3x+4-x+2+x-21}{x-5} = \frac{3x-15}{x-5}\]

  2. Factor and cancel.

    \[\frac{3(x-5)}{x-5} = 3, \quad x \neq 5\]

R7

Find and fix the mistake.

\[\frac{7x-3}{x+8} - \frac{4x-6}{x+8} = \frac{3x-9}{x+8}\]
Answer

\(\dfrac{3(x+1)}{x+8}, \; x \neq -8\)

  1. The student subtracted the 6 instead of adding it. \(-(4x - 6) = -4x + 6\).

    \[7x - 3 - 4x + 6 = 3x + 3\]

  2. The correct answer:

    \[\frac{3x+3}{x+8} = \frac{3(x+1)}{x+8}, \quad x \neq -8\]

R8

A field trip costs \(12n + 90\) dollars. A grant covers \(2n + 30\) dollars, and the \(n\) students split the rest equally. Write each student's cost in simplest form and find it for 20 students.

Answer

\(10 + \dfrac{60}{n} \text{ dollars}; \; \$13 \text{ for 20 students}\)

  1. Subtract the shares.

    \[\frac{12n+90}{n} - \frac{2n+30}{n} = \frac{10n+60}{n}\]

  2. Split the fraction.

    \[10 + \frac{60}{n}\]

  3. Substitute \(n = 20\).

    \[10 + \frac{60}{20} = 10 + 3 = 13 \text{ dollars}\]

Homework word problems

Twelve word problems that build from direct setups to a challenge. Translate the situation into a sum or difference over a common denominator, simplify, and check your answer with a number.

W1

Lena runs \(\dfrac{5}{k}\) kilometers on Monday and \(\dfrac{7}{k}\) kilometers on Tuesday. Write her total distance in simplest form, then find it when \(k = 4\).

Answer

\(\dfrac{12}{k} \text{ km}; \; 3 \text{ km when } k = 4\)

  1. Add the distances.

    \[\frac{5}{k} + \frac{7}{k} = \frac{12}{k}\]

  2. Substitute \(k = 4\).

    \[\frac{12}{4} = 3 \text{ km}\]

W2

A board is \(\dfrac{7x+4}{x+1}\) feet long. A piece \(\dfrac{2x-1}{x+1}\) feet long is cut off, with \(x > 1\). How long is the remaining board?

Answer

\(5 \text{ feet}\)

  1. Subtract, distributing the minus sign.

    \[\frac{7x+4-2x+1}{x+1} = \frac{5x+5}{x+1}\]

  2. Factor and cancel.

    \[\frac{5(x+1)}{x+1} = 5 \text{ feet}\]

W3

A triangle has sides \(\dfrac{x+2}{x+4}\), \(\dfrac{2x+3}{x+4}\), and \(\dfrac{x+3}{x+4}\) inches, with \(x > 0\). Write the perimeter in simplest form and evaluate it when \(x = 2\).

Answer

\(\dfrac{4(x+2)}{x+4} \text{ in}; \; \tfrac{8}{3} \text{ in when } x = 2\)

  1. Add all three sides.

    \[\frac{(x+2)+(2x+3)+(x+3)}{x+4} = \frac{4x+8}{x+4} = \frac{4(x+2)}{x+4}\]

  2. Substitute \(x = 2\).

    \[\frac{4(4)}{6} = \frac{16}{6} = \frac{8}{3} \text{ in}\]

W4

A club earns \(6n + 40\) dollars at a bake sale and \(2n + 20\) dollars at a car wash. The \(n\) members share the earnings equally. Write each member's share in simplest form and find it for 12 members.

Answer

\(8 + \dfrac{60}{n} \text{ dollars}; \; \$13 \text{ for 12 members}\)

  1. Add each member's share of both events.

    \[\frac{6n+40}{n} + \frac{2n+20}{n} = \frac{8n+60}{n}\]

  2. Split and substitute \(n = 12\).

    \[8 + \frac{60}{n} \;\Rightarrow\; 8 + \frac{60}{12} = 8 + 5 = 13 \text{ dollars}\]

W5

Jamal walks \(\dfrac{3x+2}{x}\) miles and Sofia walks \(\dfrac{x+8}{x}\) miles, with \(x > 0\). How much farther does Jamal walk? Evaluate at \(x = 6\), and find the value of \(x\) for which they walk the same distance.

Answer

\(\dfrac{2(x-3)}{x} \text{ miles}; \; 1 \text{ mile at } x = 6; \; \text{equal at } x = 3\)

  1. Subtract Sofia's distance from Jamal's.

    \[\frac{3x+2}{x} - \frac{x+8}{x} = \frac{3x+2-x-8}{x} = \frac{2x-6}{x}\]

  2. At \(x = 6\):

    \[\frac{2(6)-6}{6} = \frac{6}{6} = 1 \text{ mile}\]

  3. They walk the same distance when the difference is zero: \(2x - 6 = 0\), so \(x = 3\).

W6

Water flows into a tank at \(\dfrac{5x+12}{x+3}\) gallons per minute and drains out at \(\dfrac{2x+3}{x+3}\) gallons per minute, with \(x > 0\). Find the net rate at which the tank fills.

Answer

\(3 \text{ gallons per minute}\)

  1. Net rate is inflow minus outflow.

    \[\frac{5x+12-2x-3}{x+3} = \frac{3x+9}{x+3}\]

  2. Factor and cancel.

    \[\frac{3(x+3)}{x+3} = 3 \text{ gallons per minute}\]

W7

Find the average of \(\dfrac{x+7}{x-2}\) and \(\dfrac{3x-11}{x-2}\). State the restriction.

Answer

\(\dfrac{2(x-1)}{x-2}, \; x \neq 2\)

  1. Add the two expressions.

    \[\frac{x+7+3x-11}{x-2} = \frac{4x-4}{x-2}\]

  2. Divide by 2 to average.

    \[\frac{4x-4}{2(x-2)} = \frac{2x-2}{x-2} = \frac{2(x-1)}{x-2}, \quad x \neq 2\]

W8

Each of \(m\) friends has a budget of \(\dfrac{9m+5}{m}\) dollars and spends \(\dfrac{4m-3}{m}\) dollars. A student writes the amount left as \(\dfrac{5m+2}{m}\). Find the error, correct it, and find the amount left when \(m = 4\).

Answer

\(\dfrac{5m+8}{m} \text{ dollars}; \; \$7 \text{ when } m = 4\)

  1. The student subtracted the 3 instead of adding it. \(-(4m - 3) = -4m + 3\).

    \[\frac{9m+5-4m+3}{m} = \frac{5m+8}{m}\]

  2. Substitute \(m = 4\).

    \[\frac{5(4)+8}{4} = \frac{28}{4} = 7 \text{ dollars}\]

W9

A garden is split into two rectangular beds that share a width of \(x + 2\) meters, with \(x > 0\). The beds have areas \(x^2 + 5x\) and \(2x + 10\) square meters. Write the total length of the garden in simplest form.

Answer

\(x + 5 \text{ meters}\)

  1. Each bed's length is its area divided by the width. Add the lengths.

    \[\frac{x^2+5x}{x+2} + \frac{2x+10}{x+2} = \frac{x^2+7x+10}{x+2}\]

  2. Factor: 2 and 5 multiply to 10 and add to 7. Cancel \(x + 2\).

    \[\frac{(x+2)(x+5)}{x+2} = x + 5 \text{ meters}\]

  3. Check at \(x = 1\): lengths \(\dfrac{6}{3} = 2\) and \(\dfrac{12}{3} = 4\), total 6; formula \(1 + 5 = 6\).

W10

A shop's revenue per item is \(\dfrac{x^2+9x}{x+6}\) dollars and its cost per item is \(\dfrac{x-12}{x+6}\) dollars, with \(x > 12\). Write the profit per item in simplest form, then find it when \(x = 15\).

Answer

\(x + 2 \text{ dollars}; \; \$17 \text{ when } x = 15\)

  1. Profit is revenue minus cost.

    \[\frac{x^2+9x-x+12}{x+6} = \frac{x^2+8x+12}{x+6}\]

  2. Factor: 6 and 2 multiply to 12 and add to 8. Cancel \(x + 6\).

    \[\frac{(x+6)(x+2)}{x+6} = x + 2\]

  3. At \(x = 15\): \(15 + 2 = 17\) dollars.

W11

Over \(w\) weeks, a library receives \(6w + 15\) new books, lends out \(2w + 3\) books, and gets back \(w + 6\) books. Write the average weekly change in books on its shelves, then evaluate it for \(w = 6\).

Answer

\(\dfrac{5w+18}{w} \text{ books per week}; \; 8 \text{ when } w = 6\)

  1. Books received and returned add; books lent subtract.

    \[\frac{6w+15}{w} - \frac{2w+3}{w} + \frac{w+6}{w}\]

  2. Distribute the minus sign and combine.

    \[\frac{6w+15-2w-3+w+6}{w} = \frac{5w+18}{w}\]

  3. Substitute \(w = 6\).

    \[\frac{30+18}{6} = \frac{48}{6} = 8 \text{ books per week}\]

W12

Challenge: find the value of \(k\) for which the expression below simplifies to \(x + 5\). State the restriction.

\[\frac{x^2+kx}{x-3} - \frac{2x+15}{x-3}\]
Answer

\(k = 4, \; x \neq 3\)

  1. Combine the numerators.

    \[\frac{x^2+kx-2x-15}{x-3} = \frac{x^2+(k-2)x-15}{x-3}\]

  2. For the result to be \(x + 5\), the numerator must equal \((x - 3)(x + 5)\).

    \[(x-3)(x+5) = x^2 + 2x - 15\]

  3. Match the \(x\)-coefficients: \(k - 2 = 2\), so \(k = 4\). Check: \(\dfrac{x^2+2x-15}{x-3} = \dfrac{(x-3)(x+5)}{x-3} = x + 5\), with \(x \neq 3\).

Quick questions and answers

Why does the denominator stay the same when I add?

The denominator names the size of each piece. Two sevenths plus three sevenths is five sevenths; the pieces are still sevenths. Only the numerators, which count the pieces, are added.

How do I find the excluded value?

Set the common denominator equal to zero and solve. Any value that makes it zero is excluded, because division by zero is undefined. Factor a quadratic denominator to find both values.

Why put the second numerator in parentheses?

A minus sign in front of a fraction subtracts the entire numerator. Parentheses remind you to distribute the minus sign to every term, so −(2x − 3) becomes −2x + 3.

Do I need to simplify after adding or subtracting?

Yes. Factor the new numerator. If it shares a factor with the denominator, cancel it, but keep the restriction from the original denominator.

Can the answer be a constant?

Yes. For example, (4x − 12)/(2x − 6) simplifies to 2. The expression equals 2 for every allowed x, and x = 3 is still excluded.

How can I check my answer?

Substitute an allowed number, such as x = 0 or x = 1, into the original expression and into your answer. If the two values differ, look for a sign error.
