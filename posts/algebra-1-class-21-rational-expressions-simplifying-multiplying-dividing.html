Find the excluded value

A rational expression is a fraction whose numerator and denominator are polynomials, such as \(\frac{x+2}{x-3}\). Because division by zero is undefined, any value of the variable that makes the denominator equal zero must be excluded. These are the excluded values, and the domain is all real numbers except them.

To find excluded values, set the denominator equal to zero and solve. If the denominator is a quadratic, factor it and use the zero product property; there may be two excluded values. A zero in the numerator is fine: at \(x = -2\), \(\frac{x+2}{x-3} = \frac{0}{-5} = 0\), a perfectly good value. Only the denominator decides what is excluded.

Practice: try these five questions

Q1

Find the excluded value and state the domain.

\[\frac{x+5}{x-7}\]
Answer

\(x \neq 7\)

  1. Set the denominator equal to zero and solve.

    \[x - 7 = 0 \;\Rightarrow\; x = 7\]

  2. At \(x = 7\) the expression becomes \(\frac{12}{0}\), which is undefined. The domain is all real numbers except 7.

Q2

Find the excluded value.

\[\frac{3x}{2x+8}\]
Answer

\(x \neq -4\)

  1. Set the denominator equal to zero.

    \[2x + 8 = 0 \;\Rightarrow\; 2x = -8 \;\Rightarrow\; x = -4\]

  2. Check: \(2(-4) + 8 = 0\). The value \(x = 0\) is allowed; it only makes the numerator zero.

Q3

Find both excluded values.

\[\frac{x-1}{x^2-25}\]
Answer

\(x \neq 5 \text{ and } x \neq -5\)

  1. Factor the denominator as a difference of squares.

    \[x^2 - 25 = (x-5)(x+5)\]

  2. Set each factor equal to zero.

    \[x - 5 = 0 \Rightarrow x = 5, \qquad x + 5 = 0 \Rightarrow x = -5\]

Q4

Find the excluded values.

\[\frac{2x+1}{x^2-x-12}\]
Answer

\(x \neq 4 \text{ and } x \neq -3\)

  1. Factor the denominator: find two numbers that multiply to \(-12\) and add to \(-1\). They are \(-4\) and \(3\).

    \[x^2 - x - 12 = (x-4)(x+3)\]

  2. Set each factor equal to zero.

    \[x = 4 \quad \text{or} \quad x = -3\]

Q5

Evaluate the expression at \(x = 6\) and at \(x = -1\). Which value is excluded? State the domain.

\[\frac{x-6}{x+1}\]
Answer

\(x = 6 \text{ gives } 0; \; x = -1 \text{ is excluded}; \; x \neq -1\)

  1. At \(x = 6\):

    \[\frac{6-6}{6+1} = \frac{0}{7} = 0 \quad \text{valid}\]

  2. At \(x = -1\):

    \[\frac{-1-6}{-1+1} = \frac{-7}{0} \quad \text{undefined}\]

  3. The denominator is zero only at \(x = -1\), so the domain is all real numbers except \(-1\).

Simplify a ratio of monomials

To simplify a ratio of monomials, handle the numbers and the variables separately. Reduce the coefficients by dividing both by their greatest common factor, then cancel common variable factors. With the same base, subtract exponents: \(\frac{x^5}{x^2} = x^{5-2} = x^3\). If the larger power is in the denominator, the leftover factor stays in the denominator: \(\frac{x^2}{x^5} = \frac{1}{x^3}\).

State the restriction from the original denominator, before anything cancels. In \(\frac{12x^3}{18x^2}\), the answer \(\frac{2x}{3}\) looks defined at \(x = 0\), but the original expression is not, so we write \(\frac{2x}{3}, \; x \neq 0\). Every variable that appears in the original denominator must be nonzero.

Practice: try these five questions

Q6

Simplify and state the restriction.

\[\frac{15x^4}{20x}\]
Answer

\(\frac{3x^3}{4}, \; x \neq 0\)

  1. Reduce the coefficients by their GCF, 5.

    \[\frac{15}{20} = \frac{5 \cdot 3}{5 \cdot 4} = \frac{3}{4}\]

  2. Subtract exponents on x.

    \[\frac{x^4}{x} = x^{4-1} = x^3\]

  3. The original denominator \(20x\) is zero when \(x = 0\).

    \[\frac{3x^3}{4}, \; x \neq 0\]

Q7

Simplify and state the restriction.

\[\frac{8x^2}{24x^5}\]
Answer

\(\frac{1}{3x^3}, \; x \neq 0\)

  1. Reduce the coefficients by their GCF, 8.

    \[\frac{8}{24} = \frac{1}{3}\]

  2. The larger power of x is in the denominator, so the leftover factor stays there.

    \[\frac{x^2}{x^5} = \frac{1}{x^{5-2}} = \frac{1}{x^3}\]

  3. Combine and state the restriction.

    \[\frac{1}{3x^3}, \; x \neq 0\]

Q8

Simplify and state the restrictions.

\[\frac{-14a^3b}{21ab^2}\]
Answer

\(-\frac{2a^2}{3b}, \; a \neq 0, \; b \neq 0\)

  1. Reduce the coefficients by their GCF, 7. Keep the negative sign.

    \[\frac{-14}{21} = -\frac{2}{3}\]

  2. Cancel each variable separately.

    \[\frac{a^3}{a} = a^2, \qquad \frac{b}{b^2} = \frac{1}{b}\]

  3. Both \(a\) and \(b\) appear in the original denominator, so both must be nonzero.

    \[-\frac{2a^2}{3b}, \; a \neq 0, \; b \neq 0\]

Q9

Simplify and state the restrictions.

\[\frac{36x^5y^2}{9x^2y^2}\]
Answer

\(4x^3, \; x \neq 0, \; y \neq 0\)

  1. Reduce the coefficients.

    \[\frac{36}{9} = 4\]

  2. Cancel the variables. The \(y^2\) factors cancel completely.

    \[\frac{x^5}{x^2} = x^3, \qquad \frac{y^2}{y^2} = 1\]

  3. Even though \(y\) disappears from the answer, it was in the original denominator, so \(y \neq 0\).

    \[4x^3, \; x \neq 0, \; y \neq 0\]

Q10

Simplify the numerator first, then simplify the ratio and state the restriction.

\[\frac{(6x^2)(10x)}{15x^4}\]
Answer

\(\frac{4}{x}, \; x \neq 0\)

  1. Multiply the monomials in the numerator.

    \[(6x^2)(10x) = 60x^3\]

  2. Reduce the coefficients and subtract exponents.

    \[\frac{60x^3}{15x^4} = \frac{4}{x^{4-3}} = \frac{4}{x}\]

  3. The original denominator \(15x^4\) is zero when \(x = 0\).

    \[\frac{4}{x}, \; x \neq 0\]

Factor before canceling

You may cancel only factors, which are expressions multiplied together, never terms that are added. In \(\frac{x^2+5x+6}{x+2}\), nothing can cancel yet because the numerator is a sum of three terms. Factor first: \(x^2 + 5x + 6 = (x+2)(x+3)\). Now \(x + 2\) is a factor of both the numerator and the denominator, and \(\frac{x+2}{x+2} = 1\).

The routine is always the same: factor the numerator and denominator completely (GCF first, then trinomials or special products), find the excluded values from the factored denominator, cancel common factors, and write what remains. Record the restrictions before canceling, because a canceled factor still makes the original denominator zero.

Q11

Simplify and state the restriction.

\[\frac{x^2+7x+12}{x+4}\]
Answer

\(x + 3, \; x \neq -4\)

  1. Factor the numerator: 3 and 4 multiply to 12 and add to 7.

    \[x^2 + 7x + 12 = (x+3)(x+4)\]

  2. The denominator is zero at \(x = -4\). Cancel the common factor \(x + 4\).

    \[\frac{(x+3)(x+4)}{x+4} = x + 3, \; x \neq -4\]

Simplify and state the restriction.

\[\frac{x^2-2x-15}{x-5}\]
Answer

\(x + 3, \; x \neq 5\)

  1. Factor the numerator: \(-5\) and \(3\) multiply to \(-15\) and add to \(-2\).

    \[x^2 - 2x - 15 = (x-5)(x+3)\]

  2. The denominator is zero at \(x = 5\). Cancel \(x - 5\).

    \[\frac{(x-5)(x+3)}{x-5} = x + 3, \; x \neq 5\]

Q13

Simplify and state the restrictions.

\[\frac{3x+12}{x^2+6x+8}\]
Answer

\(\frac{3}{x+2}, \; x \neq -2, \; x \neq -4\)

  1. Factor the GCF out of the numerator and factor the trinomial in the denominator.

    \[\frac{3(x+4)}{(x+2)(x+4)}\]

  2. The denominator is zero at \(x = -2\) and \(x = -4\). Cancel \(x + 4\).

    \[\frac{3}{x+2}, \; x \neq -2, \; x \neq -4\]

Q14

Simplify and state the restrictions.

\[\frac{x^2+x-20}{x^2-x-12}\]
Answer

\(\frac{x+5}{x+3}, \; x \neq 4, \; x \neq -3\)

  1. Factor both trinomials.

    \[\frac{(x+5)(x-4)}{(x-4)(x+3)}\]

  2. The denominator is zero at \(x = 4\) and \(x = -3\). Cancel \(x - 4\).

    \[\frac{x+5}{x+3}, \; x \neq 4, \; x \neq -3\]

  3. Note: \(x + 5\) and \(x + 3\) cannot cancel; they are different factors.

Q15

Simplify and state the restriction.

\[\frac{2x^2+7x+3}{2x+1}\]
Answer

\(x + 3, \; x \neq -\tfrac{1}{2}\)

  1. Factor the nonmonic trinomial. Use \(ac = 6\): 1 and 6 multiply to 6 and add to 7.

    \[2x^2 + x + 6x + 3 = x(2x+1) + 3(2x+1) = (2x+1)(x+3)\]

  2. The denominator is zero when \(2x + 1 = 0\), so \(x = -\tfrac{1}{2}\). Cancel \(2x + 1\).

    \[\frac{(2x+1)(x+3)}{2x+1} = x + 3, \; x \neq -\tfrac{1}{2}\]

Simplify a difference of squares

A difference of squares factors as \(a^2 - b^2 = (a-b)(a+b)\). Spot it when two perfect squares are subtracted: \(x^2 - 16 = (x-4)(x+4)\) and \(4x^2 - 9 = (2x-3)(2x+3)\). A sum of squares such as \(x^2 + 16\) does not factor over the real numbers. Combine this with a GCF in the other part of the fraction: \(x^2 + 4x = x(x+4)\).

Watch for opposite factors. Since \(1 - x = -(x - 1)\), the fraction \(\frac{x-1}{1-x}\) equals \(-1\), not 1. When a factor in the numerator is the opposite of one in the denominator, factor out \(-1\) first, then cancel. As always, list every excluded value from the factored original denominator, including the ones that cancel.

\[\frac{x^2-49}{x^2-14x+49}\]

\(\frac{x+7}{x-7}, \; x \neq 7\)

    \[\frac{(x-7)(x+7)}{(x-7)(x-7)}\]

Q19

Simplify and find both excluded values.

\[\frac{4x^2-9}{2x^2+3x}\]
Answer

\(\frac{2x-3}{x}, \; x \neq 0, \; x \neq -\tfrac{3}{2}\)

  1. \(4x^2 = (2x)^2\) and \(9 = 3^2\), so the numerator is a difference of squares. Factor x out of the denominator.

    \[\frac{(2x-3)(2x+3)}{x(2x+3)}\]

  2. The denominator is zero at \(x = 0\) and \(2x + 3 = 0\), so \(x = -\tfrac{3}{2}\). Cancel \(2x + 3\).

    \[\frac{2x-3}{x}, \; x \neq 0, \; x \neq -\tfrac{3}{2}\]

Q20

Simplify. Watch for opposite factors.

\[\frac{x^2-1}{1-x}\]
Answer

\(-(x+1), \; x \neq 1\)

  1. Factor the numerator and write the denominator as \(-(x-1)\).

    \[\frac{(x-1)(x+1)}{-(x-1)}\]

  2. The denominator is zero at \(x = 1\). Cancel \(x - 1\); the \(-1\) remains.

    \[-(x+1) = -x - 1, \; x \neq 1\]

  3. Check at \(x = 2\): \(\frac{4-1}{1-2} = \frac{3}{-1} = -3\), and \(-(2+1) = -3\).

Spot the cancellation mistake

The most common error with rational expressions is canceling a term instead of a factor. In \(\frac{x+6}{x}\), the \(x\) on top is only one term of the sum \(x + 6\), so it cannot cancel with the \(x\) below. A quick test exposes the mistake: at \(x = 2\), \(\frac{2+6}{2} = 4\), not 6. One counterexample is enough to prove a claimed simplification false.

The correct moves are to factor or to split the fraction. Splitting divides every term by the denominator: \(\frac{x+6}{x} = \frac{x}{x} + \frac{6}{x} = 1 + \frac{6}{x}\). Factoring works when every term shares a factor: \(\frac{5x+10}{5} = \frac{5(x+2)}{5} = x + 2\). Some expressions, like \(\frac{x^2+9}{x+3}\), are already in simplest form because the numerator has no factor in common with the denominator. A correct simplification also keeps its restriction.

Practice: try these five questions

Q21

A student writes the work below. Test it at \(x = 4\), then write the expression correctly.

\[\frac{x+8}{8} = x\]
Answer

\(\text{False; } \frac{x+8}{8} = \frac{x}{8} + 1\)

  1. Test at \(x = 4\).

    \[\frac{4+8}{8} = \frac{12}{8} = \frac{3}{2} \neq 4\]

  2. The 8 in the numerator is a term, not a factor, so it cannot cancel. Split the fraction instead.

    \[\frac{x+8}{8} = \frac{x}{8} + \frac{8}{8} = \frac{x}{8} + 1\]

  3. The denominator 8 is never zero, so there is no excluded value.

Q22

A student writes the work below. Test it at \(x = 1\) and explain the error.

\[\frac{x^2+9}{x+3} = x+3\]
Answer

\(\text{False; already simplest, } x \neq -3\)

  1. Test at \(x = 1\).

    \[\frac{1+9}{1+3} = \frac{10}{4} = \frac{5}{2} \neq 4\]

  2. The student treated \(x^2 + 9\) like \((x+3)(x+3)\). But \((x+3)^2 = x^2 + 6x + 9\), and \(x^2 + 9\) is a sum of squares, which does not factor.

  3. No factor is shared, so \(\frac{x^2+9}{x+3}\) is already in simplest form, with \(x \neq -3\).

Q23

Find and correct the mistake.

\[\frac{5x+10}{5} = x + 10\]
Answer

\(x + 2\)

  1. The student divided only the first term by 5. Every term must be divided, so factor the 5 out of both terms.

    \[\frac{5x+10}{5} = \frac{5(x+2)}{5} = x + 2\]

  2. Check at \(x = 1\): \(\frac{15}{5} = 3\) and \(1 + 2 = 3\). The denominator is never zero, so there is no restriction.

Q24

A student says the equation below is true for all real numbers. What is missing?

\[\frac{x^2-4}{x-2} = x+2\]
Answer

\(\text{The restriction } x \neq 2\)

  1. The algebra is correct: factor and cancel.

    \[\frac{(x-2)(x+2)}{x-2} = x + 2\]

  2. But at \(x = 2\), the left side is \(\frac{0}{0}\), undefined, while the right side is 4. The two sides are equal only when \(x \neq 2\).

    \[\frac{x^2-4}{x-2} = x + 2, \; x \neq 2\]

Q25

Which simplifications are correct for all allowed values? For each false one, give a counterexample.

\[\text{(a) } \frac{3x}{3y} = \frac{x}{y} \qquad \text{(b) } \frac{x+3}{y+3} = \frac{x}{y} \qquad \text{(c) } \frac{x(x+1)}{x(x+2)} = \frac{x+1}{x+2}\]
Answer

\(\text{(a) and (c) are correct; (b) is false}\)

  1. (a) The 3 is a factor of both the numerator and the denominator, so it cancels. Correct, with \(y \neq 0\).

  2. (b) The 3s are terms, not factors. Counterexample: \(x = 1, \; y = 2\).

    \[\frac{1+3}{2+3} = \frac{4}{5}, \qquad \frac{1}{2} \neq \frac{4}{5}\]

  3. (c) The \(x\) multiplies the whole numerator and the whole denominator, so it cancels. Correct, with \(x \neq 0\) and \(x \neq -2\).

Multiply rational expressions

Multiply rational expressions the way you multiply fractions: numerator times numerator over denominator times denominator. The efficient order is to factor everything first, cancel any factor that appears in any numerator with the same factor in any denominator, and only then multiply what remains. Canceling first keeps the numbers small and the polynomials simple.

Find restrictions from every original denominator before canceling. In \(\frac{x^2-9}{2x} \cdot \frac{4x}{x+3}\), the denominators \(2x\) and \(x + 3\) give \(x \neq 0\) and \(x \neq -3\). After canceling, the product \(2(x-3)\) looks defined everywhere, but it equals the original product only when both restrictions hold. Leave the answer in factored form unless asked to expand.

Practice: try these five questions

Q26

Multiply, simplify, and state the restrictions.

\[\frac{x^2-16}{3x} \cdot \frac{6x}{x+4}\]
Answer

\(2(x-4), \; x \neq 0, \; x \neq -4\)

  1. Restrictions from the denominators: \(3x\) and \(x + 4\) give \(x \neq 0\) and \(x \neq -4\). Factor the difference of squares.

    \[\frac{(x-4)(x+4)}{3x} \cdot \frac{6x}{x+4}\]

  2. Cancel \(x + 4\) and simplify \(\frac{6x}{3x} = 2\).

    \[(x-4) \cdot 2 = 2(x-4)\]

Q27

Multiply, simplify, and state the restrictions.

\[\frac{x+2}{x-1} \cdot \frac{x^2-1}{x^2+5x+6}\]
Answer

\(\frac{x+1}{x+3}, \; x \neq 1, \; x \neq -2, \; x \neq -3\)

  1. Factor every polynomial.

    \[\frac{x+2}{x-1} \cdot \frac{(x-1)(x+1)}{(x+2)(x+3)}\]

  2. Restrictions from the denominators \(x - 1\) and \((x+2)(x+3)\): \(x \neq 1, -2, -3\).

  3. Cancel \(x + 2\) and \(x - 1\).

    \[\frac{x+1}{x+3}\]

Q28

Multiply, simplify, and state the restrictions.

\[\frac{5x^2}{x+3} \cdot \frac{x^2+3x}{10x^3}\]
Answer

\(\frac{1}{2}, \; x \neq 0, \; x \neq -3\)

  1. Factor \(x^2 + 3x = x(x+3)\). Restrictions from \(x + 3\) and \(10x^3\): \(x \neq -3, \; x \neq 0\).

    \[\frac{5x^2}{x+3} \cdot \frac{x(x+3)}{10x^3}\]

  2. Cancel \(x + 3\). The remaining numerator is \(5x^3\) over \(10x^3\).

    \[\frac{5x^3}{10x^3} = \frac{1}{2}\]

Q29

Multiply, simplify, and state the restrictions.

\[\frac{x^2-x-6}{x^2-9} \cdot \frac{x+3}{x+2}\]
Answer

\(1, \; x \neq 3, \; x \neq -3, \; x \neq -2\)

  1. Factor every polynomial.

    \[\frac{(x-3)(x+2)}{(x-3)(x+3)} \cdot \frac{x+3}{x+2}\]

  2. Restrictions from \((x-3)(x+3)\) and \(x + 2\): \(x \neq 3, -3, -2\).

  3. Every factor cancels, leaving 1.

    \[1, \; x \neq 3, \; x \neq -3, \; x \neq -2\]

Q30

Multiply, simplify, and state the restrictions.

\[\frac{2x-6}{x^2+2x} \cdot \frac{x^2-4}{x-3}\]
Answer

\(\frac{2(x-2)}{x}, \; x \neq 0, \; x \neq -2, \; x \neq 3\)

  1. Factor: a GCF in each binomial and trinomial, and a difference of squares.

    \[\frac{2(x-3)}{x(x+2)} \cdot \frac{(x-2)(x+2)}{x-3}\]

  2. Restrictions from \(x(x+2)\) and \(x - 3\): \(x \neq 0, -2, 3\).

  3. Cancel \(x - 3\) and \(x + 2\).

    \[\frac{2(x-2)}{x}\]

Divide using the reciprocal

To divide by a rational expression, multiply by its reciprocal: \(\frac{A}{B} \div \frac{C}{D} = \frac{A}{B} \cdot \frac{D}{C}\). After flipping the divisor, the problem is a multiplication: factor, cancel common factors, and multiply what remains.

Division adds one more kind of restriction. Exclude values that make any original denominator zero, and also values that make the divisor itself equal zero, because you cannot divide by zero. The divisor \(\frac{C}{D}\) is zero when its numerator \(C\) is zero. In \(\frac{x^2-4}{x+5} \div \frac{x-2}{x+5}\), the denominators give \(x \neq -5\) and the divisor's numerator gives \(x \neq 2\). Find all restrictions before flipping.

\[\frac{x^2-9}{x+1} \div \frac{x+3}{x+1}\]

\(x - 3, \; x \neq -1, \; x \neq -3\)

  1. Restrictions: the denominators give \(x \neq -1\); the divisor's numerator \(x + 3\) gives \(x \neq -3\).

Q35

Divide, simplify, and state the restrictions. Watch for opposite factors.

\[\frac{x-7}{3x} \div \frac{7-x}{6x^2}\]
Answer

\(-2x, \; x \neq 0, \; x \neq 7\)

  1. Restrictions: the denominators give \(x \neq 0\); the divisor's numerator \(7 - x\) gives \(x \neq 7\).

  2. Multiply by the reciprocal and write \(7 - x = -(x-7)\).

    \[\frac{x-7}{3x} \cdot \frac{6x^2}{-(x-7)}\]

  3. Cancel \(x - 7\) and simplify \(\frac{6x^2}{3x} = 2x\), keeping the negative sign.

    \[-2x\]

Find the rectangle’s length

Rational expressions describe real quantities: areas, rates, prices per unit. Translate the relationship into an operation. For a rectangle, area = length × width, so length = area ÷ width. For motion, speed = distance ÷ time. For a triangle, area = \(\tfrac{1}{2}\) × base × height. Then divide or multiply the rational expressions exactly as before.

A condition such as \(x \gt 3\) keeps every measurement positive and every denominator nonzero, so no separate restriction is needed in the answer. Always check: multiply your length by the width and confirm you get the original area. You can also substitute a number, for example \(x = 5\), into both the given data and your answer.

Practice: try these five questions

Q36

A rectangle has area \(\dfrac{x^2-4}{x+5}\) square units and width \(\dfrac{x-2}{x+5}\) units, with \(x \gt 2\). Find its length.

Answer

\(L = x + 2 \text{ units}\)

  1. Length equals area divided by width.

    \[L = \frac{x^2-4}{x+5} \div \frac{x-2}{x+5} = \frac{(x-2)(x+2)}{x+5} \cdot \frac{x+5}{x-2}\]

  2. Cancel \(x + 5\) and \(x - 2\).

    \[L = x + 2\]

  3. Check length × width.

    \[(x+2) \cdot \frac{x-2}{x+5} = \frac{x^2-4}{x+5}\]

Q37

A rectangle has length \(\dfrac{x+4}{x-1}\) units and width \(\dfrac{x^2-1}{x+4}\) units, with \(x \gt 1\). Find its area.

Answer

\(A = x + 1 \text{ square units}\)

  1. Area equals length times width. Factor the difference of squares.

    \[A = \frac{x+4}{x-1} \cdot \frac{(x-1)(x+1)}{x+4}\]

  2. Cancel \(x + 4\) and \(x - 1\).

    \[A = x + 1\]

  3. Check at \(x = 3\): length \(\frac{7}{2}\), width \(\frac{8}{7}\), area \(\frac{7}{2} \cdot \frac{8}{7} = 4 = 3 + 1\).

Q38

A rectangular garden has area \(x^2 + 7x + 10\) square feet and length \(x + 5\) feet, with \(x \gt 0\). Find its width.

Answer

\(W = x + 2 \text{ feet}\)

  1. Width equals area divided by length. Factor the area.

    \[W = \frac{x^2+7x+10}{x+5} = \frac{(x+5)(x+2)}{x+5}\]

  2. Cancel \(x + 5\).

    \[W = x + 2\]

  3. Check.

    \[(x+5)(x+2) = x^2 + 7x + 10\]

Q39

A car travels \(\dfrac{x^2-25}{2x}\) miles in \(\dfrac{x+5}{4x}\) hours, with \(x \gt 5\). Find its average speed in miles per hour.

Answer

\(2(x-5) \text{ miles per hour}\)

  1. Speed equals distance divided by time.

    \[\frac{x^2-25}{2x} \div \frac{x+5}{4x} = \frac{(x-5)(x+5)}{2x} \cdot \frac{4x}{x+5}\]

  2. Cancel \(x + 5\) and simplify \(\frac{4x}{2x} = 2\).

    \[2(x-5) = 2x - 10\]

  3. Check at \(x = 10\): distance \(\frac{75}{20} = 3.75\) mi, time \(\frac{15}{40} = 0.375\) h, speed \(10\) mph, and \(2(10-5) = 10\).

Q40

A triangle has base \(\dfrac{2x+6}{x}\) units and height \(\dfrac{x^2}{x+3}\) units, with \(x \gt 0\). Find its area.

Answer

\(A = x \text{ square units}\)

  1. Use \(A = \tfrac{1}{2}bh\) and factor \(2x + 6 = 2(x+3)\).

    \[A = \frac{1}{2} \cdot \frac{2(x+3)}{x} \cdot \frac{x^2}{x+3}\]

  2. Cancel the 2, the \(x + 3\), and one factor of \(x\).

    \[A = x\]

  3. Check at \(x = 3\): base \(4\), height \(\frac{9}{6} = 1.5\), area \(\frac{1}{2} \cdot 4 \cdot 1.5 = 3\).

Homework review

One review question for each topic, in image order. Factor completely, state restrictions from the original expression, cancel only common factors, and check with a number.

R1

Find the excluded values.

\[\frac{x+3}{x^2-9x+20}\]
Answer

\(x \neq 4 \text{ and } x \neq 5\)

  1. Factor the denominator: \(-4\) and \(-5\) multiply to 20 and add to \(-9\).

    \[x^2 - 9x + 20 = (x-4)(x-5)\]

  2. Set each factor equal to zero.

    \[x = 4 \quad \text{or} \quad x = 5\]

R2

Simplify and state the restrictions.

\[\frac{18x^2y^3}{27x^4y}\]
Answer

\(\frac{2y^2}{3x^2}, \; x \neq 0, \; y \neq 0\)

  1. Reduce the coefficients by their GCF, 9.

    \[\frac{18}{27} = \frac{2}{3}\]

  2. Cancel the variables.

    \[\frac{x^2}{x^4} = \frac{1}{x^2}, \qquad \frac{y^3}{y} = y^2\]

  3. Both variables appear in the original denominator.

    \[\frac{2y^2}{3x^2}, \; x \neq 0, \; y \neq 0\]

R3

Simplify and state the restriction.

\[\frac{x^2-3x-28}{x+4}\]
Answer

\(x - 7, \; x \neq -4\)

  1. Factor: \(-7\) and \(4\) multiply to \(-28\) and add to \(-3\).

    \[\frac{(x-7)(x+4)}{x+4}\]

  2. Cancel \(x + 4\); the denominator was zero at \(x = -4\).

    \[x - 7, \; x \neq -4\]

R4

Simplify and find both excluded values.

\[\frac{x^2-81}{x^2-9x}\]
Answer

\(\frac{x+9}{x}, \; x \neq 0, \; x \neq 9\)

  1. Factor the difference of squares and the GCF.

    \[\frac{(x-9)(x+9)}{x(x-9)}\]

  2. The denominator is zero at \(x = 0\) and \(x = 9\). Cancel \(x - 9\).

    \[\frac{x+9}{x}, \; x \neq 0, \; x \neq 9\]

R5

A student claims the statement below. Test it at \(x = 1\) and write the expression correctly.

\[\frac{2x+7}{2x} = 7\]
Answer

\(\text{False; } \frac{2x+7}{2x} = 1 + \frac{7}{2x}, \; x \neq 0\)

  1. Test at \(x = 1\).

    \[\frac{2+7}{2} = \frac{9}{2} \neq 7\]

  2. \(2x\) is a term of the numerator, not a factor, so it cannot cancel. Split the fraction.

    \[\frac{2x+7}{2x} = \frac{2x}{2x} + \frac{7}{2x} = 1 + \frac{7}{2x}, \; x \neq 0\]

R6

Multiply, simplify, and state the restrictions.

\[\frac{x^2-25}{x^2+4x} \cdot \frac{x+4}{x-5}\]
Answer

\(\frac{x+5}{x}, \; x \neq 0, \; x \neq -4, \; x \neq 5\)

  1. Factor every polynomial.

    \[\frac{(x-5)(x+5)}{x(x+4)} \cdot \frac{x+4}{x-5}\]

  2. Restrictions from \(x(x+4)\) and \(x - 5\): \(x \neq 0, -4, 5\). Cancel \(x + 4\) and \(x - 5\).

    \[\frac{x+5}{x}\]

R7

Divide, simplify, and state the restrictions.

\[\frac{x^2-x-12}{x^2-16} \div \frac{x+3}{x+4}\]
Answer

\(1, \; x \neq 4, \; x \neq -4, \; x \neq -3\)

  1. Restrictions: \(x^2 - 16\) and \(x + 4\) give \(x \neq 4, -4\); the divisor's numerator gives \(x \neq -3\).

  2. Multiply by the reciprocal and factor.

    \[\frac{(x-4)(x+3)}{(x-4)(x+4)} \cdot \frac{x+4}{x+3}\]

  3. Every factor cancels.

    \[1\]

R8

A rectangle has area \(\dfrac{x^2+x-6}{x+4}\) square units and width \(\dfrac{x-2}{x+4}\) units, with \(x \gt 2\). Find its length and check.

Answer

\(L = x + 3 \text{ units}\)

  1. Divide area by width.

    \[L = \frac{(x+3)(x-2)}{x+4} \cdot \frac{x+4}{x-2} = x + 3\]

  2. Check length × width.

    \[(x+3) \cdot \frac{x-2}{x+4} = \frac{x^2+x-6}{x+4}\]

Homework word problems

Twelve word problems that build from direct setups to a multi-step challenge. Translate the situation into a product or quotient, simplify, and check your answer with a number.

W1

A club raises \(6x^2 + 18x\) dollars and shares it equally among \(3x\) members. Write the amount each member receives in simplest form.

Answer

\(2(x+3) = 2x + 6 \text{ dollars}\)

  1. Divide the total by the number of members and factor.

    \[\frac{6x^2+18x}{3x} = \frac{6x(x+3)}{3x}\]

  2. Cancel \(3x\). The number of members is positive, so \(x \neq 0\) automatically.

    \[2(x+3) = 2x + 6\]

W2

A cyclist rides \(x^2 - 16\) miles in \(x + 4\) hours, with \(x \gt 4\). Find the average speed.

Answer

\(x - 4 \text{ miles per hour}\)

  1. Speed equals distance divided by time.

    \[\frac{x^2-16}{x+4} = \frac{(x-4)(x+4)}{x+4} = x - 4\]

  2. Check at \(x = 6\): 20 miles in 10 hours is 2 mph, and \(6 - 4 = 2\).

W3

A rectangle has area \(x^2 - 49\) square feet and length \(x + 7\) feet, with \(x \gt 7\). Find the width, then evaluate it when \(x = 10\).

Answer

\(W = x - 7; \; W = 3 \text{ ft when } x = 10\)

  1. Width equals area divided by length.

    \[W = \frac{x^2-49}{x+7} = \frac{(x-7)(x+7)}{x+7} = x - 7\]

  2. At \(x = 10\): \(W = 3\) ft. Check: length 17 ft, \(17 \times 3 = 51\), and \(10^2 - 49 = 51\).

W4

A machine fills \(\dfrac{x^2-9}{4x}\) boxes per minute for \(\dfrac{8x}{x+3}\) minutes, with \(x \gt 3\). How many boxes does it fill?

Answer

\(2(x-3) \text{ boxes}\)

  1. Total equals rate times time.

    \[\frac{(x-3)(x+3)}{4x} \cdot \frac{8x}{x+3}\]

  2. Cancel \(x + 3\) and simplify \(\frac{8x}{4x} = 2\).

    \[2(x-3) = 2x - 6\]

W5

A bag of nuts weighing \(\dfrac{x+3}{2x}\) pounds costs \(\dfrac{x^2+5x+6}{x}\) dollars, with \(x \gt 0\). Find the price per pound.

Answer

\(2(x+2) \text{ dollars per pound}\)

  1. Price per pound equals cost divided by weight.

    \[\frac{x^2+5x+6}{x} \div \frac{x+3}{2x} = \frac{(x+2)(x+3)}{x} \cdot \frac{2x}{x+3}\]

  2. Cancel \(x + 3\) and \(x\).

    \[2(x+2) = 2x + 4\]

W6

A square has side \(s\) units, \(s \gt 0\). Write the ratio of its perimeter to its area in simplest form, then find the ratio for \(s = 8\).

Answer

\(\frac{4}{s}; \; \frac{1}{2} \text{ when } s = 8\)

  1. Perimeter is \(4s\) and area is \(s^2\).

    \[\frac{4s}{s^2} = \frac{4}{s}\]

  2. At \(s = 8\): \(\frac{4}{8} = \frac{1}{2}\). Check: perimeter 32, area 64, and \(\frac{32}{64} = \frac{1}{2}\).

W7

Jordan says \(\dfrac{x^2+10}{x+10}\) simplifies to \(x\). Test the claim at \(x = 2\) and explain the correct result.

Answer

\(\text{False; already simplest, } x \neq -10\)

  1. Test at \(x = 2\).

    \[\frac{4+10}{2+10} = \frac{14}{12} = \frac{7}{6} \neq 2\]

  2. Jordan canceled the term 10, not a factor. \(x^2 + 10\) does not factor, so the expression shares no factor with \(x + 10\). It is already in simplest form, with \(x \neq -10\).

W8

A rectangle has length \(\dfrac{x+6}{x-2}\) units and width \(\dfrac{x^2-4}{2x+12}\) units, with \(x \gt 2\). Find the area, then evaluate it when \(x = 6\).

Answer

\(A = \frac{x+2}{2}; \; A = 4 \text{ when } x = 6\)

  1. Multiply length by width and factor.

    \[\frac{x+6}{x-2} \cdot \frac{(x-2)(x+2)}{2(x+6)}\]

  2. Cancel \(x + 6\) and \(x - 2\).

    \[A = \frac{x+2}{2}\]

  3. At \(x = 6\): \(A = 4\). Check: length \(\frac{12}{4} = 3\), width \(\frac{32}{24} = \frac{4}{3}\), and \(3 \cdot \frac{4}{3} = 4\).

W9

A box has volume \(x^3 + 5x^2 + 6x\) cubic inches and base area \(x^2 + 3x\) square inches, with \(x \gt 0\). Find its height.

Answer

\(h = x + 2 \text{ inches}\)

  1. Height equals volume divided by base area. Factor both.

    \[h = \frac{x(x+2)(x+3)}{x(x+3)}\]

  2. Cancel \(x\) and \(x + 3\).

    \[h = x + 2\]

W10

A printer prints \(\dfrac{2x^2+10x}{x-1}\) pages in \(\dfrac{x+5}{x-1}\) minutes, with \(x \gt 1\). How many pages does it print per minute?

Answer

\(2x \text{ pages per minute}\)

  1. Divide pages by minutes.

    \[\frac{2x(x+5)}{x-1} \cdot \frac{x-1}{x+5}\]

  2. Cancel \(x - 1\) and \(x + 5\).

    \[2x\]

W11

Let \(f(x) = \dfrac{x^2-x-6}{x-3}\). Simplify \(f(x)\), find \(f(5)\), and explain what happens at \(x = 3\).

Answer

\(f(x) = x + 2, \; x \neq 3; \; f(5) = 7; \; f(3) \text{ is undefined}\)

  1. Factor and cancel.

    \[f(x) = \frac{(x-3)(x+2)}{x-3} = x + 2, \; x \neq 3\]

  2. \(f(5) = 5 + 2 = 7\). Check with the original: \(\frac{25-5-6}{2} = \frac{14}{2} = 7\).

  3. At \(x = 3\) the original gives \(\frac{0}{0}\), so \(f(3)\) is undefined. The graph is the line \(y = x + 2\) with a hole (open circle) at \((3, 5)\).

W12

Challenge: simplify and state every restriction.

\[\frac{x^2-9}{x^2+4x+4} \cdot \frac{x+2}{x-3} \div \frac{x+3}{x^2-4}\]
Answer

\(x - 2, \; x \neq -2, \; x \neq 2, \; x \neq 3, \; x \neq -3\)

  1. Restrictions: denominators \((x+2)^2\), \(x - 3\) and \(x^2 - 4\) give \(x \neq -2, 3, 2\); the divisor's numerator \(x + 3\) gives \(x \neq -3\).

  2. Multiply by the reciprocal of the divisor and factor everything.

    \[\frac{(x-3)(x+3)}{(x+2)(x+2)} \cdot \frac{x+2}{x-3} \cdot \frac{(x-2)(x+2)}{x+3}\]

  3. Cancel \(x - 3\), \(x + 3\), and both factors of \(x + 2\).

    \[x - 2\]

Quick questions and answers

What is an excluded value?

It is a value of the variable that makes a denominator equal zero. The rational expression is undefined there, so the value is left out of the domain.

Why do I state restrictions from the original expression?

Canceling a factor removes it from the answer but not from the original problem. If x + 2 was in the original denominator, x = −2 is still excluded even after x + 2 cancels.

What can I cancel?

Only factors that multiply the entire numerator and the entire denominator. Terms joined by + or − cannot be canceled; factor first, then cancel matching factors.

How do I multiply rational expressions?

Factor every numerator and denominator, cancel common factors across the fractions, and multiply what remains. State the restrictions from every original denominator.

How do I divide rational expressions?

Multiply the first expression by the reciprocal of the second. Exclude values that make any denominator zero and values that make the divisor's numerator zero.

What happens with opposite factors like x − 1 and 1 − x?

They differ by a factor of −1, since 1 − x = −(x − 1). Their ratio is −1, so a negative sign remains after canceling.
