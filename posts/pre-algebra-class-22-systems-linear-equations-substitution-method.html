Solving a system by substitution

A system of two linear equations is a pair of equations that must be true at the same time. A solution of the system is an ordered pair \((x, y)\) that makes both equations true. On a graph, each equation is a line, and the solution is the point where the two lines cross.

The substitution method turns two equations with two variables into one equation with one variable. In the image, the first equation says \(y = x + 2\). Because \(y\) and \(x + 2\) are equal, you may replace \(y\) in the second equation with \((x + 2)\): \(x + (x + 2) = 8\). Now only \(x\) is left, so \(2x + 2 = 8\), \(2x = 6\) and \(x = 3\).

Then go back to the simpler equation to find the other variable: \(y = 3 + 2 = 5\). Write the answer as an ordered pair with \(x\) first: \((3, 5)\). Finally, check both equations. Checking only one is not enough, because many pairs make one equation true.

Practice: try these five questions

Q1

Solve the system by substitution: \(y = x + 4\) and \(x + y = 10\).

Answer

\((3, 7)\)

  1. Replace \(y\) with \((x + 4)\) in the second equation: \(x + (x + 4) = 10\).

  2. Combine like terms: \(2x + 4 = 10\), so \(2x = 6\) and \(x = 3\).

  3. Find \(y\): \(y = 3 + 4 = 7\).

  4. Check both equations: \(7 = 3 + 4\) and \(3 + 7 = 10\).

Q2

Solve the system by substitution: \(y = 2x\) and \(x + y = 12\).

Answer

\((4, 8)\)

  1. Replace \(y\) with \(2x\): \(x + 2x = 12\).

  2. \(3x = 12\), so \(x = 4\).

  3. \(y = 2(4) = 8\).

  4. Check: \(8 = 2(4)\) and \(4 + 8 = 12\).

Q3

Decide whether each ordered pair is a solution of the system \(y = x + 3\) and \(2x + y = 9\).

(a) \((2, 5)\)

(b) \((4, 7)\)

Answer

(a) Yes. (b) No.

  1. (a) \((2, 5)\): first equation \(5 = 2 + 3\) is true; second equation \(2(2) + 5 = 9\) is true. Both are true, so \((2, 5)\) is a solution.

  2. (b) \((4, 7)\): first equation \(7 = 4 + 3\) is true, but second equation \(2(4) + 7 = 15\), not 9. One equation fails, so \((4, 7)\) is not a solution.

  3. A solution must make both equations true; passing one check is not enough.

Q4

Solve the system by substitution: \(y = x - 1\) and \(x + y = 9\).

Answer

\((5, 4)\)

  1. Replace \(y\) with \((x - 1)\): \(x + (x - 1) = 9\).

  2. \(2x - 1 = 9\), so \(2x = 10\) and \(x = 5\).

  3. \(y = 5 - 1 = 4\).

  4. Check: \(4 = 5 - 1\) and \(5 + 4 = 9\).

Q5

Solve the system by substitution: \(y = 3x\) and \(2x + y = 20\).

Answer

\((4, 12)\)

  1. Replace \(y\) with \(3x\): \(2x + 3x = 20\).

  2. \(5x = 20\), so \(x = 4\).

  3. \(y = 3(4) = 12\).

  4. Check: \(12 = 3(4)\) and \(2(4) + 12 = 20\).

When x is already isolated

Substitution works with either variable. In the image, the first equation is already solved for \(x\): \(x = 2y + 1\). It tells you exactly what to put in place of \(x\) in the second equation: \((2y + 1) + 3y = 16\).

This time the equation that remains has only \(y\): \(5y + 1 = 16\), so \(5y = 15\) and \(y = 3\). Then substitute \(y = 3\) back into \(x = 2y + 1\) to get \(x = 2(3) + 1 = 7\).

Be careful with the order of the answer. You found \(y\) first, but an ordered pair is always written \((x, y)\), so the solution is \((7, 3)\), not \((3, 7)\). Check: \(7 = 2(3) + 1\) and \(7 + 3(3) = 16\).

Q6

Solve the system by substitution: \(x = y + 3\) and \(x + y = 11\).

Answer

\((7, 4)\)

  1. Replace \(x\) with \((y + 3)\): \((y + 3) + y = 11\).

  2. \(2y + 3 = 11\), so \(2y = 8\) and \(y = 4\).

  4. Check: \(7 = 4 + 3\) and \(7 + 4 = 11\).

Q7

Solve the system by substitution: \(x = 3y\) and \(x + 2y = 15\).

Answer

\((9, 3)\)

  1. Replace \(x\) with \(3y\): \(3y + 2y = 15\).

  2. \(5y = 15\), so \(y = 3\).

  3. \(x = 3(3) = 9\), giving \((9, 3)\).

  4. Check: \(9 = 3(3)\) and \(9 + 2(3) = 15\).

Q8

Solve the system by substitution: \(x = 2y - 1\) and \(x + y = 8\).

Answer

\((5, 3)\)

  1. Replace \(x\) with \((2y - 1)\): \((2y - 1) + y = 8\).

  2. \(3y - 1 = 8\), so \(3y = 9\) and \(y = 3\).

  3. \(x = 2(3) - 1 = 5\), giving \((5, 3)\).

  4. Check: \(5 = 2(3) - 1\) and \(5 + 3 = 8\).

Q9

Solve the system by substitution: \(x = 4y + 2\) and \(2x - 3y = 14\).

Answer

\((10, 2)\)

  1. Replace \(x\) with \((4y + 2)\): \(2(4y + 2) - 3y = 14\).

  2. Distribute: \(8y + 4 - 3y = 14\), so \(5y + 4 = 14\).

  3. \(5y = 10\) and \(y = 2\).

  4. \(x = 4(2) + 2 = 10\), giving \((10, 2)\). Check: \(2(10) - 3(2) = 20 - 6 = 14\).

Q10

A student solves \(x = y + 5\) and \(x + 2y = 11\). She finds \(y = 2\) and writes the solution as \((2, 7)\). What went wrong? Give the correct solution.

Answer

The coordinates are reversed; the solution is \((7, 2)\).

  1. Substitute: \((y + 5) + 2y = 11\), so \(3y + 5 = 11\), \(3y = 6\) and \(y = 2\). Her value of \(y\) is correct.

  2. Then \(x = 2 + 5 = 7\), also correct.

  3. An ordered pair is written \((x, y)\). Since \(x = 7\) and \(y = 2\), the solution is \((7, 2)\). Writing \((2, 7)\) means \(x = 2\), which fails the first equation: \(2 \ne 7 + 5\).

  4. Check \((7, 2)\): \(7 = 2 + 5\) and \(7 + 2(2) = 11\).

Isolate a variable first

Often neither equation starts with a variable by itself. Then the first job is to isolate a variable: solve one equation for \(x\) or for \(y\). Choose a variable whose coefficient is 1 (or \(-1\)), so you avoid fractions.

In the image, \(x + y = 9\) has \(y\) with coefficient 1. Subtract \(x\) from both sides: \(y = 9 - x\). Now substitute \((9 - x)\) for \(y\) in the other equation: \(2x + (9 - x) = 13\), so \(x + 9 = 13\) and \(x = 4\). Then \(y = 9 - 4 = 5\).

Always substitute into the equation you did not use to isolate the variable. Putting \(9 - x\) back into \(x + y = 9\) only gives \(9 = 9\), which tells you nothing new.

Q11

Solve by first isolating \(y\): \(x + y = 10\) and \(3x + y = 16\).

Answer

\((3, 7)\)

  1. Isolate \(y\) in the first equation: \(y = 10 - x\).

  2. Substitute into the second: \(3x + (10 - x) = 16\).

  3. \(2x + 10 = 16\), so \(2x = 6\) and \(x = 3\).

  4. \(y = 10 - 3 = 7\). Check: \(3 + 7 = 10\) and \(3(3) + 7 = 16\).

Q12

Solve by first isolating \(x\): \(x + y = 7\) and \(x + 4y = 19\).

Answer

\((3, 4)\)

  1. Isolate \(x\) in the first equation: \(x = 7 - y\).

  2. Substitute into the second: \((7 - y) + 4y = 19\).

  3. \(3y + 7 = 19\), so \(3y = 12\) and \(y = 4\).

  4. \(x = 7 - 4 = 3\), giving \((3, 4)\). Check: \(3 + 4 = 7\) and \(3 + 4(4) = 19\).

Q13

Solve the system: \(y - x = 2\) and \(3x + y = 18\).

Answer

\((4, 6)\)

  1. Isolate \(y\) in the first equation by adding \(x\) to both sides: \(y = x + 2\).

  2. Substitute into the second: \(3x + (x + 2) = 18\).

  3. \(4x + 2 = 18\), so \(4x = 16\) and \(x = 4\).

  4. \(y = 4 + 2 = 6\). Check: \(6 - 4 = 2\) and \(3(4) + 6 = 18\).

Q14

Solve the system: \(x - y = 1\) and \(2x + 3y = 22\).

Answer

\((5, 4)\)

  1. Isolate \(x\) in the first equation by adding \(y\) to both sides: \(x = y + 1\).

  2. Substitute into the second: \(2(y + 1) + 3y = 22\).

  3. Distribute: \(2y + 2 + 3y = 22\), so \(5y = 20\) and \(y = 4\).

  4. \(x = 4 + 1 = 5\). Check: \(5 - 4 = 1\) and \(2(5) + 3(4) = 22\).

Q15

In the system \(3x + y = 11\) and \(2x + 5y = 16\), which variable is easiest to isolate, and why? Isolate it and solve the system.

Answer

Isolate \(y\) (coefficient 1): \(y = 11 - 3x\); solution \((3, 2)\)

  1. In \(3x + y = 11\), \(y\) has coefficient 1, so isolating it needs no division and no fractions: \(y = 11 - 3x\).

  2. Substitute into the second equation with parentheses: \(2x + 5(11 - 3x) = 16\).

  3. Distribute: \(2x + 55 - 15x = 16\), so \(-13x + 55 = 16\) and \(-13x = -39\). Thus \(x = 3\).

  4. \(y = 11 - 3(3) = 2\). Check: \(3(3) + 2 = 11\) and \(2(3) + 5(2) = 16\).

Substitute with parentheses

When you substitute an expression, always put it in parentheses. In the image, \(3y\) means 3 times \(y\), and \(y\) is the whole expression \(x - 2\). So \(3y\) becomes \(3(x - 2)\), and the 3 multiplies both terms.

Distribute: \(3(x - 2) = 3x - 6\). Then \(x + 3x - 6 = 14\), so \(4x - 6 = 14\), \(4x = 20\) and \(x = 5\). Finally \(y = 5 - 2 = 3\), giving \((5, 3)\).

The most common mistake is writing \(x + 3x - 2 = 14\), multiplying only the first term. Watch the signs too: subtracting an expression, as in \(3x - 2(2x - 1)\), changes the sign of every term inside, giving \(3x - 4x + 2\).

Q16

Solve the system: \(y = x + 1\) and \(x + 2y = 11\).

Answer

\((3, 4)\)

  1. Substitute with parentheses: \(x + 2(x + 1) = 11\).

  2. Distribute the 2: \(x + 2x + 2 = 11\), so \(3x + 2 = 11\).

  3. \(3x = 9\) and \(x = 3\).

  4. \(y = 3 + 1 = 4\). Check: \(3 + 2(4) = 11\).

Q17

Solve the system: \(y = x - 3\) and \(2x + 3y = 21\).

Answer

\((6, 3)\)

  1. Substitute with parentheses: \(2x + 3(x - 3) = 21\).

  2. Distribute the 3 to both terms: \(2x + 3x - 9 = 21\), so \(5x - 9 = 21\).

  3. \(5x = 30\) and \(x = 6\).

  4. \(y = 6 - 3 = 3\). Check: \(2(6) + 3(3) = 12 + 9 = 21\).

Q18

Solve the system: \(x = y + 2\) and \(4x - 3y = 13\).

Answer

\((7, 5)\)

  1. Substitute with parentheses: \(4(y + 2) - 3y = 13\).

  2. Distribute the 4: \(4y + 8 - 3y = 13\), so \(y + 8 = 13\).

  3. \(y = 5\).

  4. \(x = 5 + 2 = 7\), giving \((7, 5)\). Check: \(4(7) - 3(5) = 28 - 15 = 13\).

Q19

Solve the system: \(y = 2x - 1\) and \(3x - 2y = -1\). Watch the sign in front of the parentheses.

Answer

\((3, 5)\)

  1. Substitute with parentheses: \(3x - 2(2x - 1) = -1\).

  2. Distribute \(-2\) to both terms: \(-2(2x) = -4x\) and \(-2(-1) = +2\). So \(3x - 4x + 2 = -1\).

  3. \(-x + 2 = -1\), so \(-x = -3\) and \(x = 3\).

  4. \(y = 2(3) - 1 = 5\). Check: \(3(3) - 2(5) = 9 - 10 = -1\).

Q20

To solve \(y = x - 4\) and \(x + 2y = 10\), Jamie writes \(x + 2x - 4 = 10\). Find Jamie's mistake, then solve the system correctly.

Answer

The 2 must multiply both terms: \(x + 2x - 8 = 10\); solution \((6, 2)\)

  1. Jamie replaced \(2y\) with \(2x - 4\), but \(2y = 2(x - 4)\): the 2 multiplies both \(x\) and \(-4\).

  2. Correct step: \(x + 2(x - 4) = 10\), so \(x + 2x - 8 = 10\).

  3. \(3x - 8 = 10\), \(3x = 18\) and \(x = 6\).

  4. \(y = 6 - 4 = 2\). Check: \(6 + 2(2) = 10\). (Jamie's equation would give \(x = \dfrac{14}{3}\), which fails the check.)

When both equations give y

If both equations are solved for \(y\), substitution becomes very quick. At the solution point both lines have the same height \(y\), so the two expressions must be equal: \(2x + 1 = 13 - x\). This is substitution too: you replaced the \(y\) in \(y = 13 - x\) with \(2x + 1\).

Collect the \(x\)-terms on one side: add \(x\) to both sides to get \(3x + 1 = 13\), so \(3x = 12\) and \(x = 4\). Use either equation to find \(y\): \(y = 2(4) + 1 = 9\), and the other equation should agree: \(13 - 4 = 9\).

Both equations are in slope-intercept form, so you can also graph them: start each line at its y-intercept and use rise over run. The lines cross at \((4, 9)\). Graphing is a good check, and substitution gives the exact answer even when the crossing point is hard to read.

Q21

Solve the system: \(y = x + 6\) and \(y = 3x - 4\).

Answer

\((5, 11)\)

  1. Both equations give \(y\), so set the expressions equal: \(x + 6 = 3x - 4\).

  2. Subtract \(x\) from both sides: \(6 = 2x - 4\). Add 4: \(10 = 2x\), so \(x = 5\).

  3. \(y = 5 + 6 = 11\).

  4. Check with the other equation: \(3(5) - 4 = 11\).

Q22

Solve the system: \(y = 2x + 3\) and \(y = 23 - 3x\).

Answer

\((4, 11)\)

  1. Set the expressions equal: \(2x + 3 = 23 - 3x\).

  2. Add \(3x\) to both sides: \(5x + 3 = 23\).

  3. \(5x = 20\), so \(x = 4\).

  4. \(y = 2(4) + 3 = 11\). Check: \(23 - 3(4) = 11\).

Q23

Solve the system: \(y = 4x\) and \(y = x + 9\).

Answer

\((3, 12)\)

  1. Set the expressions equal: \(4x = x + 9\).

  2. Subtract \(x\): \(3x = 9\), so \(x = 3\).

  3. \(y = 4(3) = 12\).

  4. Check: \(3 + 9 = 12\).

Q24

Solve the system: \(y = -x + 10\) and \(y = 2x - 2\).

Answer

\((4, 6)\)

  1. Set the expressions equal: \(-x + 10 = 2x - 2\).

  2. Add \(x\) to both sides: \(10 = 3x - 2\). Add 2: \(12 = 3x\), so \(x = 4\).

  3. \(y = -4 + 10 = 6\).

  4. Check: \(2(4) - 2 = 6\).

Q25

Graph \(y = x + 1\) and \(y = -x + 5\) on the same grid. Read the point where the lines cross, then confirm it by substitution.

Answer

The lines cross at \((2, 3)\)

  1. Graph \(y = x + 1\): start at \((0, 1)\) and move right 1, up 1: \((1, 2)\), \((2, 3)\), \((3, 4)\).

  2. Graph \(y = -x + 5\): start at \((0, 5)\) and move right 1, down 1: \((1, 4)\), \((2, 3)\), \((3, 2)\).

  3. Both lists contain \((2, 3)\), where the lines cross.

  4. Substitution: \(x + 1 = -x + 5\) gives \(2x = 4\), so \(x = 2\) and \(y = 2 + 1 = 3\). The graph and the algebra agree.

When a system has no solution

Sometimes the variable disappears. In the image, substituting \(2x + 3\) for \(y\) gives \((2x + 3) - 2x = 7\). The \(x\)-terms cancel and you are left with \(3 = 7\), a false statement. No value of \(x\) can make it true, so the system has no solution.

Here is why. The first equation can be rewritten as \(y - 2x = 3\), and the second says \(y - 2x = 7\). The same quantity cannot equal 3 and 7 at once. Rewrite the second equation as \(y = 2x + 7\): both lines have slope 2 but different y-intercepts, so they are parallel and never cross.

Quick test: if both equations, written as \(y = mx + b\), have the same slope and different y-intercepts, the system has no solution. Write the answer as "no solution", not as a number.

Practice: try these five questions

Q26

Solve the system: \(y = 3x + 1\) and \(y - 3x = 5\).

Answer

No solution

  1. Replace \(y\) with \((3x + 1)\): \((3x + 1) - 3x = 5\).

  2. Combine like terms: \(3x - 3x + 1 = 5\), so \(1 = 5\).

  3. \(1 = 5\) is false, and no \(x\) can change that.

  4. No ordered pair satisfies both equations. (Both lines have slope 3; their y-intercepts are 1 and 5.)

Q27

Solve the system: \(y = x + 4\) and \(2x - 2y = 6\).

Answer

No solution

  1. Substitute: \(2x - 2(x + 4) = 6\).

  2. Distribute \(-2\): \(2x - 2x - 8 = 6\), so \(-8 = 6\).

  3. The statement is false, so the system has no solution.

  4. Why: \(2x - 2y = 6\) rewrites as \(y = x - 3\). Both lines have slope 1 with different y-intercepts (4 and \(-3\)), so they are parallel.

Q28

One of these systems has no solution and the other has exactly one. Solve each.

(a) \(y = 2x - 1\) and \(y = 2x + 4\)

(b) \(y = 2x - 1\) and \(y = 3x - 4\)

Answer

(a) No solution. (b) \((3, 5)\)

  1. (a) Set equal: \(2x - 1 = 2x + 4\). Subtract \(2x\): \(-1 = 4\), false. No solution (same slope 2, different intercepts).

  2. (b) Set equal: \(2x - 1 = 3x - 4\). Subtract \(2x\): \(-1 = x - 4\), so \(x = 3\).

  3. (b) \(y = 2(3) - 1 = 5\). Check: \(3(3) - 4 = 5\). Exactly one solution, \((3, 5)\).

Q29

Graph \(y = x + 2\) and \(y = x - 1\) on the same grid. Use the graph and substitution to explain why the system has no solution.

Answer

The lines are parallel (slope 1, intercepts 2 and \(-1\)); substitution gives \(2 = -1\), false

  1. \(y = x + 2\): start at \((0, 2)\), move right 1 and up 1.

  2. \(y = x - 1\): start at \((0, -1)\), move right 1 and up 1.

  3. Both lines have slope 1, so they rise at the same rate and stay 3 units apart. They never cross.

  4. Substitution: \(x + 2 = x - 1\) gives \(2 = -1\), a false statement. No solution.

Q30

Solve the system: \(y = -2x + 5\) and \(4x + 2y = 6\). Then rewrite the second equation in the form \(y = mx + b\) to explain your result.

Answer

No solution; the second equation is \(y = -2x + 3\), a parallel line

  1. Substitute: \(4x + 2(-2x + 5) = 6\).

  2. Distribute: \(4x - 4x + 10 = 6\), so \(10 = 6\), false. No solution.

  3. Rewrite \(4x + 2y = 6\): subtract \(4x\) to get \(2y = -4x + 6\), then divide by 2: \(y = -2x + 3\).

  4. Both lines have slope \(-2\) but y-intercepts 5 and 3, so they are parallel and never meet.

Infinitely many solutions

The variable can also disappear and leave a true statement. In the image, \((2x + 3) - 2x = 3\) becomes \(3 = 3\). This is true for every value of \(x\), so the system has infinitely many solutions.

The reason: \(y - 2x = 3\) rearranges to \(y = 2x + 3\), exactly the first equation. Both equations describe the same line, so every point on that line satisfies both. Choose any \(x\) and compute \(y = 2x + 3\): \((-1, 1)\), \((0, 3)\) and \((1, 5)\) are three of the solutions.

Compare the endings. One value such as \(x = 4\): exactly one solution, where the lines cross. A false statement such as \(3 = 7\): no solution, parallel lines. A true statement such as \(3 = 3\): infinitely many solutions, the same line. Describe the answer as "every point on \(y = 2x + 3\)", not "the answer is 3".

Practice: try these five questions

Q31

Solve the system: \(y = x + 5\) and \(y - x = 5\). Name three solutions.

Answer

Infinitely many solutions; for example \((0, 5)\), \((1, 6)\), \((2, 7)\)

  1. Substitute: \((x + 5) - x = 5\).

  2. Combine like terms: \(5 = 5\), true for every \(x\).

  3. Both equations describe the line \(y = x + 5\), so every point on it is a solution.

  4. Choose \(x = 0, 1, 2\): \((0, 5)\), \((1, 6)\), \((2, 7)\).

Q32

Solve the system: \(x = 2y - 1\) and \(3x - 6y = -3\). Name three solutions.

Answer

Infinitely many solutions; for example \((-1, 0)\), \((1, 1)\), \((3, 2)\)

  1. Substitute: \(3(2y - 1) - 6y = -3\).

  2. Distribute: \(6y - 3 - 6y = -3\), so \(-3 = -3\), true for every \(y\).

  3. Both equations describe the same line, \(x = 2y - 1\).

  4. Choose \(y = 0, 1, 2\): \(x = -1, 1, 3\), giving \((-1, 0)\), \((1, 1)\), \((3, 2)\).

Q33

The system \(y = 3x - 2\) and \(6x - 2y = 4\) has infinitely many solutions. Decide whether each ordered pair is a solution.

(a) \((4, 10)\)

(b) \((1, 2)\)

(c) \((-1, -5)\)

Answer

(a) Yes. (b) No. (c) Yes.

  1. Substitution confirms the claim: \(6x - 2(3x - 2) = 6x - 6x + 4 = 4\), true for every \(x\). So a pair is a solution exactly when it lies on \(y = 3x - 2\).

  2. (a) \((4, 10)\): \(3(4) - 2 = 10\). Yes. Also \(6(4) - 2(10) = 4\).

  3. (b) \((1, 2)\): \(3(1) - 2 = 1 \ne 2\). No.

  4. (c) \((-1, -5)\): \(3(-1) - 2 = -5\). Yes. Also \(6(-1) - 2(-5) = -6 + 10 = 4\).

Q34

Use substitution to classify each system as having one solution, no solution, or infinitely many solutions. Give the solution when there is exactly one.

(a) \(y = 4x - 1\) and \(y - 4x = -1\)

(b) \(y = 4x - 1\) and \(y - 4x = 2\)

(c) \(y = 4x - 1\) and \(y + x = 9\)

Answer

(a) Infinitely many. (b) No solution. (c) One solution, \((2, 7)\)

  1. (a) \((4x - 1) - 4x = -1\) gives \(-1 = -1\), true: infinitely many solutions (same line).

  2. (b) \((4x - 1) - 4x = 2\) gives \(-1 = 2\), false: no solution (parallel lines).

  3. (c) \((4x - 1) + x = 9\) gives \(5x - 1 = 9\), so \(x = 2\) and \(y = 4(2) - 1 = 7\): one solution, \((2, 7)\).

  4. Check (c): \(7 + 2 = 9\).

Q35

For \(y = -x + 6\) and \(2x + 2y = 12\), a student gets \(12 = 12\) and writes "The solution is 12." Explain the error and describe the correct answer.

Answer

\(12 = 12\) means infinitely many solutions: every point on \(y = -x + 6\), such as \((0, 6)\), \((2, 4)\), \((6, 0)\)

  1. Substitute: \(2x + 2(-x + 6) = 2x - 2x + 12 = 12\), so \(12 = 12\).

  2. The variable disappeared and the statement is true. That does not give a value for \(x\) or \(y\); 12 is not a solution (a solution must be an ordered pair).

  3. A true statement means both equations describe the same line: \(2x + 2y = 12\) divides by 2 to give \(x + y = 6\), or \(y = -x + 6\).

  4. So there are infinitely many solutions, every point on \(y = -x + 6\), for example \((0, 6)\), \((2, 4)\) and \((6, 0)\).

School play ticket sales

Systems are a natural tool when a story gives you two facts about two unknowns. Start by naming the unknowns with letters that remind you what they mean: \(a\) = adult tickets and \(s\) = student tickets.

Turn each fact into an equation. The number of tickets gives \(a + s = 20\). The money gives \(5a + 3s = 76\), because each adult ticket brings in $5 and each student ticket $3. Isolate \(s = 20 - a\), substitute with parentheses: \(5a + 3(20 - a) = 76\), so \(5a + 60 - 3a = 76\), \(2a = 16\) and \(a = 8\). Then \(s = 20 - 8 = 12\).

Answer in words with units, "8 adult tickets and 12 student tickets", and check against the story, not just your equations: \(8 + 12 = 20\) tickets and \(8(\$5) + 12(\$3) = \$40 + \$36 = \$76\). A count of tickets must also be a whole number that is not negative, which is a useful reasonableness check.

Q36

A museum sold 30 tickets for $201. Adult tickets cost $8 and child tickets cost $5. Write a system and find how many of each were sold.

Answer

17 adult tickets and 13 child tickets

  1. Let \(a\) = adult tickets and \(c\) = child tickets: \(a + c = 30\) and \(8a + 5c = 201\).

  2. Isolate \(c = 30 - a\) and substitute: \(8a + 5(30 - a) = 201\).

  3. \(8a + 150 - 5a = 201\), so \(3a = 51\) and \(a = 17\). Then \(c = 30 - 17 = 13\).

  4. Check: \(17 + 13 = 30\) tickets and \(17(\$8) + 13(\$5) = \$136 + \$65 = \$201\).

Q37

The sum of two numbers is 25. The larger number is 7 more than the smaller. Write a system and find both numbers.

Answer

9 and 16

  1. Let \(s\) = smaller and \(L\) = larger: \(s + L = 25\) and \(L = s + 7\).

  2. Substitute: \(s + (s + 7) = 25\), so \(2s + 7 = 25\).

  3. \(2s = 18\), \(s = 9\), and \(L = 9 + 7 = 16\).

  4. Check: \(9 + 16 = 25\) and \(16 - 9 = 7\).

Q38

At a bake sale, 40 items were sold for $62. Cookies cost $1 each and brownies cost $2 each. How many of each were sold?

Answer

18 cookies and 22 brownies

  1. Let \(c\) = cookies and \(b\) = brownies: \(c + b = 40\) and \(c + 2b = 62\).

  2. Isolate \(c = 40 - b\) and substitute: \((40 - b) + 2b = 62\).

  3. \(40 + b = 62\), so \(b = 22\) and \(c = 40 - 22 = 18\).

  4. Check: \(18 + 22 = 40\) items and \(18(\$1) + 22(\$2) = \$18 + \$44 = \$62\).

Q39

A jar holds 18 coins, all dimes and quarters, worth $3.00 in total. How many of each coin are there?

Answer

10 dimes and 8 quarters

  1. Let \(d\) = dimes and \(q\) = quarters. Count: \(d + q = 18\). Value in cents: \(10d + 25q = 300\).

  2. Isolate \(d = 18 - q\) and substitute: \(10(18 - q) + 25q = 300\).

  3. \(180 - 10q + 25q = 300\), so \(15q = 120\) and \(q = 8\). Then \(d = 18 - 8 = 10\).

  4. Check: \(10 + 8 = 18\) coins and \(10(10) + 25(8) = 100 + 200 = 300\) cents, or $3.00.

Q40

A rectangle has a perimeter of 36 cm. Its length is 4 cm more than its width. Write a system and find the length and width.

Answer

Length 11 cm, width 7 cm

  1. Let \(L\) = length and \(W\) = width: \(2L + 2W = 36\) and \(L = W + 4\).

  2. Substitute: \(2(W + 4) + 2W = 36\), so \(2W + 8 + 2W = 36\).

  3. \(4W + 8 = 36\), \(4W = 28\) and \(W = 7\). Then \(L = 7 + 4 = 11\).

R1

Solve the system by substitution: \(y = x + 6\) and \(x + y = 14\).

Answer

\((4, 10)\)

  1. Replace \(y\): \(x + (x + 6) = 14\), so \(2x + 6 = 14\).

  2. \(2x = 8\) and \(x = 4\).

  3. \(y = 4 + 6 = 10\). Check: \(4 + 10 = 14\).

R2

Solve the system: \(x = 3y - 2\) and \(x + y = 14\).

Answer

\((10, 4)\)

  1. Replace \(x\): \((3y - 2) + y = 14\), so \(4y - 2 = 14\).

  2. \(4y = 16\) and \(y = 4\).

  3. \(x = 3(4) - 2 = 10\), giving \((10, 4)\). Check: \(10 + 4 = 14\).

R3

Solve the system: \(x + y = 12\) and \(4x + y = 27\).

Answer

\((5, 7)\)

  1. Isolate \(y\) in the first equation: \(y = 12 - x\).

  2. Substitute: \(4x + (12 - x) = 27\), so \(3x + 12 = 27\).

  3. \(3x = 15\) and \(x = 5\). Then \(y = 12 - 5 = 7\).

  4. Check: \(4(5) + 7 = 27\).

R4

Solve the system: \(y = x - 5\) and \(3x + 2y = 15\).

Answer

\((5, 0)\)

  1. Substitute with parentheses: \(3x + 2(x - 5) = 15\).

  2. Distribute: \(3x + 2x - 10 = 15\), so \(5x = 25\) and \(x = 5\).

  3. \(y = 5 - 5 = 0\). A coordinate of 0 is fine.

  4. Check: \(3(5) + 2(0) = 15\).

R5

Solve the system: \(y = 5x - 2\) and \(y = 2x + 7\).

Answer

\((3, 13)\)

  1. Set the expressions equal: \(5x - 2 = 2x + 7\).

  2. Subtract \(2x\): \(3x - 2 = 7\), so \(3x = 9\) and \(x = 3\).

  3. \(y = 5(3) - 2 = 13\). Check: \(2(3) + 7 = 13\).

R6

Solve the system: \(y = -3x + 4\) and \(6x + 2y = 10\).

Answer

No solution

  1. Substitute: \(6x + 2(-3x + 4) = 10\).

  2. Distribute: \(6x - 6x + 8 = 10\), so \(8 = 10\), false.

  3. No solution. The second equation is \(y = -3x + 5\): same slope \(-3\), different y-intercept, so the lines are parallel.

R7

Solve the system: \(y = 5 - 2x\) and \(4x + 2y = 10\). If there are infinitely many solutions, name three.

Answer

Infinitely many solutions; for example \((0, 5)\), \((1, 3)\), \((2, 1)\)

  1. Substitute: \(4x + 2(5 - 2x) = 10\).

  2. Distribute: \(4x + 10 - 4x = 10\), so \(10 = 10\), true for every \(x\).

  3. Both equations describe the line \(y = -2x + 5\).

  4. Choose \(x = 0, 1, 2\): \((0, 5)\), \((1, 3)\), \((2, 1)\).

R8

Graph \(y = 2x - 3\) and \(y = -x + 3\) on the same grid. Read the crossing point, then confirm it by substitution.

Answer

The lines cross at \((2, 1)\)

  1. \(y = 2x - 3\): start at \((0, -3)\), move right 1 and up 2: \((1, -1)\), \((2, 1)\), \((3, 3)\).

  2. \(y = -x + 3\): start at \((0, 3)\), move right 1 and down 1: \((1, 2)\), \((2, 1)\), \((3, 0)\).

  3. The lines cross at \((2, 1)\).

  4. Substitution: \(2x - 3 = -x + 3\) gives \(3x = 6\), so \(x = 2\) and \(y = 2(2) - 3 = 1\).

20 floor tickets and 30 balcony tickets

Answer

23 and 17

  2. Isolate \(x = y + 6\) and substitute: \((y + 6) + y = 40\).

  3. \(2y + 6 = 40\), \(2y = 34\), \(y = 17\), and \(x = 23\).

  4. Check: \(23 + 17 = 40\) and \(23 - 17 = 6\).

Maya is 18 and her brother is 6

Quick questions and answers

What is the substitution method for systems of equations?

Solve one equation for one variable, then replace that variable in the other equation with the expression, in parentheses. The result is one equation with one variable. Solve it, substitute back to find the other variable, and check the ordered pair in both equations.

Which variable should I isolate first?

Choose a variable that is already alone, such as y = x + 2, or one with a coefficient of 1 or −1, such as y in x + y = 9. Isolating it needs no division, so you avoid fractions.

Why do I need parentheses when I substitute?

The expression replaces the whole variable. In x + 3y = 14 with y = x − 2, 3y becomes 3(x − 2) = 3x − 6. Without parentheses it is easy to multiply only the first term and get the wrong answer.

How can I tell when a system has no solution?

If the variable disappears and leaves a false statement such as 3 = 7, there is no solution. In slope-intercept form the two lines have the same slope and different y-intercepts, so they are parallel and never meet.

What does it mean when I get 3 = 3?

If the variable disappears and leaves a true statement, the two equations describe the same line. The system has infinitely many solutions: every point on that line, such as (−1, 1), (0, 3) and (1, 5) on y = 2x + 3.

How do I set up a word problem as a system?

Name the two unknowns with letters, then write one equation for each fact in the story, such as a count (a + s = 20) and a total value (5a + 3s = 76). Solve by substitution, answer in words with units, and check against the story.
