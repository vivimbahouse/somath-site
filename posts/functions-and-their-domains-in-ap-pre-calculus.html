AP Precalculus Domain and Range: Restrictions and Practice

Follow the input through the function. Preserve original restrictions, solve inequalities, and distinguish domain from range.

School of Math · Updated October 6, 2026 · 4 min read

The domain tells you which inputs a function accepts; the range tells you which outputs it produces. In a composition, the expression sent into the outer function must belong to that function’s domain. Outside scaling and shifting affect outputs, not that input requirement.

Worked multiple-choice example: a transformed input

Let f have domain −2 ≤ x ≤ 8. Define g(x) = 3f(2(x + 4)) − 1. What is the domain of g?

  1. [−7, 23]
  2. [−5, 0]
  3. [−3, 2]
  4. [0, 20]
Answer

The input to f is 2(x + 4), so require −2 ≤ 2(x + 4) ≤ 8. Expanding gives −2 ≤ 2x + 8 ≤ 8. Subtract 8 and divide by 2: −10 ≤ 2x ≤ 0, hence −5 ≤ x ≤ 0. The answer is B, [−5, 0]. The outside 3 and −1 do not change the domain restriction.

Three restrictions worth checking first

ExpressionReal-domain requirementExample
FractionDenominator ≠ 01/(x − 2): x ≠ 2
Even rootRadicand ≥ 0√(x + 3): x ≥ −3
LogarithmArgument > 0ln(x − 4): x > 4

When several restrictions apply, use their intersection. A denominator containing a square root must be defined and nonzero, so its radicand must be strictly positive, not merely nonnegative.

Domain is not range

For h(x) = √(x − 3) + 2, the domain is [3, ∞), because x − 3 ≥ 0. The square-root output is nonnegative, so adding 2 gives range [2, ∞). Solve an input restriction for the domain and analyze possible outputs for the range.

Try five original questions

1. Find the domain of √(5 − x).

Answer

Require 5 − x ≥ 0, so x ≤ 5. Domain: (−∞, 5].

2. Find the domain of 1/√(x + 2).

Answer

The square root is in the denominator, so x + 2 > 0. Domain: (−2, ∞).

3. Simplify (x² − 4)/(x − 2), and state the original domain.

Answer

The expression simplifies to x + 2 only for x ≠ 2. The original domain is all real numbers except 2.

4. If f has domain [1, 7], find the domain of f(3 − 2x).

Answer

Require 1 ≤ 3 − 2x ≤ 7. Subtract 3: −2 ≤ −2x ≤ 4. Dividing by −2 reverses the inequalities, giving −2 ≤ x ≤ 1. Domain: [−2, 1].

5. Find the real domain of ln(x − 1)/√(6 − x).

Answer

The logarithm requires x > 1. The square root is in the denominator, requiring x < 6. Both conditions hold on (1, 6).

What to check before finishing

Keep restrictions from the original expression, not only the simplified one. Reverse inequality signs when dividing by a negative number. Check whether endpoints are permitted, and test one interior value if the interval feels uncertain.

Questions and answers

What is the difference between domain and range?

Domain describes allowed inputs; range describes possible outputs.

Does multiplying a function’s output change its domain?

Not by itself. Restrictions come from which inputs the original function can accept.

Can I include a zero inside a square root?

Yes for a standalone real square root, but not when that root is a denominator.

Can a logarithm’s argument equal zero?

No. A real logarithm requires a strictly positive argument.

Does simplifying erase a hole in the original domain?

No. Preserve restrictions from the original expression.
