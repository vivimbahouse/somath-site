What is a function? Inputs, rules, and outputs

A function is a rule that takes an input, applies the rule, and produces exactly one output. In the poster, the input 3 enters the rule \(f(x)=2x+1\) and the output is 7. Function notation records this as \(f(3)=7\): the letter in parentheses is the input, and the value of the expression is the output.

Different inputs may share an output, but one input can never have two outputs. The mapping \(1\to3,\;2\to5,\;3\to7\) is a function. The mapping \(2\to4,\;2\to6\) is not, because the input 2 is sent to two different places.

On a graph, the same idea becomes the vertical line test: a graph represents \(y\) as a function of \(x\) when every vertical line meets it at most once. The parabola \(y=x^2\) passes the test; a circle fails it because the vertical line \(x=0\) crosses the circle twice.

Q1

Let \(f(x)=3x-5\). Evaluate \(f(4)\), \(f(-2)\), and \(f(0)\). Write each result in function notation.

Answer

\(f(4)=7,\quad f(-2)=-11,\quad f(0)=-5\)

  1. Replace \(x\) by 4 and simplify.

    \[f(4)=3(4)-5=12-5=7\]

  2. Replace \(x\) by \(-2\). Keep the parentheses so the sign is handled correctly.

    \[f(-2)=3(-2)-5=-6-5=-11\]

  3. Replace \(x\) by 0. The output is the constant term.

    \[f(0)=3(0)-5=-5\]

Check

Each input produced exactly one output, which is what function notation promises: the input sits inside the parentheses and the output is the value of the expression.

Q2

Decide whether each relation is a function. Explain using the input-output rule.

\[A:\;1\to4,\quad 2\to4,\quad 3\to9\]
\[B:\;\{(1,2),\,(1,5),\,(3,7)\}\]
Answer

Relation A is a function. Relation B is not a function.

  1. Relation A: inputs 1, 2, and 3 each appear once. Two different inputs (1 and 2) share the output 4, which is allowed.

    \[A:\;1\to4,\quad 2\to4,\quad 3\to9\]

  2. Relation B: the input 1 appears twice with different outputs, 2 and 5. One input with two outputs breaks the rule.

    \[B:\;\{(1,2),\,(1,5),\,(3,7)\}\]

Check

The test is always about inputs, never about outputs. Repeated outputs are fine; a repeated input with different outputs is not.

Q3

Let \(g(x)=x^2-2x\). Find \(g(5)\) and \(g(-3)\). What do the results tell you about functions and repeated outputs?

Answer

\(g(5)=15\) and \(g(-3)=15\). Two different inputs can share one output.

  1. Substitute 5.

    \[g(5)=5^2-2(5)=25-10=15\]

  2. Substitute \(-3\), squaring the negative number carefully.

    \[g(-3)=(-3)^2-2(-3)=9+6=15\]

  3. Both inputs give 15. That does not violate the definition: each input still has exactly one output.

Check

If you were asked instead to solve \(g(x)=15\), you would get both \(x=5\) and \(x=-3\). Solving an equation can return several inputs; evaluating a function returns one output.

Q4

Use the vertical line test to decide which equations define \(y\) as a function of \(x\).

\[y=|x|,\qquad x=y^2,\qquad x^2+y^2=9,\qquad y=x^3\]
Answer

\(y=|x|\) and \(y=x^3\) are functions of \(x\). \(x=y^2\) and \(x^2+y^2=9\) are not.

  1. \(y=|x|\): each \(x\) gives exactly one absolute value, so every vertical line meets the V-shaped graph once.

  2. \(x=y^2\): the input \(x=4\) gives two outputs, so the vertical line \(x=4\) meets the sideways parabola twice.

    \[x=4\;\Rightarrow\;y=2\;\text{or}\;y=-2\]

  3. \(x^2+y^2=9\): this circle of radius 3 is crossed twice by \(x=0\), at \((0,3)\) and \((0,-3)\).

  4. \(y=x^3\): cubing any real number gives one result, so every vertical line meets the curve exactly once.

Check

A quick algebraic version of the test: if you can solve for \(y\) and get a single expression in \(x\), the equation defines a function.

Q5

Let \(h(x)=2x+1\). (a) Find the input \(x\) for which \(h(x)=11\). (b) Simplify \(h(a+1)\).

Answer

(a) \(x=5\). (b) \(h(a+1)=2a+3\).

  1. (a) Set the rule equal to the desired output and solve for the input.

    \[2x+1=11\]
    \[2x=10\quad\Rightarrow\quad x=5\]

  2. (b) The input is the whole expression \(a+1\). Substitute it in place of \(x\), then distribute.

    \[h(a+1)=2(a+1)+1\]
    \[h(a+1)=2a+2+1=2a+3\]

Check

Substitute back: \(h(5)=2(5)+1=11\). For part (b), test \(a=0\): \(h(1)=3\) and \(2(0)+3=3\). Both agree.

Domain and range

The domain of a function is the set of all inputs (\(x\)-values); the range is the set of all outputs (\(y\)-values). For a set of ordered pairs such as \(\{(-2,1),(0,3),(2,1)\}\), list the first coordinates once each for the domain, \(\{-2,0,2\}\), and the second coordinates once each for the range, \(\{1,3\}\).

For a graph, read the domain left to right and the range bottom to top. The parabola \(y=x^2\) uses every real \(x\), so its domain is \((-\infty,\infty)\); its outputs are never negative, so the range is \([0,\infty)\).

For an equation, find the \(x\)-values that make the expression defined. A denominator cannot be zero: \(f(x)=\dfrac{1}{x-2}\) requires \(x\ne2\), so the domain is \((-\infty,2)\cup(2,\infty)\) and the range is \((-\infty,0)\cup(0,\infty)\). A square root needs a nonnegative radicand: \(g(x)=\sqrt{x-3}\) requires \(x\ge3\), giving domain \([3,\infty)\) and range \([0,\infty)\). A square bracket includes an endpoint, a parenthesis excludes it, and infinity always takes a parenthesis.

Q6

State the domain and range of the relation. Is it a function?

\[\{(-3,2),\,(-1,5),\,(0,2),\,(4,-1)\}\]
Answer

Domain \(\{-3,-1,0,4\}\); range \(\{-1,2,5\}\). It is a function.

  1. List each distinct first coordinate once for the domain.

    \[\text{Domain}=\{-3,-1,0,4\}\]

  2. List each distinct second coordinate once for the range. The output 2 appears twice but is written once.

    \[\text{Range}=\{-1,2,5\}\]

  3. No input repeats with a different output, so the relation is a function.

Check

Four ordered pairs, four different inputs: the pairing is one output per input, exactly as the definition requires.

Q7

Find the domain and range of the function. Use interval notation.

\[f(x)=\frac{4}{x+5}\]
Answer

Domain \((-\infty,-5)\cup(-5,\infty)\); range \((-\infty,0)\cup(0,\infty)\).

  1. The only restriction is a zero denominator. Exclude the value that makes \(x+5=0\).

    \[x+5\ne0\quad\Rightarrow\quad x\ne-5\]

  2. Write the domain as two intervals around the excluded point.

    \[(-\infty,-5)\cup(-5,\infty)\]

  3. A fraction with nonzero numerator 4 can never equal 0, so 0 is the only output that does not occur.

    \[\text{Range: }(-\infty,0)\cup(0,\infty)\]

Check

Try to solve \(\dfrac{4}{x+5}=0\): multiplying through gives \(4=0\), which is impossible. That confirms 0 is missing from the range.

Q8

Find the domain and range of the function. Use interval notation.

\[g(x)=\sqrt{2x-8}\]
Answer

Domain \([4,\infty)\); range \([0,\infty)\).

  1. The radicand of a real square root must be nonnegative.

    \[2x-8\ge0\]

  2. Solve the inequality.

    \[2x\ge8\quad\Rightarrow\quad x\ge4\]

  3. The endpoint 4 is included because \(\sqrt{0}=0\) is defined, so use a square bracket.

    \[\text{Domain}=[4,\infty)\]

  4. A principal square root is never negative and starts at 0 when \(x=4\), then grows without bound.

    \[\text{Range}=[0,\infty)\]

Check

Test values: \(g(4)=0\), \(g(6)=2\), \(g(3)=\sqrt{-2}\) is undefined. The boundary at 4 behaves exactly as the interval notation claims.

Q9

The graph of \(f(x)=-x^2+4\) is a parabola that opens downward with vertex \((0,4)\). State its domain and range from the graph's shape.

Answer

Domain \((-\infty,\infty)\); range \((-\infty,4]\).

  1. Any real number can be squared, negated, and added to 4, so every \(x\) is allowed.

    \[\text{Domain}=(-\infty,\infty)\]

  2. The highest point is the vertex at \(y=4\). Since \(-x^2\le0\), every output is at most 4.

    \[-x^2+4\le4\]

  3. Outputs go down forever as \(|x|\) grows, so the range extends to \(-\infty\) and includes 4.

    \[\text{Range}=(-\infty,4]\]

Check

Compare with the poster's \(y=x^2\), range \([0,\infty)\). Reflecting and shifting flips the range to end at the new maximum, 4.

Q10

Find the domain of the function. Two restrictions apply.

\[h(x)=\frac{\sqrt{x+1}}{x-3}\]
Answer

Domain \([-1,3)\cup(3,\infty)\).

  1. The square root in the numerator requires a nonnegative radicand.

    \[x+1\ge0\quad\Rightarrow\quad x\ge-1\]

  2. The denominator cannot be zero.

    \[x-3\ne0\quad\Rightarrow\quad x\ne3\]

  3. Combine: start at \(-1\) (included), remove 3, and continue to infinity.

    \[[-1,3)\cup(3,\infty)\]

Check

Check the boundary points: \(h(-1)=0/(-4)=0\) is defined, so \(-1\) is included; \(h(3)\) divides by zero, so 3 is excluded.

Linear functions: slope, intercepts, and constant change

A linear function has the rule \(f(x)=mx+b\). The slope \(m\) is the rate of change: when \(x\) increases by 1, the output changes by \(m\). The constant \(b\) is the \(y\)-intercept, the initial value at \(x=0\).

For \(f(x)=2x+1\), the points \((0,1)\), \((1,3)\), and \((2,5)\) lie on the line. The slope is \(m=\dfrac{3-1}{1-0}=2\) (rise 2 for run 1), the \(y\)-intercept is \((0,1)\), and the \(x\)-intercept comes from \(2x+1=0\), which gives \(\left(-\tfrac12,0\right)\). In the table, equal steps of 1 in \(x\) always produce equal steps of 2 in \(f(x)\).

The sign of the slope tells the direction: \(m\gt0\) increasing, \(m\lt0\) decreasing, \(m=0\) constant. In context, a taxi that charges $4 plus $3 per mile is \(C(d)=3d+4\) for \(d\ge0\): the slope is the $3 per-mile rate and the intercept is the $4 initial cost.

Q11

For the linear function, state the slope, the \(y\)-intercept, and the \(x\)-intercept, and say whether the function is increasing or decreasing.

\[f(x)=-3x+6\]
Answer

Slope \(-3\); \(y\)-intercept \((0,6)\); \(x\)-intercept \((2,0)\); decreasing.

  1. Match the rule to \(mx+b\). The coefficient of \(x\) is the slope and the constant is the \(y\)-intercept.

    \[m=-3,\qquad b=6\;\Rightarrow\;(0,6)\]

  2. For the \(x\)-intercept, set the output equal to 0 and solve.

    \[-3x+6=0\]
    \[x=2\;\Rightarrow\;(2,0)\]

  3. A negative slope means the line falls from left to right, so the function is decreasing.

Check

Moving from \((0,6)\) to \((2,0)\) is a run of 2 and a fall of 6, and \(\dfrac{-6}{2}=-3\) matches the slope.

Q12

A line passes through \((1,2)\) and \((4,11)\). Find the slope and write the function in the form \(f(x)=mx+b\).

Answer

\(m=3\); \(f(x)=3x-1\).

  1. Compute the slope from the two points.

    \[m=\frac{11-2}{4-1}=\frac{9}{3}=3\]

  2. Use one point to find \(b\).

    \[2=3(1)+b\]
    \[b=-1\]

  3. Write the rule.

    \[f(x)=3x-1\]

Check

Second point: \(f(4)=3(4)-1=11\). Both points satisfy the rule.

Q13

The table shows outputs of a function at equally spaced inputs. Show the function is linear, write its rule, and find \(f(10)\).

\(x\)0123
\(f(x)\)581114
Answer

First differences are constant (3), so \(f(x)=3x+5\) and \(f(10)=35\).

  1. Compute first differences between consecutive outputs.

    \[8-5=3,\quad 11-8=3,\quad 14-11=3\]

  2. Equal changes in \(x\) produce equal changes in \(f(x)\), so the function is linear with slope 3. The output at \(x=0\) is the intercept 5.

    \[f(x)=3x+5\]

  3. Evaluate at 10.

    \[f(10)=3(10)+5=35\]

Check against the table: \(f(3)=3(3)+5=14\), which matches the last column.

Q14

Classify each linear function as increasing, decreasing, or constant, and give its rate of change.

\[f(x)=7-2x,\qquad g(x)=5,\qquad h(x)=\frac{x}{2}+1\]
Answer

\(f\) is decreasing (rate \(-2\)); \(g\) is constant (rate 0); \(h\) is increasing (rate \(\tfrac12\)).

  1. Rewrite \(f\) in \(mx+b\) order: \(f(x)=-2x+7\). Slope \(-2\lt0\): decreasing. Each unit increase in \(x\) lowers the output by 2.

  2. \(g(x)=5\) has slope 0: a horizontal line, so the output never changes.

  3. \(h(x)=\tfrac12x+1\) has slope \(\tfrac12\gt0\): increasing. Each unit increase in \(x\) raises the output by one half.

Check

Test with \(x=0\) and \(x=2\): \(f\) goes \(7\to3\), \(g\) goes \(5\to5\), \(h\) goes \(1\to2\). The directions match the slopes.

Q15

A gym charges a $25 enrollment fee plus $40 per month. Write a function \(C(m)\) for the total cost after \(m\) months, state a sensible domain, find \(C(6)\), and find how many months give a total of $345.

Answer

\(C(m)=40m+25\), \(m\ge0\) (whole months); \(C(6)=\$265\); 8 months cost $345.

  1. The $40 per month is the rate of change (slope) and the $25 fee is the initial value (intercept).

    \[C(m)=40m+25,\qquad m\ge0\]

  2. Evaluate at 6 months.

    \[C(6)=40(6)+25=240+25=265\]

  3. Set the cost equal to 345 and solve for \(m\).

    \[40m+25=345\]
    \[40m=320\quad\Rightarrow\quad m=8\]

Check

\(C(8)=40(8)+25=345\). Units: dollars per month times months gives dollars, plus the one-time fee in dollars.

Quadratic functions: vertex, symmetry, and zeros

A quadratic function can be written in standard form \(f(x)=ax^2+bx+c\) with \(a\ne0\), or in vertex form \(f(x)=a(x-h)^2+k\). The vertex is \((h,k)\), the axis of symmetry is the vertical line \(x=h\), and the sign of \(a\) sets the direction: \(a\gt0\) opens upward and the vertex is a minimum; \(a\lt0\) opens downward and the vertex is a maximum.

The poster uses \(f(x)=x^2-4x+3=(x-2)^2-1\). A table of values around the vertex shows the symmetry: \(f(0)=3,\;f(1)=0,\;f(2)=-1,\;f(3)=0,\;f(4)=3\). The vertex is \((2,-1)\), the minimum value is \(-1\), the domain is \((-\infty,\infty)\), and the range is \([-1,\infty)\).

To find zeros, set \(f(x)=0\): \((x-1)(x-3)=0\) gives \(x=1\) or \(x=3\), so the \(x\)-intercepts are \((1,0)\) and \((3,0)\). To find the \(y\)-intercept, set \(x=0\): \(f(0)=3\). A useful shortcut for the axis is \(x=-\dfrac{b}{2a}\), which here gives \(x=2\).

Q16

Write the function in vertex form. Then state the vertex, axis of symmetry, minimum or maximum value, range, zeros, and \(y\)-intercept.

\[f(x)=x^2-6x+5\]
Answer

Vertex form \((x-3)^2-4\); vertex \((3,-4)\); axis \(x=3\); minimum \(-4\); range \([-4,\infty)\); zeros \(x=1,5\); \(y\)-intercept \((0,5)\).

  1. Complete the square: half of \(-6\) is \(-3\), and \((-3)^2=9\).

    \[f(x)=(x^2-6x+9)-9+5\]
    \[f(x)=(x-3)^2-4\]

  2. Read the vertex \((h,k)=(3,-4)\) and the axis \(x=3\). Since \(a=1\gt0\), the parabola opens upward and \(-4\) is a minimum, so the range is \([-4,\infty)\).

  3. Zeros: factor the standard form.

    \[(x-1)(x-5)=0\]
    \[x=1\;\text{or}\;x=5\]

  4. \(y\)-intercept: evaluate at \(x=0\).

    \[f(0)=5\;\Rightarrow\;(0,5)\]

Check

Symmetry check: the zeros 1 and 5 average to 3, the axis. Expanding \((x-3)^2-4=x^2-6x+9-4=x^2-6x+5\) recovers the original.

Q17

The function is given in vertex form. State the vertex, the direction of opening, the maximum or minimum value, the range, the zeros, and the \(y\)-intercept.

\[g(x)=-2(x+1)^2+8\]
Answer

Vertex \((-1,8)\); opens downward; maximum 8; range \((-\infty,8]\); zeros \(x=-3,1\); \(y\)-intercept \((0,6)\).

  1. Compare with \(a(x-h)^2+k\): \(x+1=x-(-1)\), so \(h=-1\) and \(k=8\). Since \(a=-2\lt0\), the parabola opens downward and 8 is the maximum. The range is \((-\infty,8]\).

  2. Zeros: set the function equal to 0 and isolate the square.

    \[-2(x+1)^2+8=0\]
    \[(x+1)^2=4\]
    \[x+1=\pm2\quad\Rightarrow\quad x=1\;\text{or}\;x=-3\]

  3. \(y\)-intercept: substitute \(x=0\).

    \[g(0)=-2(1)^2+8=6\;\Rightarrow\;(0,6)\]

Check

The zeros \(-3\) and 1 are each 2 units from the axis \(x=-1\), as symmetry requires.

Q19

Find the vertex using \(x=-\dfrac{b}{2a}\). Then write the function in vertex form and state its range.

\[h(x)=2x^2+8x+3\]
Answer

Vertex \((-2,-5)\); \(h(x)=2(x+2)^2-5\); range \([-5,\infty)\).

  1. Identify \(a=2\), \(b=8\), and compute the axis.

    \[x=-\frac{8}{2(2)}=-2\]

  2. Evaluate the function at the axis to find \(k\).

    \[h(-2)=2(4)+8(-2)+3=8-16+3=-5\]

  3. Write vertex form with \(a=2\), \(h=-2\), \(k=-5\). Because \(a\gt0\), \(-5\) is the minimum.

    \[h(x)=2(x+2)^2-5\]
    \[\text{Range}=[-5,\infty)\]

Expand to confirm: \(2(x^2+4x+4)-5=2x^2+8x+8-5=2x^2+8x+3\).

Q20

A parabola has zeros at \(x=-2\) and \(x=6\) and passes through \((0,-6)\). Write its equation in factored form and standard form, then find its vertex.

Answer

\(f(x)=\tfrac12(x+2)(x-6)=\tfrac12x^2-2x-6\); vertex \((2,-8)\).

  1. Zeros give the factors; keep an unknown leading coefficient \(a\).

    \[f(x)=a(x+2)(x-6)\]

  2. Use the point \((0,-6)\) to find \(a\).

    \[-6=a(2)(-6)=-12a\]
    \[a=\tfrac12\]

  3. Expand to standard form.

    \[f(x)=\tfrac12(x^2-4x-12)=\tfrac12x^2-2x-6\]

  4. The axis is midway between the zeros; evaluate there.

    \[x=\frac{-2+6}{2}=2\]
    \[f(2)=\tfrac12(4)(-4)=-8\;\Rightarrow\;(2,-8)\]

Check

Check the given point: \(f(0)=\tfrac12(0)-0-6=-6\). And \(-\dfrac{b}{2a}=-\dfrac{-2}{2\cdot\frac12}=2\) agrees with the axis.

Polynomial functions: zeros and end behavior

A polynomial function has the form \(f(x)=a_nx^n+\cdots+a_1x+a_0\) with \(a_n\ne0\), where every exponent of \(x\) is a nonnegative integer. Its domain is all real numbers. For \(f(x)=2x^3-5x^2+x-4\), the degree is 3, the leading coefficient is 2, and the constant term is \(-4\).

In factored form, each factor gives a zero and an \(x\)-intercept \((r,0)\). For \(p(x)=(x+2)(x-1)^2\), the zero \(x=-2\) has multiplicity 1, so the graph crosses the axis there; the zero \(x=1\) has multiplicity 2, so the graph touches the axis and turns. Odd multiplicity crosses; even multiplicity touches.

The leading term controls the ends of the graph. Even degree with a positive leading coefficient: both ends up. Even degree, negative: both ends down. Odd degree, positive: left end down, right end up. Odd degree, negative: left end up, right end down. The example \(p(x)=(x+2)(x-1)^2\) has degree 3 and leading coefficient 1, so its left end goes down and its right end goes up. A polynomial of degree \(n\ge1\) has at most \(n\) real zeros and at most \(n-1\) turning points.

Q21

State the degree, leading coefficient, and constant term. Describe the end behavior and give the domain.

\[f(x)=-3x^4+2x^3-x+7\]
Answer

Degree 4; leading coefficient \(-3\); constant \(7\); both ends go down; domain \((-\infty,\infty)\).

  1. The highest power is \(x^4\), so the degree is 4 and the leading coefficient is its coefficient, \(-3\). The constant term is 7.

  2. Even degree with a negative leading coefficient: left end down and right end down. The leading term \(-3x^4\) dominates for large \(|x|\).

  3. Every polynomial accepts every real input.

    \[\text{Domain}=(-\infty,\infty)\]

Check

Test \(x=10\): \(-3(10)^4=-30{,}000\) overwhelms the other terms, so the output is strongly negative on the right, as predicted.

Q22

List the zeros with their multiplicities and state whether the graph crosses or touches the \(x\)-axis at each. Then give the degree and end behavior.

\[p(x)=(x-3)(x+1)^2(x-5)\]
Answer

Zeros: \(3\) (mult. 1, crosses), \(-1\) (mult. 2, touches), \(5\) (mult. 1, crosses). Degree 4, leading coefficient 1: both ends up.

  1. Set each factor equal to zero. The exponent on the factor is the multiplicity.

    \[x=3\;(1),\qquad x=-1\;(2),\qquad x=5\;(1)\]

  2. Odd multiplicity crosses the axis; even multiplicity touches and turns. So the graph crosses at 3 and 5 and touches at \(-1\).

  3. Add the multiplicities for the degree: \(1+2+1=4\). Multiplying the leading terms gives \(x\cdot x^2\cdot x=x^4\), coefficient 1. Even degree, positive: both ends up.

Check

Sign test near \(x=-1\): \(p(-2)=(-5)(1)(-7)=35\gt0\) and \(p(0)=(-3)(1)(-5)=15\gt0\). The graph stays positive on both sides of \(-1\), which is what touching (not crossing) looks like.

Q23

Predict the end behavior of each polynomial from its leading term only.

\[q(x)=2x^5-x^2+4,\qquad r(x)=-x^3+6x-1\]
Answer

\(q\): left end down, right end up. \(r\): left end up, right end down.

  1. \(q(x)=2x^5-x^2+4\): degree 5 (odd), leading coefficient 2 (positive). Odd and positive means the graph falls on the left and rises on the right.

  2. \(r(x)=-x^3+6x-1\): degree 3 (odd), leading coefficient \(-1\) (negative). Odd and negative means it rises on the left and falls on the right.

Rational functions: holes and asymptotes

A rational function is a ratio of polynomials, \(f(x)=\dfrac{P(x)}{Q(x)}\) with \(Q(x)\ne0\). Exclude every zero of the original denominator from the domain. For \(g(x)=\dfrac{1}{x-2}\), the domain is \((-\infty,2)\cup(2,\infty)\).

Factor before simplifying. In \(f(x)=\dfrac{(x-1)(x+2)}{(x-1)(x-3)}\), the domain excludes \(x=1\) and \(x=3\). The canceled factor \(x-1\) creates a hole at \(x=1\); its height comes from the simplified form, \(y=\dfrac{1+2}{1-3}=-\dfrac32\), so the hole is \(\left(1,-\tfrac32\right)\). The remaining denominator \(x-3\) gives a vertical asymptote at \(x=3\). Simplifying does not restore excluded inputs: \(x=1\) is still outside the domain.

Horizontal asymptotes come from comparing degrees. Numerator degree less than denominator degree: \(y=0\). Equal degrees: \(y\) equals the ratio of leading coefficients. Numerator degree greater: no horizontal asymptote. For \(f(x)=\dfrac{x+2}{x-3}\), the horizontal asymptote is \(y=1\). A graph may cross a horizontal asymptote. The workflow: factor, restrict the domain, simplify, then identify holes and asymptotes.

Function transformations: shifts, reflections, and scaling

Start with a parent function: linear \(f(x)=x\), quadratic \(f(x)=x^2\), cubic \(f(x)=x^3\), or reciprocal \(f(x)=\dfrac1x\). The general transformation rule is \(g(x)=a\,f\big(b(x-h)\big)+k\) with \(a\ne0\) and \(b\ne0\).

Each parameter has one job. \(h\): shift right \(h\) if \(h\gt0\), left \(|h|\) if \(h\lt0\). \(k\): shift up \(k\) if \(k\gt0\), down \(|k|\) if \(k\lt0\). \(|a|\): vertical scale factor; \(a\lt0\) also reflects across the \(x\)-axis. \(|b|\): horizontal scale factor \(\dfrac{1}{|b|}\); \(b\lt0\) reflects across the \(y\)-axis before shifting. A scale factor greater than 1 is a stretch; a factor between 0 and 1 is a compression.

Example: \(g(x)=-2(x-3)^2+1\) from the parent \(x^2\) is a shift right 3, a vertical stretch by 2, a reflection across the \(x\)-axis, and a shift up 1. The vertex moves to \((3,1)\), the parabola opens downward, the domain is \((-\infty,\infty)\), and the range is \((-\infty,1]\). Apply vertical scaling and reflection before the vertical shift. Inside changes affect \(x\); outside changes affect \(y\).

Compare function families

Recognize each family by its structure. Linear, such as \(f(x)=2x+1\): constant rate of change. Quadratic, such as \(f(x)=x^2\): degree 2, a parabola. Polynomial, such as \(f(x)=x^3-x\): nonnegative integer powers. Rational, such as \(f(x)=\dfrac1x\): a ratio of polynomials. The families nest: linear and quadratic functions are polynomials, and every polynomial is also rational because \(P(x)=\dfrac{P(x)}{1}\).

Tables reveal the family when the inputs are equally spaced. For \(2x+1\), the first differences are constant (\(+2\)). For \(x^2\), the first differences \(3,5,7\) are not constant but the second differences are (\(+2\)). For \(x^3\) the outputs \(1,8,27,64\) need third differences, and for \(\dfrac1x\) the outputs \(1,\tfrac12,\tfrac13,\tfrac14\) have a constant product with \(x\). A finite table alone does not prove the model; it suggests one to test.

Choose a model from the relationship, then check its domain and units. Taxi fare \(C(d)=3d+4\), \(d\ge0\), is linear. Square area \(A(s)=s^2\), \(s\ge0\), is quadratic. Cube volume \(V(s)=s^3\), \(s\ge0\), is a cubic polynomial. Travel time for 120 miles, \(T(v)=\dfrac{120}{v}\), \(v\gt0\), is rational.

Parent point \((2,4)\) maps to \((7,0)\): \(g(7)=\tfrac12(4)-2=0\).

R8

Two tables use the same inputs. Identify the family each table suggests and write a rule for each.

\(x\)0123
Table A: \(y\)25811
Table B: \(y\)12510
Answer

Table A: linear, \(y=3x+2\). Table B: quadratic, \(y=x^2+1\).

  1. Table A first differences are all 3, so the model is linear with slope 3 and intercept 2 (the output at \(x=0\)).

    \[y=3x+2\]

  2. Table B first differences are \(1,3,5\); second differences are \(2,2\), so the model is quadratic.

  3. Compare Table B with \(x^2\): \(0,1,4,9\). Each output is 1 more.

    \[y=x^2+1\]

Check

Check the last rows: \(3(3)+2=11\) and \(3^2+1=10\). Both rules reproduce their tables.

Homework word problems

Twelve problems progress from direct linear models to choosing and comparing families. Define the variable, write the model, state its domain, solve, and interpret the result with units.

W1

A plumber charges a $60 call-out fee plus $45 per hour. Write the cost function \(C(h)\), find the cost of a 3-hour job, and find how many hours produce a bill of $285.

Answer

\(C(h)=45h+60\); a 3-hour job costs $195; a $285 bill means 5 hours.

  1. Rate per hour is the slope; the fixed fee is the intercept. Time cannot be negative.

    \[C(h)=45h+60,\qquad h\ge0\]

  2. Evaluate at 3.

    \[C(3)=135+60=195\]

  3. Solve for \(h\).

    \[45h+60=285\]
    \[45h=225\quad\Rightarrow\quad h=5\]

Check

\(C(5)=225+60=285\). Dollars per hour times hours plus dollars gives dollars.

W2

A tank holds 500 gallons and drains at a constant 20 gallons per minute. Write \(V(t)\) for the volume after \(t\) minutes, give the domain in context, and find when the tank is empty.

Answer

\(V(t)=500-20t\), domain \(0\le t\le25\); the tank is empty at \(t=25\) minutes.

  1. Draining lowers the volume, so the rate of change is \(-20\) gallons per minute and the initial value is 500.

    \[V(t)=500-20t\]

  2. Set the volume to zero.

    \[500-20t=0\quad\Rightarrow\quad t=25\]

  3. The model only makes sense while the volume is between 500 and 0, so restrict the domain.

    \[0\le t\le25\]

Check

\(V(10)=300\): after 10 minutes, 200 gallons have drained, which is \(10\times20\).

W3

A trip is 240 miles. Write the travel time \(T(v)\) in hours as a function of average speed \(v\) in miles per hour. Find \(T(60)\) and \(T(80)\), state the domain, and explain the meaning of the horizontal asymptote.

Answer

\(T(v)=\dfrac{240}{v}\), \(v\gt0\); \(T(60)=4\) h, \(T(80)=3\) h; the asymptote \(T=0\) means time shrinks toward zero but never reaches it.

  1. Time equals distance divided by speed. Speed must be positive for the trip to happen.

    \[T(v)=\frac{240}{v},\qquad v\gt0\]

  2. Evaluate.

    \[T(60)=4,\qquad T(80)=3\]

  3. Numerator degree 0 is less than denominator degree 1, so the horizontal asymptote is \(T=0\). Faster speeds give shorter times, approaching but never equaling zero.

Check

Miles divided by miles per hour gives hours. Doubling the speed halves the time: \(T(120)=2\).

W4

A ball is thrown upward from a height of 5 feet. Its height in feet after \(t\) seconds is modeled below. Find the maximum height and when it occurs, the starting height, and the time the ball reaches the ground (to the nearest hundredth).

\[h(t)=-16t^2+48t+5\]
Answer

Maximum 41 ft at \(t=1.5\) s; starting height 5 ft; ground at \(t=\dfrac{6+\sqrt{41}}{4}\approx3.10\) s.

  1. The axis of symmetry gives the time of the maximum.

    \[t=-\frac{48}{2(-16)}=1.5\]

  2. Evaluate the height at that time.

    \[h(1.5)=-16(2.25)+48(1.5)+5\]
    \[h(1.5)=-36+72+5=41\]

  3. The starting height is \(h(0)=5\), the constant term.

  4. Set \(h(t)=0\) and use the quadratic formula on \(16t^2-48t-5=0\).

    \[t=\frac{48\pm\sqrt{2304+320}}{32}=\frac{48\pm8\sqrt{41}}{32}\]
    \[t=\frac{6\pm\sqrt{41}}{4}\approx3.10\;\text{(reject the negative root)}\]

Check

Domain in context: \(0\le t\le3.10\). The negative root \(t\approx-0.10\) is before the throw and has no physical meaning.

W5

A theater sells \(200-5p\) tickets when the price is \(p\) dollars. Write the revenue function \(R(p)\), give the domain in context, and find the price that maximizes revenue and the maximum revenue.

Answer

\(R(p)=-5p^2+200p\), \(0\le p\le40\); maximum revenue $2,000 at a price of $20.

  1. Revenue is price times quantity.

    \[R(p)=p(200-5p)=-5p^2+200p\]

  2. Quantity must be nonnegative: \(200-5p\ge0\) gives \(p\le40\); price is nonnegative too.

    \[0\le p\le40\]

  3. The vertex of a downward parabola is the maximum.

    \[p=-\frac{200}{2(-5)}=20\]
    \[R(20)=20(200-100)=2000\]

Check

Neighbors: \(R(19)=19(105)=1995\) and \(R(21)=21(95)=1995\). Both are below 2,000, confirming the maximum. Revenue is zero at \(p=0\) and \(p=40\).

W6

A rectangular garden is enclosed with 60 meters of fencing. Let \(w\) be the width. Write the area \(A(w)\), state the domain, and find the dimensions that give the largest area.

Answer

\(A(w)=w(30-w)=30w-w^2\), \(0\lt w\lt30\); maximum area 225 m\(^2\) when the garden is 15 m by 15 m.

  1. The perimeter is 60, so width plus length is 30 and the length is \(30-w\).

    \[A(w)=w(30-w)=30w-w^2\]

  2. Both dimensions must be positive.

    \[0\lt w\lt30\]

  3. The zeros are 0 and 30; the vertex lies midway.

    \[w=15\]
    \[A(15)=15\cdot15=225\]

Check

Compare \(A(10)=200\) and \(A(20)=200\): symmetric about \(w=15\), and both smaller than 225.

W7

An open box is made from a 12-inch square of cardboard by cutting an \(x\)-inch square from each corner and folding up the sides. Write the volume \(V(x)\) in factored and expanded form, state the degree and domain, and find \(V(2)\) and \(V(3)\).

Answer

\(V(x)=x(12-2x)^2=4x^3-48x^2+144x\); degree 3; domain \(0\lt x\lt6\); \(V(2)=128\) in\(^3\), \(V(3)=108\) in\(^3\).

  1. The base is \((12-2x)\) by \((12-2x)\) and the height is \(x\).

    \[V(x)=x(12-2x)^2\]

  2. Expand.

    \[V(x)=x(144-48x+4x^2)=4x^3-48x^2+144x\]

  3. A cubic polynomial. The cut must be positive and leave a base: \(12-2x\gt0\) gives \(x\lt6\).

    \[0\lt x\lt6\]

  4. Evaluate.

    \[V(2)=2(8)^2=128\]
    \[V(3)=3(6)^2=108\]

Check

The zeros \(x=0\) and \(x=6\) (multiplicity 2) are the endpoints where the box collapses. The largest volume occurs between them, at a value of \(x\) you will locate exactly in calculus.

W8

The water level in a wave tank, in centimeters above the rest level, is modeled for \(0\le t\le5\) seconds by the function below. Factor it, find its zeros and their multiplicities, interpret what happens at each zero, and find \(h(1)\) and \(h(5)\).

\[h(t)=t^3-6t^2+9t\]
Answer

\(h(t)=t(t-3)^2\); zeros \(t=0\) (mult. 1) and \(t=3\) (mult. 2); the level crosses the rest level at 0 and touches it at 3 without going below; \(h(1)=4\) cm, \(h(5)=20\) cm.

  1. Factor out \(t\), then recognize a perfect square.

    \[h(t)=t(t^2-6t+9)=t(t-3)^2\]

  2. At \(t=0\) the multiplicity is 1, so the level crosses the rest line as the wave begins. At \(t=3\) the multiplicity is 2, so the level dips to exactly the rest line and turns back up without crossing.

  3. Evaluate.

    \[h(1)=1\cdot(-2)^2=4\]
    \[h(5)=5\cdot(2)^2=20\]

Check

Between the zeros, \(h(2)=2\) and \(h(4)=4\) are both positive: the water stays at or above rest level for the whole interval, as the even multiplicity predicts.

W9

A workshop spends $2,000 on setup plus $50 per unit to produce \(x\) units. The average cost per unit is given below. State the domain, find the average cost for 100 and 400 units, find how many units give an average cost of $60, and interpret the horizontal asymptote.

\[\bar C(x)=\frac{50x+2000}{x}\]
Answer

Domain \(x\gt0\); \(\bar C(100)=\$70\), \(\bar C(400)=\$55\); 200 units give $60; the asymptote \(y=50\) is the per-unit cost that average cost approaches but never reaches.

  1. Rewrite as a sum to see the structure. At least one unit must be produced.

    \[\bar C(x)=50+\frac{2000}{x},\qquad x\gt0\]

  2. Evaluate.

    \[\bar C(100)=50+20=70,\qquad \bar C(400)=50+5=55\]

  3. Set the average equal to 60.

    \[50+\frac{2000}{x}=60\]
    \[\frac{2000}{x}=10\quad\Rightarrow\quad x=200\]

  4. Equal degrees with leading coefficients 50 and 1 give the horizontal asymptote \(y=50\). The setup cost is spread thinner as output grows, so the average cost falls toward $50.

Check

\(\bar C(200)=\dfrac{10000+2000}{200}=60\). Dollars divided by units gives dollars per unit.

W10

The concentration of a medicine in the bloodstream, in milligrams per liter, \(t\) hours after a dose is modeled below. Find \(C(0)\), \(C(2)\), and \(C(6)\); state the horizontal asymptote and its meaning; and show, without calculus, that the concentration never exceeds 1 mg/L.

\[C(t)=\frac{4t}{t^2+4},\qquad t\ge0\]
Answer

\(C(0)=0\), \(C(2)=1\), \(C(6)=0.6\); horizontal asymptote \(C=0\) (the medicine washes out); \(C(t)\le1\) because \((t-2)^2\ge0\).

  1. Evaluate the three times.

    \[C(0)=0,\qquad C(2)=\frac{8}{8}=1,\qquad C(6)=\frac{24}{40}=0.6\]

  2. Numerator degree 1 is less than denominator degree 2, so the horizontal asymptote is \(C=0\): the concentration fades toward zero over time. The denominator \(t^2+4\) is never zero, so there is no vertical asymptote.

  3. Bound the function with a perfect square.

    \[(t-2)^2\ge0\;\Rightarrow\;t^2+4\ge4t\]
    \[\frac{4t}{t^2+4}\le1,\;\text{with equality only at }t=2\]

Check

The peak of 1 mg/L at 2 hours is consistent with the values: \(C(1)=0.8\) rising and \(C(6)=0.6\) falling.

W11

A lemonade stand's daily profit in dollars depends on the price \(p\) per cup. Identify the transformations of the parent \(p^2\), state the best price and maximum profit, find the prices that give zero profit, and give the domain over which the profit is nonnegative.

\[P(p)=-2(p-3)^2+18\]
Answer

Shift right 3, vertical stretch by 2, reflection across the \(p\)-axis, shift up 18; best price $3 with maximum profit $18; zero profit at \(p=0\) and \(p=6\); nonnegative profit for \(0\le p\le6\).

  1. Read the vertex form \(a(p-h)^2+k\): \(h=3\), \(a=-2\), \(k=18\). The negative \(a\) reflects the parabola so it opens downward and the vertex is a maximum.

    \[\text{Vertex }(3,18)\]

  2. Set profit to zero.

    \[-2(p-3)^2+18=0\]
    \[(p-3)^2=9\quad\Rightarrow\quad p=0\;\text{or}\;p=6\]

  3. Between the zeros the downward parabola is above the axis.

    \[0\le p\le6\]

Check

Expanded form \(P(p)=-2p^2+12p\) confirms \(P(0)=0\). Test \(P(1)=10\): a $1 price earns less than the $18 earned at $3.

W12

A lab records a bacteria count \(N\) (in thousands) at equally spaced hours. Use differences to choose a family, write a rule in the form \(N(t)=t^2+c\), predict \(N(10)\), find when the count reaches 84 thousand, and explain why the table alone does not prove the model.

\(t\) (hours)01234
\(N\) (thousands)3471219
Answer

Second differences are constant (2), so a quadratic fits: \(N(t)=t^2+3\); \(N(10)=103\) thousand; \(N=84\) at \(t=9\) hours; a finite table only suggests the model.

  1. First differences, then second differences.

    \[4-3=1,\;7-4=3,\;12-7=5,\;19-12=7\]
    \[3-1=2,\;5-3=2,\;7-5=2\]

  2. Constant second differences with equally spaced inputs suggest a quadratic. Compare with \(t^2\): \(0,1,4,9,16\). Each count is 3 more.

    \[N(t)=t^2+3\]

  3. Predict and solve.

    \[N(10)=100+3=103\]
    \[t^2+3=84\;\Rightarrow\;t^2=81\;\Rightarrow\;t=9\;(t\ge0)\]

  4. Five data points are consistent with this rule, but other functions also pass through the same five points. The table motivates the model; it does not prove how the count behaves at hour 10 or hour 20.

Check

Verify the last row: \(N(4)=16+3=19\). The negative root \(t=-9\) is rejected because time starts at 0.

Quick questions and answers

What makes a relation a function?

Each input has exactly one output. Different inputs may share an output, but one input can never produce two outputs. On a graph, every vertical line must meet the curve at most once.

How do I find a domain from an equation?

Look for operations that can fail: a denominator cannot be zero and the radicand of a square root cannot be negative. Exclude those inputs and write the remaining set in interval notation, using brackets for included endpoints and parentheses for excluded ones and for infinity.

What is the difference between standard form and vertex form?

Standard form is ax² + bx + c; vertex form is a(x − h)² + k. Vertex form shows the vertex (h, k) and the axis x = h directly. Convert by completing the square or by using the axis x = −b/(2a).

How does multiplicity change a graph?

A zero with odd multiplicity makes the graph cross the x-axis; a zero with even multiplicity makes it touch the axis and turn back. The degree bounds the real zeros (at most n) and the turning points (at most n − 1).

When is an excluded value a hole instead of an asymptote?

Factor first. If the factor that makes the denominator zero cancels with the numerator, the excluded value is a hole, with height found from the simplified form. If it does not cancel, it is a vertical asymptote. Either way the value stays out of the domain.

Which transformations happen inside and which outside?

Changes inside the parentheses affect x: horizontal shifts and horizontal scaling or reflection. Changes outside affect y: vertical scaling, reflection across the x-axis, and vertical shifts. Apply scaling and reflection before the vertical shift.
